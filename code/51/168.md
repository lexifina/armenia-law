# Հոդված 168. Չօգտագործված ամենամյա արձակուրդի տրամադրումը աշխատանքից ազատվելիս
Աշխատանքից ազատվելիս (բացառությամբ սույն օրենսգրքի 113-րդ հոդվածի 1-ին մասի 5-րդ և 6-րդ կետերով և 109-րդ հոդվածի 6-րդ, 7-րդ, 12-րդ, 13-րդ կետերով նախատեսված դեպքերի) չօգտագործված ամենամյա արձակուրդը այդ իրավունքը ձեռք բերած աշխատողի ցանկությամբ տրամադրվում է ազատման տարին, ամիսը, ամսաթիվը տեղափոխելու միջոցով: Այդ դեպքում աշխատանքից ազատման օր է համարվում ամենամյա արձակուրդի ժամկետի ավարտին հաջորդող օրը:
(168-րդ հոդվածը փոփ., լրաց. 24.06.10 ՀՕ-117-Ն)
