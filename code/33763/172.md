# Հոդված 172. Դպրոցի նպատակը և իրավական կարգավիճակը
1. Դատական դպրոցը շահույթ ստանալու նպատակ չհետապնդող պետական ոչ առևտրային կազմակերպության կարգավիճակ ունեցող իրավաբանական անձ է:
2. Դատական դպրոցի հիմնադիրն է Հայաստանի Հանրապետությունը` ի դեմս Դատարանների նախագահների խորհրդի:
3.
