# Հոդված 17. Ջրավազանային կառավարման պլանները
Ջրի ազգային ծրագրից ելնելով` Ջրային ռեսուրսների կառավարման և պահպանության մարմինը մշակում է ջրավազանային կառավարման պլաններ՝ վեց տարի ժամկետով, որոնք հաստատում է կառավարությունը:
Ջրավազանային կառավարման պլանավորման միջոցով հավասարակշռվում են ջրօգտագործողների, ներառյալ՝ համայնքների, էներգետիկայի, արդյունաբերության, գյուղատնտեսության և շրջակա միջավայրի փոխկապակցված հարաբերությունները՝ հաշվի առնելով նաև կլիմայի փոփոխության նկատմամբ ջրային ռեսուրսների խոցելիությունն ու հարմարվողականությունը:
Ջրավազանային կառավարման պլաններով սահմանվում են ռիսկային և խիստ փոփոխված ջրային մարմինները։
Ջրավազանային կառավարման պլանի բովանդակությունը հաստատում է Ջրային ռեսուրսների կառավարման և պահպանության մարմնի ղեկավարը։
(17-րդ հոդվածը լրաց. 07.07.22 ՀՕ-316-Ն)
