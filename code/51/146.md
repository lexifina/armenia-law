# Հոդված 146. Արտաժամյա աշխատաժամանակի տևողությունը
1. Գործատուի պահանջով արտաժամյա աշխատանքը իրար հաջորդող երկու օրվա ընթացքում չպետք է գերազանցի 4 ժամը, իսկ տարվա ընթացքում` 180 ժամը:
(պարբերությունն ուժը կորցրել է 24.06.10 ՀՕ-117-Ն)
2. Գործատուն պարտավոր է յուրաքանչյուր աշխատողի կատարած արտաժամյա աշխատաժամանակը ստույգ հաշվառել աշխատաժամանակի հաշվարկի տեղեկագրերում:
(146-րդ հոդվածը փոփ. 24.06.10 ՀՕ-117-Ն)
