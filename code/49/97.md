# Հոդված 97. Ալիմենտ պահող կազմակերպության վարչակազմի պարտականությունը
Ալիմենտ վճարելու վերաբերյալ համաձայնության կամ կատարողական թերթի հիման վրա ալիմենտ վճարելու պարտավոր անձի աշխատավայրի (կազմակերպության) վարչակազմը պարտավոր է յուրաքանչյուր ամիս ալիմենտ պահել այդ անձի աշխատավարձից և (կամ) այլ եկամտից և վճարել կամ դրանք փոխանցել ալիմենտ ստացողին՝ ալիմենտ վճարելու պարտավոր անձին աշխատավարձի և (կամ) այլ եկամտի վճարման պահից ոչ ուշ՝ եռօրյա ժամկետում։
