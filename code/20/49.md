# Հոդված 49. Ընդերքի պետական սեփականության իրավունքի խախտումը
Ընդերքից ինքնագլուխ օգտվելը, ընդերքի պետական սեփականության իրավունքն ուղղակի կամ քողարկված ձևով խախտող գործարքներ կատարելը`
