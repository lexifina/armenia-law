# Հոդված 190. Քաղաքացիների կողմից ողորկափող որսորդական հրազեն ձեռք բերելու, պահելու, ուրիշին տալու կամ վաճառելու կարգը խախտելը
Առանց ոստիկանության թույլտվության քաղաքացիների կողմից ողորկափող որսորդական հրազեն ձեռք բերելը, պահելը, ուրիշ անձանց տալը կամ վաճառելը`
առաջացնում է տուգանքի նշանակում սահմանված նվազագույն աշխատավարձի երեսնապատիկի չափով` զենքի բռնագրավմամբ կամ առանց դրա:
Նույն գործողությունները այն անձի կողմից կատարելը, որը սույն հոդվածի առաջին մասով նախատեսված խախտումներից որևէ մեկի համար մեկ տարվա ընթացքում ենթարկվել է վարչական տույժի`
առաջացնում է տուգանքի նշանակում սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով` զենքի բռնագրավմամբ:
