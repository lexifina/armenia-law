# Հոդված 228. Արտոնագրային իրավունքը խախտելը
1. Արտոնագրային իրավունքի օբյեկտն ապօրինի օգտագործելը կամ մինչև այդ իրավունքի պաշտոնական ճանաչումը դրա էության վերաբերյալ առանց հայտատուի համաձայնության տեղեկություն տարածելը կամ դրա հեղինակությունը յուրացնելը, եթե դա խոշոր չափերի գույքային վնաս է պատճառել՝
պատժվում է տուգանքով` առավելագույնը քսանապատիկի չափով, կամ հանրային աշխատանքներով` ութսունից հարյուր հիսուն ժամ տևողությամբ, կամ որոշակի պաշտոններ զբաղեցնելու կամ որոշակի գործունեությամբ զբաղվելու իրավունքից զրկելով` առավելագույնը երեք տարի ժամկետով, կամ ազատության սահմանափակմամբ` առավելագույնը երկու տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ` առավելագույնը երկու տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը՝
1) առանձնապես խոշոր չափերի գույքային վնաս է պատճառել,
2) կատարվել է տեղեկատվական կամ հաղորդակցական տեխնոլոգիաներն օգտագործելով,
3) կատարվել է համահեղինակության հարկադրելով,
4) կատարվել է իշխանական կամ ծառայողական լիազորությունները կամ դրանցով պայմանավորված ազդեցությունն օգտագործելով կամ
5) կատարվել է մի խումբ անձանց կողմից նախնական համաձայնությամբ`
