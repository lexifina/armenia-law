# Հոդված 1017. Ապահովագրական դեպքը վրա հասնելու մասին ապահովագրողին ծանուցելը
1. Գույքային ապահովագրության պայմանագրով` ապահովագրվողը, ապահովագրական դեպքի վրա հասնելն իրեն հայտնի դառնալուց հետո, պարտավոր է այդ մասին անհապաղ տեղեկացնել ապահովագրողին կամ նրա ներկայացուցչին: Եթե պայմանագրով նախատեսված է ծանուցման ժամկետ և (կամ) եղանակ, դա պետք է արվի սահմանված ժամկետում ու պայմանագրում նշված եղանակով:
Նման պարտականություն կրում է նաև շահառուն, որը տեղյակ է իր օգտին ապահովագրական պայմանագրի կնքված լինելու մասին, եթե նա մտադիր է օգտվել ապահովագրական հատուցում ստանալու իրավունքից:
2.
