# Հոդված 11. Ընտրողների ցուցակներին ներկայացվող պահանջները
1. Ընտրողների ցուցակներում նշվում են քաղաքացիների ազգանունը, անունը, հայրանունը, ծննդյան տարին, ամիսը, ամսաթիվը և հասցեն:
2. Ընտրողների ցուցակները կազմվում են ըստ քաղաքացիների հաշվառման հասցեների: Հաշվառում չունեցող քաղաքացիներին ընտրողների ցուցակներում ընդգրկելու կարգը սահմանում է կենտրոնական ընտրական հանձնաժողովը:
3. Ընտրողների ցուցակները կազմվում են մատյանի ձևով և էջակալվում մինչև 1000 ընտրողի քանակով: Ընտրողների ցուցակի յուրաքանչյուր էջն ստորագրում և կնքում է համայնքի ղեկավարը և ՆԳՆ համապատասխան անձնագրային մարմինները:
4. Անձը հաստատող փաստաթղթում հայրանվան բացակայությունը (մյուս տվյալների համապատասխանության դեպքում) ընտրական որևէ գործընթացի մասնակցության արգելք չէ:
(11-րդ հոդվածը լրաց., փոփ. 03.07.02 ՀՕ-406-Ն)
