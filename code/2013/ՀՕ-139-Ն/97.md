# Հոդված 97. Գործի վարույթը կարճելու կարգը և հետևանքները
1. Գործի վարույթը կարճելու մասին դատարանը կայացնում է որոշում, որով լուծվում են նաև դատավարության մասնակիցների միջև դատական ծախսերի բաշխման հարցերը։
2.
