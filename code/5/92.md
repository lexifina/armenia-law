# Հոդված 92. Գույքի մանր հափշտակում
Գույքի մանր հափշտակումը գողության (բացի անձնական գույքից), յուրացման, վատնման, պաշտոնեական դիրքի չարաշահման կամ խարդախության միջոցով, որ կատարվել է նույնպիսի խախտումների համար վարչական տույժ նշանակելուց հետո մեկ տարվա ընթացքում կամ սույն հոդվածով նախկինում դատապարտված անձի կողմից`
