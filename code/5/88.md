# Հոդված 88. Գույքի հափշտակումը ավազակության միջոցով
Գույքին տիրանալու նպատակով կատարված հարձակումը, որ զուգորդվել է հարձակման ենթարկված անձի կյանքի կամ առողջության համար վտանգավոր բռնության հետ կամ այդպիսի բռնություն գործադրելու սպառնալիքի հետ (ավազակություն)`
պատժվում է ազատազրկմամբ չորսից մինչև տասը տարի ժամանակով:
Ավազակությունը, որ կատարվել է մի խումբ անձանց կողմից նախապես համաձայնության գալով կամ շինություն, պահեստարան կամ բնակարան մուտք գործելով կամ առանձնապես վտանգավոր ռեցեդիվիստի կողմից, կամ զուգորդվել է ծանր մարմնական վնասվածքներ հասցնելու հետ կամ կատարվել է նախկինում ավազակություն կամ բանդիտիզմ կատարած անձի կողմից կամ հրազենի կամ որպես զենք օգտագործվող այլ առարկաների գործադրմամբ`
պատժվում է ազատազրկմամբ ութից մինչև տասնհինգ տարի ժամանակով` անձնական գույքի բռնագրավմամբ:
(29.10.69, 29.12.82, 28.08.85, 11.05.92 խմբագրությամբ)
