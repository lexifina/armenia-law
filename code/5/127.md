# Հոդված 127. Երեխային փոխելը
Երեխային փոխելը, որը կատարվել է շահադիտական կամ այլ ստոր դրդումներով`

Նույն արարքը, որ կատարվել է առանց սույն հոդվածի առաջին մասում նշված հատկանիշների`
