# Հոդված 99. Հոգեբույժի մոտ արտահիվանդանոցային հսկողությունը և հարկադիր բուժումը
Հոգեբույժի մոտ արտահիվանդանոցային հսկողություն և հարկադիր բուժում կարող է նշանակվել, եթե անձն իր հոգեկան վիճակով հոգեբուժական հիվանդանոցում տեղավորման կարիք չունի:
(99-րդ հոդվածը` 18.06.20 ՀՕ-347-Ն օրենքի 2-րդ հոդվածի փոփոխություններով ուժի մեջ կմտնի 06.10.2020 թվականին:)
