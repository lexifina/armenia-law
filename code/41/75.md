# Հոդված 75. ՀՏԿ-ների հաշվառումը
ՀՏԿ-ները հաշվառվում են պետական ջրային կադաստրում:
ՀՏԿ-ների և դրանց օգտագործման պայմանների քանակական և որակական տվյալները մուտքագրվում են Ջրային համակարգերի կառավարման մարմնում:
(75-րդ հոդվածը 02.03.18 ՀՕ-126-Ն օրենքի 9-րդ հոդվածի փոփոխությամբ ուժի մեջ կմտնի 01.01.2020 թվականին:)
