# Հոդված 187. Պետական տուրք
Քաղաքացիական կացության ակտերի գրանցման մարմիններում ծնունդը, մահը, որդեգրումը, հայրության որոշումը գրանցվում են, ինչպես նաև այդ ակտերի գրանցման մասին սկզբնական վկայականներ են տրվում, հայրությունը որոշելու կապակցությամբ ծննդյան ակտերում ուղղումներ և լրացումներ են մտցվում ԽՍՀ Միությանօրենսդրությանը համապատասխան, առանց պետական տուրք գանձելու:
Աուսնադրությունները, ամուսնալուծությունները, անունների, հայրանունների և ազգանունների փոփոխումը գրանցելու համար, ակտային գրանցումները վերականգնելու և ուղղելու ու քաղաքացիական կացության ակտերի գրանցման մասին քաղաքացիներին կրկնակի վկայականներ տալու համար պետական տուրք է գանձվում ԽՍՀՄնախարարների խորհրդի կողմից սահմանված չափերով:
