# Հոդված 126. Խնամակալական պարտականությունները չարաշահելը
Խնամակալությունը շահադիտական նպատակներով ի վնաս խնամարկյալի օգտագործելը (բնակելի տարածության զբաղեցում, գույքի օգտագործում և այլն), ինչպես նաև խնամարկալային առանց հսկողության և առանց անհրաժեշտ նյութական օգնության թողնելը`
պատժվում է ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով կամ տուգանքով մինչև երեք հարյուր դրամ:
(29.10.69, 29.12.82 խմբագրությամբ)
