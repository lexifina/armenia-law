# Հոդված 38. Անչափահաս երեխաներ չունեցող ամուսինների ամուսնալուծությունը փոխադարձ համաձայնությամբ
Անչափահաս երեխաներ չունեցող ամուսինների միջև ամուսնալուծվելու վերաբերյալ փոխադարձ համաձայնություն լինելու դեպքում նրանց ամուսնալուծությունը կատարվում է քաղաքացիական կացության ակտերի գրանցման մարմիններում: Ապահարզանը ձևակերպվում և ամուսիններին ամուսնալուծության վերաբերյալ վկայական է տրվում ապահարզանի մասին դիմում տալու օրվանից երեք ամիս անցնելուց հետո: ամուսնալուծությունը գրանցելու համար պետական տուրք է գանձվում հարյուր դրամի չափով: Կարիքավոր անաշխատունակ ամուսնուն ապրուստի միջոցի հայթայթման կամ ընդհանուր համատեղ սեփականություն հանդիսացող գույքի բաժանման վերաբերյալ ամուսինների միջև վեճ լինելու դեպքում ամուսինները կամ նրանցից մեկը իրավասու են ամուսնալուծության հայցով դիմելու դատարան:
(29.05.85 խմբագրությամբ)
