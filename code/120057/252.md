# Հոդված 252. Անձի հոգեկան վիճակը պարզելու համար փորձաքննության նշանակումը
1. Առաջին ատյանի դատարանը քաղաքացու հոգեկան խանգարման վերաբերյալ հիմնավոր կասկածների առկայության դեպքում քաղաքացուն անգործունակ ճանաչելու հիմքերի առկայությունը պարզելու նպատակով նշանակում է դատահոգեբուժական փորձաքննություն:
2. Քաղաքացին իրավունք ունի դատահոգեբուժական փորձաքննությանը ներկայանալու իր ներկայացուցչի հետ:
3. Դատահոգեբուժական փորձաքննության անցկացումից անձի ակնհայտ խուսափելու դեպքում, որի վերաբերյալ անգործունակ ճանաչելու մասին դիմում է ներկայացվել, առաջին ատյանի դատարանը որոշում է կայացնում անձին հարկադիր կարգով դատահոգեբուժական փորձաքննության ուղարկելու մասին և դրա հարկադիր կատարման դիմումը անհապաղ ուղարկում է հարկադիր կատարման:
4. Որոշումը կատարվում է անհապաղ՝ «Կատարողական վարույթի մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով:
(252-րդ հոդվածը փոփ. 11.04.24 ՀՕ-193-Ն)
(11.04.24 ՀՕ-193-Ն օրենքն ունի անցումային դրույթ)
