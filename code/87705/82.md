# Հոդված 82. Մի քանի հայցերով գործերի միացումը և առանձնացումը
1. Վարչական դատարանն իրավունք ունի գործի քննության յուրաքանչյուր փուլում մեկ վարույթում միացնելու միևնույն առարկային վերաբերող մի քանի գործ։
2. Վարչական դատարանն իրավունք ունի մեկ կամ մի քանի միացված պահանջներ առանձնացնելու առանձին վարույթներում։
