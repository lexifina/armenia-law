# Հոդված 236. ԴԱՏԱԿԱՆ ՔՆՆՈՒԹՅԱՆ ԱՆՄԻՋԱԿԱՆՈՒԹՅՈՒՆԸ, ԲԱՆԱՎՈՐՈՒԹՅՈՒՆԸ և ԱՆԸՆԴՀԱՏՈՒԹՅՈՒՆԸ
