# Հոդված 183. Նախաքննության կատարումը քննչական խմբի կողմից
1. Վարույթի բարդության կամ դրա ծավալի մեծության դեպքում նախաքննության կատարումը կարող է առանձին որոշմամբ հանձնարարվել մի քանի քննիչի: Որոշման մեջ նշվում են խմբի ղեկավար քննիչը և մյուս բոլոր քննիչները, որոնց հանձնարարվում է նախաքննության կատարումը:
