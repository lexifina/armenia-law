# Հոդված 1148. Գյուտի, օգտակար մոդելի, արդյունաբերական նմուշի համահեղինակները
1. Գյուտի, օգտակար մոդելի, արդյունաբերական նմուշի համահեղինակների փոխհարաբերությունները սահմանվում են նրանց համաձայնությամբ:
2. Գյուտի, օգտակար մոդելի, արդյունաբերական նմուշի ստեղծմանը ցուցաբերված ոչ ստեղծագործական բնույթի աջակցությունը (տեխնիկական կամ կազմակերպչական օգնություն, իրավունքների ձևակերպմանն օժանդակել և այլն) չի հանգեցնում համահեղինակության:
(հոդվածը 03.03.21 ՀՕ-111-Ն օրենքի փոփոխությամբ ուժի մեջ կմտնի 01.07.2021 թվականին)
