# Հոդված 274. Թմրամիջոցներ կամ հոգեմետ նյութեր գործածելու համար որջեր կազմակերպելը կամ պահելը
(Վերնագիրը փոփ. 26.05.08 ՀՕ-76-Ն)
1. Թմրամիջոցներ կամ հոգեմետ նյութեր գործածելու համար որջեր կազմակերպելը կամ պահելը՝
պատժվում է ազատազրկմամբ՝ առավելագույնը չորս տարի ժամկետով:
2. Նույն արարքները, որոնք կատարվել են՝
1) կազմակերպված խմբի կողմից,
1.1) (1.1 կետն ուժը կորցրել է 23.05.11 ՀՕ-143-Ն)
2) պաշտոնեական դիրքն օգտագործելով,
3) ուսումնադաստիարակչական հաստատություններում՝
պատժվում են ազատազրկմամբ՝ երեքից յոթ տարի ժամկետով:
(274-րդ հոդվածը փոփ., լրաց. 26.05.08 ՀՕ-76-Ն, փոփ. 23.05.11 ՀՕ-143-Ն)
