# Հոդված 88.1. Առանց համապատասխան թույլտվության ֆիզիկական կամ իրավաբանական անձանց կողմից անազատ և կիսաազատ պայմաններում վայրի կենդանիներ, այդ թվում` Հայաստանի Հանրապետության կենդանիների Կարմիր գրքում գրանցված կենդանիներ պահելը կամ դրանց հաշվառման տվյալները լիազոր մարմնին չտրամադրելը
(հոդվածը 23.03.22 ՀՕ-75-Ն օրենքի լրացմամբ ուժի մեջ կմտնի «Կենդանական աշխարհի մասին» օրենքի 6-րդ հոդվածի 1-ին մասի «բ1» և «գ1» կետերով սահմանված կարգի ընդունումից հետո)
