# Հոդված 77. Գրավոր ապացույցի հետազոտումը
1. Գրավոր ապացույցը հետազոտվում է դատական նիստում: Անհրաժեշտության դեպքում գրավոր ապացույցը կարող է հետազոտվել տեխնիկական միջոցների կիրառմամբ:
2. Գործին մասնակցող անձինք կարող են դիրքորոշում հայտնել կամ միմյանց հարցեր ուղղել այդ ապացույցի վերաբերյալ։
3. Անհրաժեշտության դեպքում գրավոր ապացույցները կարող են տրամադրվել նաև վկաներին։
