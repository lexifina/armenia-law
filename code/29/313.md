# Հոդված 313. Խաբեության, բռնության, սպառնալիքի ազդեցության ներքո, մեկ կողմի ներկայացուցչի մյուս կողմի հետ չարամիտ համաձայնությամբ կամ ծանր հանգամանքների բերումով կնքված գործարքի անվավերությունը
