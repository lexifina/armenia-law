# Հոդված 3323. Փաստաբանի կամ նոտարի լիազորությունների իրականացմանը խոչընդոտելը կամ, կապված նրա լիազորությունների իրականացման հետ, սպառնալը
1. Պաշտոնատար անձի կողմից փաստաբանի կամ նոտարի լիազորությունների իրականացմանը խոչընդոտելը`
պատժվում է տուգանքով` նվազագույն աշխատավարձի երկուհարյուրապատիկից չորսհարյուրապատիկի չափով, կամ կալանքով` մեկից երեք ամիս ժամկետով:
2. Փաստաբանի կամ նոտարի նկատմամբ սպանության, առողջությանը վնաս պատճառելու, գույքը ոչնչացնելու կամ վնասելու սպառնալիքը` կապված նրա լիազորությունների իրականացման հետ`
պատժվում է տուգանքով` նվազագույն աշխատավարձի երկուհարյուրապատիկից հինգհարյուրապատիկի չափով, կամ կալանքով` երկուսից երեք ամիս ժամկետով:
