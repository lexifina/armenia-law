# Հոդված 118. Ապրանքների վերամշակման թույլտվության մեջ փոփոխություններ (լրացումներ) կատարելը
1. Ապրանքների վերամշակման թույլտվության մեջ փոփոխություններ (լրացումներ) կատարելու անհրաժեշտություն առաջանալիս մաքսային մարմինների տրամադրած թույլտվության մեջ կարող են կատարվել փոփոխություններ (լրացումներ) վերամշակման թույլտվությունն ստացած անձի կողմից վերամշակման թույլտվությունը տրամադրած մաքսային մարմին էլեկտրոնային եղանակով կամ թղթային կրիչով դիմում ներկայացնելու միջոցով:
2. Մաքսային մարմինը երեք աշխատանքային օրվա ընթացքում ուսումնասիրում է անձի կողմից սույն հոդվածի 1-ին մասին համապատասխան առաջարկվող փոփոխությունները (լրացումները) և համաձայնության դեպքում կատարում է փոփոխություններ (լրացումներ) վերամշակման թույլտվության մեջ:
3. Լրացուցիչ տեղեկատվության կամ հարցման անհրաժեշտության դեպքում սույն մասով սահմանված ժամկետը կասեցվում է այդ տեղեկատվության կամ հարցման պատասխանն ստանալու ժամկետով:
4. Վերամշակման թույլտվության մեջ փոփոխություններ (լրացումներ) կատարելը մերժվում է սույն օրենքի 117-րդ հոդվածի 8-րդ մասով սահմանված հիմքերի առկայության դեպքում, որի մասին մաքսային մարմինը էլեկտրոնային եղանակով կամ թղթային կրիչով ծանուցում է անձին՝ նշելով մերժման հիմքերը:
5. Վերամշակման թույլտվության մեջ փոփոխություններ (լրացումներ) կատարելու համար անձի կողմից ներկայացվող դիմումի ձևը, ինչպես նաև այն էլեկտրոնային եղանակով ներկայացնելիս կառուցվածքն ու ձևաչափը սահմանում է Կոմիտեն:
