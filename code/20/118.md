# Հոդված 118. Օդային տրանսպորտով վտանգավոր նյութեր և առարկաներ փոխադրելու կանոնները խախտելը
Օդային տրանսպորտով վտանգավոր նյութեր կամ առարկաներ փոխադրելու կանոնները խախտելը`
առաջացնում է տուգանքի նշանակում քաղաքացիների նկատմամբ` սահմանված նվազագույն աշխատավարձի տասը տոկոսից մինչև երեսուն տոկոսի չափով` նշված նյութերը և առարկաները հատուցմամբ վերցնելով կամ բռնագրավելով կամ առանց դրանց, և պաշտոնատար անձանց նկատմամբ` սահմանված նվազագույն աշխատավարձի քսան տոկոսից մինչև հիսուն տոկոսի չափով:
(118-րդ հոդվածը խմբ. 02.09.93 ՀՕ-79)
