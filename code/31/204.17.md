# Հոդված 204¹⁷. Բողոքի քննության կարգը
1. Դատարանը դատական նիստում լսում է նոր երևան եկած հանգամանքների վերաբերյալ բողոք ներկայացրած անձի հիմնավորումները և պահանջը, ինչպես նաև գործին մասնակցող անձանց դիրքորոշումը դատական ակտի վերանայման կապակցությամբ:
2. Դատական նիստի ժամանակի և վայրի մասին պատշաճ ձևով ծանուցված բողոք ներկայացրած անձի կամ գործին մասնակցող անձանց չներկայանալն արգելք չէ գործի քննության համար:
