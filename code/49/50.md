# Հոդված 50. Ամուսնության մեջ չգտնվող անչափահաս ծնողների իրավունքները
1. Ամուսնության մեջ չգտնվող անչափահաս ծնողներն ունեն իրենց երեխայի հետ համատեղ ապրելու և նրա դաստիարակությանը մասնակցելու իրավունքներ։
