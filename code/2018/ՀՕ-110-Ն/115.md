# Հոդված 115. Դատավարական ժամկետների հաշվարկը
1. Դատավարական ժամկետները հաշվարկվում են տարիներով, ամիսներով, շաբաթներով և օրերով: Օրերով հաշվարկվող ժամկետներում չեն ներառվում օրենսդրությամբ նախատեսված ոչ աշխատանքային օրերը:
2. Տարիներով, ամիսներով, շաբաթներով կամ օրերով հաշվարկվող դատավարական ժամկետների ընթացքն սկսվում է այն օրացուցային տարվա, ամսվա, շաբաթվա, ամսաթվի կամ անխուսափելիորեն վրա հասած իրադարձության հաջորդ օրվանից, որով որոշված է դրա ժամկետի սկիզբը:
3. Առանձին դատավարական գործողությունների կատարման ժամկետները որոշվում են օրացուցային տարով, ամսով, շաբաթով, ամսաթվով կամ ժամանակահատվածով, որի ընթացքում գործողությունը կարող է կատարվել:
