# Հոդված 169.30. Կանխամտածված կեղծ գովազդը
1. Գովազդատուի, գովազդ արտադրողի կամ գովազդակրի կողմից սպառողին հումքի, ապրանքի, մատուցվող ծառայության որակի, գնի կամ այլ առանձնահատկության վերաբերյալ մոլորության մեջ գցելը, եթե դրա հետևանքով անձի կամ կազմակերպության իրավունքներին, ազատություններին կամ օրինական շահերին կամ հասարակության կամ պետության օրինական շահերին պատճառվել է մանր չափերի գույքային վնաս՝
առաջացնում է տուգանքի նշանակում՝ սահմանված նվազագույն աշխատավարձի հիսնապատիկից հարյուրապատիկի չափով։
2. Սույն հոդվածի իմաստով՝ մանր չափ է համարվում 500.000 Հայաստանի Հանրապետության դրամը չգերազանցող գումարը (արժեքը)։
(169.30-րդ հոդվածը լրաց. 09.06.22 ՀՕ-155-Ն)
