# Հոդված 324. Կողմերի բացման խոսքը
1. Մինչև ապացույցների հետազոտումն սկսելը բացման խոսքով հանդես են գալիս նախ հանրային մեղադրողը, իսկ այնուհետև, իր ցանկությամբ, պաշտպանը կամ պաշտպանությունն ինքնուրույն իրականացնող մեղադրյալը:
2. Հանրային մեղադրողը բացման խոսքում ներկայացնում է մեղադրանքի փաստական հիմքը, ինչպես նաև մեղադրյալին վերագրվող արարքի իրավական գնահատականը:
3. Պաշտպանության կողմի բացման խոսքում ներկայացվում է մեղադրանքի վերաբերյալ դիրքորոշումը: Նախագահողն իրավասու է մեղադրյալի դիրքորոշումը ճշտող հարցեր տալու:
4. Բացման խոսքերը ներկայացնելուց անմիջապես հետո դատարանն անցնում է ապացույցների հետազոտմանը:
