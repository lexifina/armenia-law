# Հոդված 281. Դատական ակտերի օրինական ուժի մեջ մտնելը
1. Առաջին ատյանի դատարանի` եզրափակիչ դատական ակտն oրինական ուժի մեջ է մտնում վերաքննության կարգով բողոքարկման ժամկետն անցնելուց հետո, եթե այն բողոքարկված չի եղել: Առաջին ատյանի դատարանի այլ դատական ակտերն oրինական ուժի մեջ են մտնում հրապարակման պահից:
