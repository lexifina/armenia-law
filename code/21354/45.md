# Հոդված 45. Անտառների կամ անտառային հողերի օգտագործումը
Սույն օրենսգրքի 34-րդ հոդվածով նախատեսված դեպքերում անտառօգտագործումն իրականացվում է անտառօգտագործման պայմանագրի և անտառահատման տոմսի կամ անտառային տոմսի հիման վրա:
Անտառահատման և անտառային տոմսերն անտառօգտագործողին տալիս են անտառային պաշարների կամ անտառների կամ անտառային հողերի օգտագործման իրավունք պետական և համայնքային անտառներում:
Անտառահատման տոմսը ներառում է մթերվող բնափայտի և երկրորդական անտառանյութի քանակական և որակական բնութագրերը, դրանց արժեքը, աշխատանքների կատարման ժամկետները, անտառավերականգնման և հատատեղերի մաքրման աշխատանքների պայմանները:
Անտառային տոմսը ներառում է կողմնակի անտառօգտագործման տեսակը, տարածքը, ծավալները, ժամկետը, արժեքը և պայմանները:
Անտառահատման կամ անտառային տոմսերը տալիս է անտառային տնտեսություն վարող կազմակերպությունը:
Անտառահատման տոմսը և անտառային տոմսը հատուկ հաշվառման ենթակա փաստաթղթեր են։
(45-րդ հոդվածը խմբ. 25.05.22 ՀՕ-141-Ն)
