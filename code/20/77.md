# Հոդված 77. Անտառներում սահմանազատող նշանները, ցուցանակները և դիտողական ագիտացիայի մյուս առարկաները ոչնչացնելը կամ վնասելը
Անտառներում սահմանազատող նշանները, ցուցանակները և դիտողական ագիտացիայի մյուս առարկաները ոչնչացնելը կամ վնասելը`
