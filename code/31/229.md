# Հոդված 229. Վճռաբեկ բողոք բերելու կարգը
1. Բողոք բերելու հիմքերի առկայության դեպքում սույն օրենսգրքի 223 հոդվածում նշված անձինք բերում են վճռաբեկ բողոք և պատշաճ ձևով ուղարկում են վճռաբեկ դատարան, իսկ բողոքի պատճենը` վճիռը կայացրած դատարան ու գործին մասնակցող անձանց:
2. Վճիռը կայացրած դատարանը բողոքի պատճենն ստանալու օրվանից անհապաղ պարտավոր է գործը պատշաճ ձևով ուղարկել վճռաբեկ դատարան:
(229-րդ հոդվածը լրաց., փոփ. 07.07.06 ՀՕ-153-Ն)
