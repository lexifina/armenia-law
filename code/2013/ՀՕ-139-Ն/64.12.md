# Հոդված 64.12. Գործի նյութերին ծանոթանալու և գործի նյութերի հասանելիության հետ կապված առանձնահատկությունները
1. Համակարգում առկա էլեկտրոնային գործի նյութերը (ներառյալ՝ դրանում կատարված փոփոխությունները և լրացումները) ամբողջ ծավալով պետք է հասանելի լինեն ոչ միայն գործը քննող դատավորին և նրա աշխատակազմին, այլև գործին մասնակցող անձանց և նրանց ներկայացուցիչներին:
2. Գործին մասնակցող անձի կամ ներկայացուցչի փոխարինման դեպքում էլեկտրոնային գործի նյութերի հասանելիությունը դադարում է փոխարինված անձի և ներկայացուցչի համար, միաժամանակ ապահովվում է հասանելիություն նոր ներգրավված գործին մասնակցող անձի և ներկայացուցչի համար:
3. Գործին մասնակցող նոր անձի ներգրավման դեպքում էլեկտրոնային գործի նյութերի հասանելիությունն ապահովվում է նաև նոր ներգրավված գործին մասնակցող անձի համար։
4. Գործին մասնակցող անձի՝ գործին մասնակցող անձանց կազմից դուրս գալու դեպքում տվյալ անձի հասանելիությունը էլեկտրոնային գործի նյութերին դադարեցվում է։
5. Գործին մասնակցող անձի ներկայացուցչի՝ վարույթից հեռացվելու դեպքում տվյալ ներկայացուցչի հասանելիությունը էլեկտրոնային գործի նյութերին դադարեցվում է։
6. Դատավարության մասնակից հանդիսացող վկայի, փորձագետի և թարգմանչի հասանելիության ծավալը գործի նյութերին որոշում է գործը քննող դատարանը Համակարգի միջոցով։
