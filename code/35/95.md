# Հոդված 95. Ընտրական համակարգը
1. Ազգային ժողովի ընտրություններ անցկացվում են համամասնական և մեծամասնական ընտրակարգերով:
2. 90 պատգամավոր ընտրվում է համամասնական ընտրակարգով, հանրապետության ամբողջ տարածքն ընդգրկող մեկ բազմամանդատ ընտրատարածքից` կուսակցությունների ընտրական ցուցակներով առաջադրված պատգամավորության թեկնածուների թվից:
3. 41 պատգամավոր ընտրվում է մեծամասնական ընտրակարգով` յուրաքանչյուր ընտրատարածքից մեկ պատգամավոր:
(95-րդ հոդվածը փոփ. 03.07.02 ՀՕ-406-Ն, 04.12.00 ՀՕ-115, 19.05.05 ՀՕ-101-Ն)
