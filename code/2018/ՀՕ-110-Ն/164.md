# Հոդված 164. Դիտողությունները պարզ թղթային արձանագրության վերաբերյալ
1. Դատավարության մասնակիցներն իրավունք ունեն ծանոթանալու պարզ թղթային եղանակով կազմված դատական նիստի արձանագրությանը և մինչև վճռի օրինական ուժի մեջ մտնելը դիտողություններ ներկայացնելու այն կազմելու լրիվության կամ ճշտության վերաբերյալ: Դատավարության մասնակիցներն իրավունք ունեն դատարանին ներկայացնելու իրենց կատարած դատական նիստի ձայնագրությունը, տեսագրությունը կամ սղագրությունը:
2. Արձանագրության վերաբերյալ դիտողություններն ուսումնասիրում է արձանագրությունը ստորագրած նախագահող դատավորը դրանք ներկայացնելու պահից երեք օրվա ընթացքում:
3. Արձանագրության վերաբերյալ դիտողություններն ընդունելու կամ մերժելու մասին դատարանը կայացնում է որոշում։
