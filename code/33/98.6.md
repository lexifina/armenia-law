# Հոդված 98⁶. Վերահսկողության տեխնիկական միջոցներ օգտագործելը և հեռախոսային կամ այլ հաղորդումները գաղտնալսելը
Քրեական վարույթն իրականացնող մարմինը պաշտպանվող անձի գրավոր դիմումի հիման վրա կամ նրա գրավոր համաձայնությամբ և սույն օրենսգրքով սահմանված կարգով իրականացնում է նրա հեռախոսային կամ այլ խոսակցությունների գաղտնալսում: Խոսակցությունների գաղտնալսման ընթացքում կարող է կիրառվել ձայնագրառում:
(98⁶ -րդ հոդվածը լրաց. 25.05.06 ՀՕ-91-Ն)
