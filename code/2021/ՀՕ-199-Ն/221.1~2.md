# Հոդված 221.1. Ազգային ժողովի ընտրությունների ժամանակ օրենքով սահմանված՝ նախընտրական քարոզչության ծախսերը նախընտրական հիմնադրամից չկատարելը կամ հանրաքվեի քարոզչության ծախսերը հանրաքվեի քարոզչության ֆինանսավորման հիմնադրամից չկատարելը կամ հայտարարագրման ենթակա տվյալները չհայտարարագրելը կամ հայտարարագիր չներկայացնելը
