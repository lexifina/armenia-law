# Հոդված 546. ԿՏԱԿԻ ՎԵՐԱՑՈՒՄԸ և ՓՈՓՈԽՈՒՄԸ
Կտակարարը ուզած ժամանակ իրավունք ունի վերացնելու կամ փոփոխելու իր կազմած կտակը, կազմելով նոր կտակ:
