# Հոդված 154. Բնակելի տներ, կցաշենքեր, ավտոտնակներ և այլ տնտեսական ու կենցաղային շինություններ ինքնակամ կառուցելը
Բնակելի շենքեր, կցաշենքեր, ավտոտնակներ և այլ տնտեսական ու կենցաղային շինություններ ինքնակամ կառուցելը`
