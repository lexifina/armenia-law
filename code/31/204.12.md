# Հոդված 204¹². Նոր երևան եկած հանգամանքներով դատական ակտի վերանայման վարույթ հարուցելու բողոքը
Նոր երևան եկած հանգամանքներով դատական ակտը վերանայելու բողոքը պետք է պարունակի`
1) բողոք ներկայացրած անձի անունը, ազգանունը (անվանումը).
2) այն դատարանի անվանումը, որին բողոքը հասցեագրվում է.
3) դատական ակտի կայացման տարին, ամիսը, ամսաթիվը, որը ենթակա է վերանայման.
4) դատական ակտի վերանայման համար հիմք դարձած նոր երևան եկած հանգամանքի շարադրանքը և հիմնավորումը, թե ինչու է այն հիմք դատական ակտի վերանայման համար.
5) բողոքով ներկայացվող պահանջը.
6) բողոքի պատճենը գործին մասնակցող անձանց ուղարկելու մասին ապացույցը.
7) վերանայվող դատական ակտը կասեցնելու վերաբերյալ միջնորդությունը.
8) բողոքին կցվող փաստաթղթերի (ապացույցների) ցանկը:
