# Հոդված 77. Դատապարտյալի` սննդամթերք և առաջին անհրաժեշտության առարկաներ ձեռք բերելը
1. Դատապարտյալն իր միջոցներով կարող է ամսվա ընթացքում ձեռք բերել սահմանված նվազագույն աշխատավարձի մինչև երեսնապատիկի չափով սնունդ և առաջին անհրաժեշտության առարկաներ, ինչպես նաև գրենական պիտույքներ, գրքեր, թերթեր, ամսագրեր և այլ գրականություն:
2. Սննդամթերք և առաջին անհրաժեշտության առարկաներ ձեռք բերելու կարգը, ինչպես նաև այն առարկաների ցանկը, որոնք արգելված է վաճառել դատապարտյալին, սահմանվում են ուղղիչ հիմնարկների ներքին կանոնակարգով։
