# Հոդված 993. Պարտադիր ապահովագրության մասին կանոնները խախտելու հետևանքները
1. Եթե անձին, հօգուտ որի օրենքով պետք է պարտադիր ապահովագրություն իրականացվի, հայտնի է դարձել, որ ապահովագրություն չի իրականացվել, նա իրավունք ունի դատական կարգով պահանջել, որ դա իրականացվի այն անձի կողմից, ում վրա դրված է ապահովագրության պարտականությունը:
