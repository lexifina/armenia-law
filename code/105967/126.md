# Հոդված 126. Ընտրվելու իրավունքը
1. Երևանի, Գյումրու և Վանաձորի ավագանու անդամ կարող են ընտրվել սույն օրենսգրքի 2-րդ հոդվածի համաձայն` տեղական ինքնակառավարման մարմինների ընտրության ժամանակ ընտրելու իրավունք ունեցող անձինք:
2.
