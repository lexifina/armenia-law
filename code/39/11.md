# Հոդված 11. ԲՆԱԿԱՎԱՅՐԻ ՍԱՀՄԱՆԱԳԾԵՐԸ
1. Բնակավայրի սահմանագծերը որոշվում են հաստատված քաղաքաշինական և հողաշինարարական փաստաթղթերի հիման վրա:
2. Բնակավայրի սահմաններում կարող են լինել հողային ֆոնդի կազմում առկա բոլոր հողերը:
3. Քաղաքաշինական նպատակներով համայնքի վարչական սահմաններում ընդգրկված հողերը օգտագործվում են գլխավոր հատակագծերով, քաղաքաշինական գոտիավորման նախագծերով, հողերի օգտագործման սխեմաներով սահմանված նպատակներով և փուլերով:
4. Հողամասերի ներառումը բնակավայրերի սահմանների մեջ չի հանգեցնում դրանց սեփականատերերի, օգտագործողների իրավունքների փոփոխման կամ դադարման:
5. Բնակավայրի սահմաններում ընդգրկված հողերի վրա տարածվում է քաղաքաշինական և հողաշինարարական փաստաթղթերով սահմանված իրավական ռեժիմը:
(11-րդ հոդվածը խմբ. 23.06.11 ՀՕ-228-Ն)
