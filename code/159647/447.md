# Հոդված 447. Անցումային դրույթներ՝ սույն Օրենսգրքի 48-րդ հոդվածի վերաբերյալ
Առաջիկայում վճարման ենթակա ներմուծման մաքսատուրքերի, հատուկ, հակագնագցման, փոխհատուցման տուրքերի հաշվին մուծվող դրամական միջոցները (փողը) կանխավճար համարելու հնարավորության մասով սույն Օրենսգրքի 48-րդ հոդվածի 1-ին կետի դրույթները կիրառվում են այն միջազգային պայմանագիրն ուժի մեջ մտնելու օրվանից, որով նախատեսվում է «Միության մասին» պայմանագրում փոփոխություններ կատարել ներմուծման մաքսատուրքերի, հատուկ, հակագնագցման, փոխհատուցման տուրքերի հաշվին կանխավճար հաշվանցելու հնարավորության մասով:
