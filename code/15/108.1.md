# Հոդված 108¹. Պայմանականորեն ազատազրկման դատապարտված և ազատազրկման վայրերից պայմանականորեն ազատված անձանց պատիժը կրելուց ազատելը հաշմանդամության պատճառով
Պարտադիր կարգով աշխատանքի ներգրավումով պայմանականորեն ազատազրկման դատապարտված կամ պարտադիր կարգով աշխատանքի ներգրավումով ազատազրկման վայրերից պայմանականորեն ազատված անձը, սահմանված կարգով առաջին կամ երկրորդ խմբի հաշմանդամ ճանաչվելու դեպքում, եթե նա հաշմանդամությունն ստացել է աշխատանքային խեղման կամ պրոֆեսիոնալ հիվանդության հետևանքով, դատարանի կողմից ժամկետից շուտ ազատվում է պատժի հետագա կրումից ԽՍՀ Միության օրենսդրությամբ և Հայաստանի Հանրապետության քրեական դատավարության օրենսգրքի 360¹ հոդվածով սահմանված կարգով:
Եթե սույն հոդվածի առաջին մասում նշված անձը առաջին կամ երկրորդ խմբի հաշմանդամություն է ստացել իր արտադրական գործունեության հետ չկապված պատճառներով, դատարանը կարող է այդ անձին կամ ժամկետից շուտ ազատել պատժի հետագա կրումից, կամ նրան ուղարկել ազատազրկում կրելու:
(ընդունվել է 28.04.77.)
