# Հոդված 118. Դատավարական ժամկետները երկարաձգելը
1. Դատարանը գործին մասնակցող անձի միջնորդությամբ կարող է երկարաձգել դատարանի սահմանած և չավարտված, իսկ օրենքով նախատեսված դեպքերում նաև օրենքով սահմանված և չավարտված դատավարական ժամկետները:
2. Դատավարական ժամկետները երկարաձգելու միջնորդության վերաբերյալ դատարանը կայացնում է որոշում: Միջնորդությունը բավարարելու մասին որոշում կայացնելու դեպքում դատարանը սահմանում է համապատասխան գործողությունը կատարելու նոր ժամկետ:
(118-րդ հոդվածը փոփ. 07.02.24 ՀՕ-82-Ն)
