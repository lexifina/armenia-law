# Հոդված 402. փոխանորդի պարտականությունները
փոխանորդը պարտավոր է`
1) փոխանորդյալի պահանջով նրան հաղորդել հանձնարարության կատարման ընթացքի վերաբերյալ բոլոր տեղեկությունները.
