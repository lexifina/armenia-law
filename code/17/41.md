# Հոդված 41. Աշխատանքից հեռացնելը
Աշխատավարձի վճարման դադարեցումով բանվորին կամ ծառայողին աշխատանքից (պաշտոնից) հեռացնել թույլատրվում է դրանում լիազորված մարմինների առաջարկությամբ միայն` ԽՍՀ Միության և Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում:
Հարբած վիճակում, թմրամիջոցներով կամ թունամիջոցներով արբեցած վիճակում աշխատանքի ներկայացած աշխատողին ձեռնարկության, հիմնարկի, կազմակերպության ադմինիստրացիան թույլ չի տալիս այդ օրը (հերթափոխում) աշխատել:
