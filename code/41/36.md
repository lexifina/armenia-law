# Հոդված 36. Ջրօգտագործման թույլտվության դադարեցումը
Եթե ջրօգտագործման թույլտվություն ունեցողը 3 տարի անընդմեջ չի օգտագործում թույլտվությամբ ստացած իր իրավունքն առանց որևէ օրինական հիմքերի, ապա նրա ջրօգտագործման թույլտվությունը համարվում է դադարեցված և ճանաչվում է առ ոչինչ:
Եթե ջրօգտագործման թույլտվություն ունեցող անձից պահանջվում է ունենալ լիցենզիա, սակայն անձը մեկ տարվա ընթացքում չի ստանում այն, ապա նրա ջրօգտագործման թույլտվությունը համարվում է առ ոչինչ:
