# Հոդված 156. Սպեկուլյացիա
Սպեկուլյացիա, այսինքն` շահ ստանալու նպատակով պետական առևտրի համակարգից այնպիսի ապրանքներ գնելն ու վերավաճառելը, որոնց համար պետության կողմից սահմանված են հաստատագրված գներ`
պատժվում է ազատազրկմամբ մինչև երկու տարի ժամանակով կամ տուգանքով հինգ հազար դրամից մինչև տասը հազար դրամ` սպեկուլյացիայի առարկաների բռնագրավմամբ:
Խոշոր չափերով կատարված սպեկուլյացիան`
պատժվում է ազատազրկմամբ երկուսից մինչև չորս տարի ժամանակով` սպեկուլյացիայի առարկաների բռնագրավմամբ:
Առանձնապես խոշոր չափերի սպեկուլյացիան`
պատժվում է ազատազրկմամբ չորսից մինչև վեց տարի ժամանակով` սպեկուլյացիայի առարկաների բռնագրավմամբ:
(29.12.82, 25.06.86, 11.05.92 խմբագրությամբ)
