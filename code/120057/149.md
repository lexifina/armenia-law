# Հոդված 149. Պահանջներից հրաժարվելը
1. Հայցվորն իրավունք ունի ամբողջությամբ կամ մասնակիորեն հրաժարվել իր պահանջներից մինչև առաջին ատյանի դատարանի կողմից դատաքննությունն ավարտելը։
2. Առաջին ատյանի դատարանը նախքան գործի վարույթը կարճելու մասին որոշում կայացնելը գործին մասնակցող անձանց բացատրում է պահանջից հրաժարվելու դատավարական հետևանքները:
3. Եթե հայցվորը մասնակիորեն հրաժարվել է իր պահանջից, ապա առաջին ատյանի դատարանը հրաժարված պահանջի մասով կարող է առանձնացնել առանձին վարույթ: Հրաժարված պահանջի վարույթով առաջին ատյանի դատարանը քննությունը հայտարարում է ավարտված և կայացնում է գործի վարույթը կարճելու մասին որոշում:
