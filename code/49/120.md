# Հոդված 120. Երեխային որդեգրելու համար խնամակալների (հոգաբարձուների), խնամատար ծնողների համաձայնությունը, որոնց ընտանիքներում գտնվում են առանց ծնողական խնամքի մնացած երեխաները
1. Խնամակալության (հոգաբարձության) տակ գտնվող երեխաներին որդեգրելու համար անհրաժեշտ է նրանց խնամակալների (հոգաբարձուների) գրավոր համաձայնությունը։
Խնամատար ընտանիքներում գտնվող երեխաներին որդեգրելու համար անհրաժեշտ է խնամատար ծնողների գրավոր համաձայնությունը։
2. Դատարանը կարող է, առանց սույն հոդվածի 1-ին մասում նշված անձանց համաձայնության, ելնելով երեխայի շահերից, վճիռ կայացնել նրան որդեգրելու մասին։
