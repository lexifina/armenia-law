# Հոդված 447. Ընդդատությունը
1. Իրավաբանական անձի վերաբերյալ վարույթն ընդդատյա է առաջին ատյանի ընդհանուր իրավասության այն դատարանին, որի դատական տարածքում է տվյալ իրավաբանական անձի գտնվելու վայրը:
2. Հայաստանի Հանրապետության տարածքից դուրս գրանցված իրավաբանական անձի վերաբերյալ վարույթն ընդդատյա է առաջին ատյանի ընդհանուր իրավասության այն դատարանին, որի դատական տարածքում կատարվել է ենթադրյալ հանցանքը:
3. Հայաստանի Հանրապետության տարածքից դուրս գրանցված իրավաբանական անձի վերաբերյալ վարույթը, եթե ենթադրյալ հանցագործությունը կատարվել է Հայաստանի Հանրապետության տարածքից դուրս, կամ դրա կատարման վայրը պարզել հնարավոր չի եղել, ընդդատյա է առաջին ատյանի ընդհանուր իրավասության այն դատարանին, որի դատական տարածքում վրա են հասել վտանգավոր հետևանքները:
