# Հոդված 5. Հայաստանի Հանրապետության քրեական օրենսգրքի ներգործությունը արտասահմանում կատարված արարքների նկատմամբ
Եթե արտասահմանում հանցագործություններ կատարած ՀՀ քաղաքացիները քրեական պատասխանատվության են կանչվել կամ դատի են տրվել Հայաստանի Հանրապետության տերիտորիայում, քրեական պատասխանատվության ենթակա են սույն օրենսգրքի համապատասխան հոդվածներով:
Նույն հիմունքներով պատասխանատվություն են կրում Հայաստանի Հանրապետության գտնվող և քաղաքացիություն չունեցող այն անձինք, ովքեր հանցագործություն են կատարել արտասահմանում:
Եթե հիշյալ անձինք իրենց կատարած հանցագործությունների համար պատիժ են կրել արտասահմանում, դատարանը կարող է նրանց նկատմամբ նշանակված պատիժը համապատասխանորեն մեղմացնել կամ հանցավորին իսպառ ազատել պատիժ կրելուց:
Արտասահմանում կատարած հանցագործությունների համար օտարերկրյա քաղաքացիները ՀՀ քրեական օրենքներով պատասխանատվության ենթակա են միջազգային պայմանագրերով նախատեսված դեպքերում:
(29.10.69, 29.12.82, 19.05.94 խմբագրությամբ)
