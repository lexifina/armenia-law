# Հոդված 258. Կոշտ գրավ
Կոշտ գրավ է համարվում այն գրավը, որի առարկան թողնվում է գրավատուի մոտ` գրավառուի փականքի տակ կամ գրավի մասին վկայող նշաններով, ինչպես նաև գրավատուի մոտ թողնված գրավի առարկան, որի նկատմամբ գրավի իրավունքը գրանցված է օրենքով սահմանված կարգով:
