# Հոդված 46. ՀՈՂԱՄԱՍՆ ՕԳՏԱԳՈՐԾՄԱՆ ՏՐԱՄԱԴՐԵԼԸ
Հողամասը սեփականատերն օգտագործման է տրամադրում կառուցապատման, անհատույց օգտագործման կամ վարձակալության իրավունքով:
Արգելվում է պետական կամ համայնքային սեփականություն հանդիսացող հողամասերը կառուցապատման նպատակով վարձակալության կամ անհատույց օգտագործման իրավունքով տրամադրելը, բացառությամբ սույն օրենսգրքի 63.1-ին հոդվածով սահմանված կամ «Պետություն-մասնավոր գործընկերության մասին» Հայաստանի Հանրապետության օրենքով նախատեսված ՊՄԳ ծրագրով (ծրագրերով) սահմանված դեպքերի:
