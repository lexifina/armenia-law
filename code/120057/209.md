# Հոդված 209. Դատարանի վճիռը
1. Գործի քննության արդյունքներով դատարանը կայացնում է վճիռ:
2. Հայցը բավարարելու վերաբերյալ վճռով դատարանը նաև բաշխում է երեխայի վերադարձն ապահովելու հետ կապված առկա և կատարվելիք ծախսերը:
3. Դատարանի վճիռն օրինական ուժի մեջ է մտնում հրապարակման օրվանից յոթ օր հետո, եթե դրա դեմ վերաքննիչ բողոք չի ներկայացվում:
4. Հայցը բավարարելու վերաբերյալ օրինական ուժի մեջ մտած վճիռը հիմք է օրենքով սահմանված կարգով Կենտրոնական մարմնի կողմից երեխայի վերադարձն ապահովելու գործընթացը կազմակերպելու համար:
