# Հոդված 247. Արտաքին դիտումը
1. Արտաքին դիտումը, առանց բնակարանի անձեռնմխելիության սահմանափակման, հատուկ կամ այլ տեխնիկական միջոցների կիրառմամբ անձանց հետևելը կամ առանձին դեպքերի և իրադարձությունների ընթացքը վերահսկելն է բաց տարածությունում, հանրային վայրում կամ բնակարան չհանդիսացող փակ տարածությունում տեսաձայնագրման, տեսագրման, ձայնագրման կամ լուսանկարման միջոցով էլեկտրոնային կամ այլ կրիչների վրա դիտման արդյունքների ամրագրմամբ:
