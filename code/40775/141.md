# Հոդված 141. Նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու վերաբերյալ գործերով վարչական դատարանի դատական ակտերի բողոքարկման հիմքը
1. Նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու վերաբերյալ գործերով վարչական դատարանի դատական ակտերը կարող են բողոքարկվել վերաքննիչ դատարան, իսկ վերաքննիչ դատարանի դատական ակտերը` վճռաբեկ դատարան, միայն նյութական իրավունքի խախտման հիմքով։
2. Վերադաս դատարանը նորմատիվ իրավական ակտերի վիճարկման վերաբերյալ գործերով փոփոխում է ստորադաս դատարանի դատական ակտը կամ մերժում բողոքը:
(141-րդ հոդվածը խմբ., փոփ. 28.10.10 ՀՕ-135-Ն)
(141-րդ հոդվածի 1-ին մասն այն մասով, որով արգելափակվում է անձի իրավունքը` դատավարական իրավունքի նորմի խախտման հիմքով բողոքարկելու նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու վերաբերյալ գործերով վարչական դատարանի դատական ակտերը, ճանաչվել է ՀՀ Սահմանադրության 3-րդ, 18-րդ և 19-րդ հոդվածներին հակասող և անվավեր 04.02.2011 ՍԴՈ-936 որոշմամբ)
