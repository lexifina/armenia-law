# Հոդված 300. Վարչական տույժ նշանակելու մասին որոշման կատարման հետաձգումը
Այն հանգամանքների առկայության դեպքում, որոնց հետևանքով տուգանքի (բացառությամբ վարչական իրավախախտում կատարելու տեղում գանձվող տուգանքի) ձևով վարչական տույժ նշանակելու մասին որոշման անհապաղ կատարումը հնարավոր չէ, որոշում կայացրած մարմինը (պաշտոնատար անձը) որոշման կատարումը կարող է հետաձգել մինչև մեկ ամիս ժամանակով:
(300-րդ հոդվածը փոփ. 16.12.05 ՀՕ-32-Ն)
