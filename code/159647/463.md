# Հոդված 463. Անցումային դրույթներ՝ սույն Օրենսգրքի 385-րդ հոդվածի կիրառման վերաբերյալ
Անկախ սույն Օրենսգրքի 385-րդ հոդվածի 3-րդ կետի դրույթներից՝ մտավոր սեփականության այնպիսի օբյեկտներ, ինչպիսիք են ապրանքների ծագման տեղանունները, ընդգրկվում են Անդամ պետությունների մտավոր սեփականության օբյեկտների միասնական մաքսային ռեեստրում սույն Օրենսգրքի 384-րդ հոդվածի 5-րդ կետով նախատեսված՝ Հանձնաժողովի այն որոշումն ուժի մեջ մտնելուց հետո, որով սահմանվում է մաքսային մարմինների կողմից մտավոր սեփականության օբյեկտների նկատմամբ իրավունքների պաշտպանությանն ուղղված միջոցների ընդունման կարգը՝ մտավոր սեփականության այնպիսի օբյեկտներ պարունակող ապրանքների նկատմամբ, ինչպիսիք են ապրանքների ծագման տեղանունները:
