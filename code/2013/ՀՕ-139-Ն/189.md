# Հոդված 189. Դիմումի պատասխանը
1. Դատավարության մասնակիցը դիմումը վարույթ ընդունելու մասին դատարանի որոշումն ստանալուց հետո՝ տասնօրյա ժամկետում, իրավունք ունի պատասխան ուղարկելու դատարան և դատավարության այլ մասնակիցների։
2. Դիմումի պատասխանը ներկայացվում է գրավոր, որում նշվում են`
1) դատարանի անվանումը, որին հասցեագրվում է պատասխանը.
2) պատասխանը ներկայացրած անձի անունը (անվանումը).
3) դիմումի վերաբերյալ դիրքորոշումը։
3. Դիմումի պատասխանն ստորագրում է պատասխանը ներկայացրած անձը կամ նրա ներկայացուցիչը։ Ներկայացուցչի ստորագրած պատասխանին կցվում է նրա լիազորությունները հավաստող լիազորագիրը, եթե այն տվյալ գործով նախկինում չի ներկայացվել։
(189-րդ հոդվածը փոփ. 09.07.19 ՀՕ-128-Ն)
