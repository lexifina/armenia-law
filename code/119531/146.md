# Հոդված 146. Դատավորի նկատմամբ կարգապահական վարույթ հարուցելու առիթները
1. Կարգապահական վարույթ հարուցելու առիթներն են՝
1) անձի, պետական և տեղական ինքնակառավարման մարմնի կամ պաշտոնատար անձի հաղորդումը.
2) կարգապահական խախտման մասին զանգվածային լրատվության միջոցների հրապարակումները.
3) վարույթ հարուցող մարմնի կողմից իր լիազորություններն իրականացնելիս առերևույթ կարգապահական խախտման հատկանիշներ պարունակող արարքի ինքնուրույն հայտնաբերումը:
2. Անանուն հաղորդումները քննարկման ենթակա չեն:
3. Վարույթ հարուցող մարմինը մինչև դրա հարուցման հարցի լուծումն իրավունք ունի հաղորդում ներկայացրած անձին առաջարկելու ներկայացնել կարգապահական վարույթ հարուցելու համար նշանակություն ունեցող տեղեկությունների վերաբերյալ նյութեր:
4. Կարգապահական վարույթ հարուցելու հարցը քննարկվում է այն հարուցելու առիթը վարույթ հարուցող մարմնին հայտնի դառնալու օրվանից մեկ ամսվա ընթացքում, իսկ փորձաքննություն նշանակվելու դեպքում՝ փորձաքննության կատարման համար անհրաժեշտ ժամկետով:
5. Սույն հոդվածի 1-ին մասի 1-ին կետով նախատեսված անձի հաղորդման հիման վրա կարգապահական վարույթ չհարուցելու դեպքում վարույթ հարուցող մարմինն իր պատասխանում նշում է չհարուցելու հիմքերը:
6. Կարգապահական վարույթ չի հարուցվում, եթե՝
1) նույն դատավորի նկատմամբ նույն արարքի համար առկա է վարույթ հարուցող նույն մարմնի կողմից հարուցված վարույթ.
2) նույն դատավորի նկատմամբ նույն արարքի համար կարգապահական պատասխանատվության ենթարկելու հարցի վերաբերյալ առկա է նույն մարմնի կարգապահական վարույթ չհարուցելու կամ վարույթը կարճելու վերաբերյալ որոշում.
3) նույն դատավորի նկատմամբ նույն արարքի համար կարգապահական պատասխանատվության ենթարկելու հարցի վերաբերյալ առկա է Բարձրագույն դատական խորհրդի որոշում:
