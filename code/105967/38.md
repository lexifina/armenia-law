# Հոդված 38. Ընտրական հանձնաժողովների ակտերը
1. Կենտրոնական ընտրական հանձնաժողովն ընդունում է ենթաօրենսդրական նորմատիվ իրավական ակտեր և անհատական իրավական ակտեր, իսկ ընտրատարածքային և տեղամասային ընտրական հանձնաժողովները` անհատական իրավական ակտեր:
Կենտրոնական և ընտրատարածքային ընտրական հանձնաժողովների նախագահները կարող են ընդունել անհատական իրավական ակտեր:
