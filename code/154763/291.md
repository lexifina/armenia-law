# Հոդված 291. Ապացուցողական գործողությունների կատարման դատական երաշխիքների շրջանակը
1. Սույն օրենսգրքով սահմանված պատշաճ իրավական ընթացակարգի շրջանակներում դատարանը քննում է՝
1) սույն օրենսգրքի 209-րդ հոդվածի 4-րդ մասով նախատեսված որևէ քննչական գործողություն կատարելու վերաբերյալ միջնորդությունը․
2) գաղտնի քննչական գործողություն կատարելու վերաբերյալ միջնորդությունը․
