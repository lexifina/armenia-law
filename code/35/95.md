# Հոդված 95. Ընտրական համակարգը
1. Ազգային ժողովի ընտրություններ անցկացվում են համամասնական և մեծամասնական ընտրակարգերով:
2. 75 պատգամավոր ընտրվում է համամասնական ընտրակարգով, հանրապետության ամբողջ տարածքն ընդգրկող մեկ բազմամանդատ ընտրատարածքից` կուսակցությունների ընտրական ցուցակներով առաջադրված պատգամավորության թեկնածուների թվից:
3. 56 պատգամավոր ընտրվում է մեծամասնական ընտրակարգով` յուրաքանչյուր ընտրատարածքից մեկ պատգամավոր:
(95-րդ հոդվածը փոփ. 03.07.02 ՀՕ-406-Ն)
