# Հոդված 64.4. Գործի վարումն էլեկտրոնային եղանակով
(վերնագիրը խմբ. 04.03.26 ՀՕ-57-Ն)
1. Յուրաքանչյուր վարչական գործի շրջանակներում դատարանը գործը վարում է էլեկտրոնային եղանակով։
2. Էլեկտրոնային եղանակով վարվող գործը ներառում է վարչական գործի բոլոր նյութերը, որոնք ստեղծվել կամ ներկայացվել են Համակարգի միջոցով, ինչպես նաև սույն օրենսգրքով նախատեսված դեպքերում՝ Համակարգից դուրս ստեղծված կամ ներկայացված գործի բոլոր նյութերի սկանավորված տարբերակները (ներառյալ՝ իրեղեն ապացույցների լուսանկարները և տեսագրությունները, դատական ծանուցագրերը, զննման արձանագրությունները և դատական նիստերի արձանագրությունները)։
(64.4-րդ հոդվածը խմբ., փոփ., լրաց. 04.03.26 ՀՕ-57-Ն)
(04.03.26 ՀՕ-57-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
