# Հոդված 277. Վարչական իրավախախտման վերաբերյալ գործերի քննության ժամկետները
Վարչական իրավախախտումների վերաբերյալ գործերը քննվում են վարչական իրավախախտման վերաբերյալ արձանագրությունը և մյուս նյութերը գործի քննության համար լիազորված մարմնի (պաշտոնատար անձի) կողմից ստանալու օրվանից սկսած տասնհինգօրյա ժամկետում:
Սույն օրենսգրքի 40¹ -40⁴,40⁶ -40¹², 44, 172, 175, 180¹ և 182 հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը քննվում են մեկ օրվա ընթացքում, սույն օրենսգրքի 147 հոդվածի երկրորդ մասով նախատեսվածները` երեք օրվա ընթացքում, սույն օրենսգրքի 53 հոդվածով նախատեսվածները` հնգօրյա ժամկետում, սույն օրենսգրքի 103, 105, 106 հոդվածներով նախատեսվածները` յոթնօրյա ժամկետում:
ԽՍՀ Միության և Հայաստանի Հանրապետության օրենսդրությամբ կարող են նախատեսվել նաև վարչական իրավախախտումների վերաբերյալ գործերի քննության այլ ժամկետներ:
