# Հոդված 306. Գերեզմանն անարգանքի ենթարկելը
1. Մահացածին թաղելու վայրը կամ գերեզմանի վրա եղած շինությունը կամ առարկան ոչնչացնելը, վնասելը կամ պղծելը՝
պատժվում է տուգանքով` տասնապատիկից երեսնապատիկի չափով, կամ հանրային աշխատանքներով՝ հարյուրից երկու հարյուր ժամ տևողությամբ, կամ կարճաժամկետ ազատազրկմամբ` առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ` առավելագույնը երեք տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը կատարվել է՝
1) ռասայական, ազգային, էթնիկ կամ սոցիալական ծագումով, կրոնով, քաղաքական կամ այլ հայացքներով կամ անձնական կամ սոցիալական բնույթի այլ հանգամանքներով պայմանավորված ատելության, անհանդուրժողականության կամ թշնամանքի շարժառիթով,
2) մի խումբ անձանց կողմից նախնական համաձայնությամբ կամ
