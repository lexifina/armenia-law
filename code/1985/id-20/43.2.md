# Հոդված 43.2. Աղբավայրի մոնիթորինգի իրականացման կարգը խախտելը
1․ Աղբավայրը շահագործողների կողմից աղբավայրերի մոնիթորինգի իրականացման կարգը խախտելը՝
առաջացնում է տուգանքի նշանակում անհատ ձեռնարկատերերի նկատմամբ` սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով, իսկ իրավաբանական անձանց նկատմամբ՝ սահմանված նվազագույն աշխատավարձի հարյուրապատիկի չափով:
2․ Վարչական տույժի միջոցներ կիրառելուց հետո` մեկ տարվա ընթացքում, նույն խախտումը կրկնելը՝
առաջացնում է տուգանքի նշանակում անհատ ձեռնարկատերերի նկատմամբ՝ սահմանված նվազագույն աշխատավարձի հարյուրապատիկի չափով, իսկ իրավաբանական անձանց նկատմամբ՝ սահմանված նվազագույն աշխատավարձի երկուհարյուրապատիկի չափով:
3. Աղբավայրը տնօրինողների կողմից աղբավայրի մոնիթորինգի իրականացման կարգը խախտելը՝
առաջացնում է տուգանքի նշանակում աղբավայրը տնօրինող անհատ ձեռնարկատերերի նկատմամբ` սահմանված նվազագույն աշխատավարձի հարյուրհիսնապատիկի չափով, իսկ իրավաբանական անձանց նկատմամբ՝ սահմանված նվազագույն աշխատավարձի երկուհարյուրապատիկի չափով:
4. Վարչական տույժի միջոցներ կիրառելուց հետո՝ մեկ տարվա ընթացքում, սույն հոդվածի 3-րդ մասով սահմանված խախտումը կրկնելը՝
առաջացնում է տուգանքի նշանակում աղբավայրը տնօրինող անհատ ձեռնարկատերերի նկատմամբ` սահմանված նվազագույն աշխատավարձի երեքհարյուրապատիկի չափով, իսկ իրավաբանական անձանց նկատմամբ՝ սահմանված նվազագույն աշխատավարձի չորսհարյուրապատիկի չափով:
(43.2-րդ հոդվածը լրաց. 26.10.22 ՀՕ-403-Ն, 13.11.25 ՀՕ-373-Ն)
