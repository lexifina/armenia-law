# Հոդված 94¹. ԳՈՒՅՔԻ ՕՊԵՐԱՏԻՎ ԿԱՌԱՎԱՐՈՒՄԸ ՊԵՏԱԿԱՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅԱՆ ԿՈՂՄԻՑ
