# Հոդված 341.2. Կոռուպցիոն բնույթի դեպքի կամ շահերի բախման կամ էթիկայի կանոնների կամ անհամատեղելիության պահանջների կամ այլ սահմանափակումների կամ հայտարարագրման հետ կապված խախտման կամ հանրային շահերին ուղղված այլ վնասի կամ դրանց սպառնալիքի վերաբերյալ հաղորդում տվող անձի տվյալների ապօրինի հրապարակումը
(341.2-րդ հոդվածը 09.06.17 ՀՕ-102-Ն օրենքի 7-րդ հոդվածի լրացմամբ ուժի մեջ կմտնի 01.01.2018 թ.)
