# Հոդված 1156. Արտոնագրի տիրոջ իրավունքների սահմանափակումը
Արտոնագրի տիրոջ իրավունքները սահմանափակելու հիմքերը, արտոնագիրը դադարեցնելու (չեղյալ հայտարարելու), այն անվավեր ճանաչելու, հարկադրական լիցենզիաներ տալու պայմանները սահմանվում են «Գյուտերի, օգտակար մոդելների, արդյունաբերական նմուշների մասին» Հայաստանի Հանրապետության օրենքով:
Արտոնագիրը հանրության գերակա շահերի ապահովման նպատակով կարող է օտարվել միայն օրենքով սահմանված բացառիկ դեպքերում և կարգով:
(1156-րդ հոդվածը խմբ. 27.11.06 ՀՕ-187-Ն, փոփ. 10.06.08 ՀՕ-112-Ն, խմբ. 24.10.18 ՀՕ-408-Ն)
