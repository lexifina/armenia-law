# Հոդված 427. Դատական ակտը վերանայող դատարանի լիազորությունները
1. Դատարանը, պարզելով սույն օրենսգրքի 418-րդ հոդվածով կամ 419-րդ հոդվածով նախատեսված հիմքերի առկայությունը, բեկանում է վերանայվող դատական ակտը և ուղարկում համապատասխան դատարան` նոր քննության, եթե չկա այն փոփոխելու հնարավորություն:
2. (մասն ուժը կորցրել է 25.03.26 ՀՕ-108-Ն)
3. Դատարանը, բեկանելով վերանայվող դատական ակտը, փոփոխում է այն, եթե գործով հաստատված փաստերը հնարավորություն են տալիս առանց գործի նոր քննության կայացնելու նոր դատական ակտ:
4. Նոր երևան եկած կամ նոր հանգամանքներով դատական ակտի վերանայման բողոքի քննության արդյունքով դատարանը կայացնում է որոշում, որը պետք է բավարարի սույն օրենսգրքի համապատասխանաբար 381-րդ և 406-րդ հոդվածների պահանջները:
5. Վերաքննիչ դատարանի դատական ակտն օրենքով սահմանված ընդհանուր կարգով կարող է բողոքարկվել Վճռաբեկ դատարան:
(427-րդ հոդվածը փոփ. 09.06.22 ՀՕ-182-Ն, 25.03.26 ՀՕ-108-Ն)
(25.03.26 ՀՕ-108-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
(հոդվածի 23.09.25 ՍԴՈ-1797 որոշմամբ ճանաչված Սահմանադրությանը հակասող դրույթը համապատասխանեցվել է Սահմանադրությանը 25.03.26 ՀՕ-108-Ն օրենքի 7-րդ հոդվածի 2-րդ կետի փոփոխությամբ)
