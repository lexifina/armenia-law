# Հոդված 91. ԳՅՈՒՂԱՏՆՏԵՍԱԿԱՆ ՆՇԱՆԱԿՈՒԹՅԱՆ ՀՈՂԵՐԻ ՏՐԱՄԱԴՐՈՒՄԸ
1. Գյուղատնտեսական նշանակության հողերը տրամադրվում են քաղաքացիներին և իրավաբանական անձանց սեփականության կամ օգտագործման իրավունքով`
1) գյուղատնտեսական մշակաբույսերի մշակման, բազմամյա տնկարկների հիմնման, գիտահետազոտական և ուսումնական,
2) խոտհնձի և անասունների արածեցման,
3) գյուղատնտեսական արտադրական շենքերի, շինությունների կառուցման,
4) բացառիկ դեպքերում բնակելի, հասարակական և արտադրական շենքերի, շինությունների կառուցման ու սպասարկման և օրենսդրությամբ չարգելված այլ գործողությունների իրականացման նպատակներով:
