# Հոդված 218. Ինքնիրավչություն
Ինքնիրավչությունը, այսինքն` օրենքով սահմանված կարգի խախտմամբ, ինքնագլուխ կերպով իր իսկական կամ ենթադրյալ իրավունքի իրականացումը, որն էական վնաս է պատճառել քաղաքացիներին կամ պետական, կամ հասարակական կազմակերպություններին`
պատժվում է ուղղիչ աշխատանքներով մինչև մեկ տարի ժամանակով, կամ տուգանքով մինչև հարյուր դրամ, կամ առաջ է բերում հասարակական ներգործության միջոցների կիրառում:
(29.12.82 խմբագրությամբ)
