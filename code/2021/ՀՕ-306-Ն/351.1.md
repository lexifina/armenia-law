# Հոդված 351.1. Եզրափակիչ դատական ակտ կայացնելուց հետո մեղադրյալի նկատմամբ ընտրված խափանման միջոցը փոխելը կամ վերացնելը
1. Եթե մինչև եզրափակիչ դատական ակտն օրինական ուժի մեջ մտնելը, իսկ այն բողոքարկելու դեպքում բողոքը վերադաս դատարանի կողմից վարույթ ընդունելը ի հայտ է գալիս մեղադրյալի կյանքին սպառնացող վտանգ, դատարանը սեփական նախաձեռնությամբ կամ մեղադրյալի կամ պաշտպանի միջնորդությամբ քննում է խափանման միջոցը փոխելու կամ վերացնելու հարցը:
2. Դատական նիստն անցկացվում է մեղադրյալի կյանքին սպառնացող վտանգի վերաբերյալ դատարանին հայտնի դառնալուց հետո՝ հնարավոր ամենակարճ ժամկետում:
3. Պատշաճ ծանուցված անձանց բացակայությունը խոչընդոտ չէ դատական նիստն անցկացնելու համար, եթե դատարանն այլ բան չի որոշում:
4. Եթե հարցի քննության արդյունքում դատարանը որոշում է փոխել կամ վերացնել մեղադրյալի նկատմամբ ընտրված խափանման միջոցը, ապա դատարանի որոշումն անհապաղ հանձնվում է հանրային մեղադրողին, պաշտպանին, մեղադրյալին և խափանման միջոցի կիրառումն ապահովող մարմնին կամ պաշտոնատար անձին:
(351.1-ին հոդվածը լրաց. 18.06.26 ՀՕ-239-Ն)
(18.06.26 ՀՕ-239-Ն օրենքն ունի անցումային դրույթ)
