# Հոդված 223.2. Հայաստանի Հանրապետության կենտրոնական ընտրական հանձնաժողովը

(223.2- րդ հոդվածը լրաց. 09.02.12 ՀՕ-11-Ն, փոփ., լրաց. 16.12.16 ՀՕ-225-Ն)
(223.2-րդ հոդվածը 29.12.20 ՀՕ-4-Ն օրենքի 11-րդ հոդվածի համաձայն ուժը կկորցնի 01.01.2022 թվականին:)
(29.12.20 ՀՕ-4-Ն օրենքն ունի հոդվածին վերաբերվող անցումային դրույթ:)
