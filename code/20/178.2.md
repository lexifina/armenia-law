# Հոդված 178.2. Երեխայի կյանքի անվտանգության ապահովման կամ առողջության պահպանման պարտականությունը չկատարելը կամ ոչ պատշաճ կատարելը
1. Երեխայի կյանքի անվտանգության ապահովման կամ առողջության պահպանման պարտականությունը չկատարելը կամ ոչ պատշաճ կատարելը, եթե դրա հետևանքով երեխայի առողջությանը պատճառվել է թեթև վնաս՝
առաջացնում է տուգանքի նշանակում՝ սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով։
(178.2-րդ հոդվածը լրաց. 09.06.22 ՀՕ-155-Ն)
