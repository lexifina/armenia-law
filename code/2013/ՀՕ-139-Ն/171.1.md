# Հոդված 171.1. Վճռաբեկ դատարանի որոշման մեջ առկա վրիպակների, գրասխալների և թվաբանական սխալների ուղղումը
1. Վճռաբեկ դատարանի որոշման մեջ առկա վրիպակների, գրասխալների և թվաբանական սխալների ուղղման վրա տարածվում են Հայաստանի Հանրապետության քաղաքացիական դատավարության օրենսգրքի համապատասխան կանոնները, եթե սույն օրենսգրքով այլ բան նախատեսված չէ։
(171.1-ին հոդվածը լրաց. 02.05.24 ՀՕ-220-Ն)
(02.05.24 ՀՕ-220-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
