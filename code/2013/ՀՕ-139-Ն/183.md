# Հոդված 183. Նոր երևան եկած կամ նոր հանգամանքներով դատական ակտը վերանայող դատարանը
1. Նոր երևան եկած կամ նոր հանգամանքներով վարչական դատարանի` օրինական ուժի մեջ մտած դատական ակտը վերանայում է վերաքննիչ դատարանը, եթե այդ դատական ակտը մինչև օրինական ուժի մեջ մտնելը չի վերանայել վերաքննիչ կամ վճռաբեկ դատարանը։
2. Նոր երևան եկած կամ նոր հանգամանքներով վերաքննիչ և վճռաբեկ դատարանների` օրինական ուժի մեջ մտած որոշումները վերանայում է վճռաբեկ դատարանը։
