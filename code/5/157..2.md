# Հոդված 157.². Առևտրի կանոնների խախտումը
Առևտրի ձեռնարկությունների (կազմակերպությունների) կամ հասարակական սննդի ձեռնարկությունների (կազմակերպությունների) պահեստներից, բազաներից, օժանդակ զետեղարաններից շահադիտական կամ այլ անձնական շահագրգռվածությունից ելնելով ապրանքներ վաճառելը կամ գնորդներից ապրանքներ թաքցնելը`
պատժվում է ուղղիչ աշխատանքներով մինչև մեկ տարի ժամանակով`առևտրի ձեռնարկություններում (կազմակերպություններում) և հասարակական սննդի ձեռնարկություններում (կազմակերպություններում) որոշակի պաշտոններ զբաղեցնելու կամ որոշակի գործունեությամբ զբաղվելու իրավունքից զրկելով կամ առանց դրա, կամ տուգանքով մինչև հարյուր դրամ:
Նույն արարքները, որ կատարվել են կրկին անգամ`
