# Հոդված 23. Ներկայացուցչին վարույթից հեռացնելը
1. Դատարանը կարող է հեռացնել վարույթից կողմի այն ներկայացուցչին, որը փաստաբան կամ օրինական կամ ի պաշտոնե ներկայացուցիչ չէ, եթե գործը քննության նախապատրաստելու փուլում կամ դատաքննության ընթացքում պարզ է դառնում, որ տվյալ անձն ունակ չէ դատարանում ներկայացնելու կողմին։
