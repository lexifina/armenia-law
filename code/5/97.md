# Հոդված 97. Գույքն անզգուշությամբ ոչնչացնելը կամ վնասելը
Գույքն անզգուշությամբ ոչնչացնելը կամ վնասելը, որը մարդկային զոհեր կամ այլ ծանր հետևանքներ է առաջացրել, ինչպես նաև անզգուշությամբ անտառային զանգվածներն ու խոշոր չափերի հասնող ցանքերը ոչնչացնելը կամ վնասելը`
