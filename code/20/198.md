# Հոդված 198. Առանց անձնագրի և առանց սոցիալական ապահովության քարտի համարի ներկայացման աշխատանքի ընդունելը
Գործատուի կողմից առանց անձնագրի և առանց սոցիալական ապահովության քարտի համարի ներկայացման քաղաքացիներին աշխատանքի ընդունելը`
առաջացնում է տուգանքի նշանակում գործատուի նկատմամբ` սահմանված նվազագույն աշխատավարձի քսանապատիկի չափով:
Սույն հոդվածի առաջին մասով նախատեսված տուգանքի նշանակման օրվանից հետո` մեկ տարվա ընթացքում, նույն խախտումը կրկնելը`
