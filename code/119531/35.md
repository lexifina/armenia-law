# Հոդված 35. Դատարանների նախագահների և Վճռաբեկ դատարանի պալատների նախագահների լիազորությունների դադարումը
1. Դատարանների նախագահների և Վճռաբեկ դատարանի պալատների նախագահների լիազորությունները դադարում են պաշտոնավարման ժամկետը լրանալու, դատարանի վերացման, նրանց՝ որպես դատավորի լիազորությունների դադարման, դադարեցման, Բարձրագույն դատական խորհրդի անդամ ընտրվելու, նրա նկատմամբ սույն օրենսգրքի 149-րդ հոդվածի 1-ին մասի 3.2-րդ կետով սահմանված կարգապահական տույժի կիրառման, ինչպես նաև սույն հոդվածի 2-րդ և 3-րդ մասերով նախատեսված դեպքերում: Վճռաբեկ դատարանի պալատի նախագահի լիազորությունները դադարում են նաև համապատասխան պալատի վերացման դեպքում:
2. Առաջին ատյանի և վերաքննիչ դատարանի նախագահը հրաժարականի մասին գրավոր դիմումի մեջ նշում է հրաժարականի հիմք հանդիսացող հանգամանքները: Բարձրագույն դատական խորհուրդը կարող է չընդունել առաջին ատյանի դատարանի և վերաքննիչ դատարանի նախագահների հրաժարականը:
3. Վճռաբեկ դատարանի և Վճռաբեկ դատարանի պալատի նախագահի կողմից հրաժարական ներկայացվելու դեպքում նրա՝ որպես Վճռաբեկ դատարանի կամ Վճռաբեկ դատարանի պալատի նախագահի լիազորությունները դադարում են Բարձրագույն դատական խորհրդի նիստում իր հրաժարականը պնդելու կամ այդ նիստին չներկայանալու օրվանից:
(35-րդ հոդվածը լրաց. 25.03.20 ՀՕ-197-Ն, 09.02.22 ՀՕ-24-Ն)
(25.03.20 ՀՕ-197-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
(09.02.22 ՀՕ-24-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
