# Հոդված 46. ՀՈՂԱՄԱՍՆ ՕԳՏԱԳՈՐԾՄԱՆ ՏՐԱՄԱԴՐԵԼԸ
Հողամասը սեփականատերն օգտագործման է տրամադրում կառուցապատման, անհատույց (մշտական) օգտագործման կամ վարձակալության իրավունքով:
Արգելվում է պետական կամ համայնքային սեփականություն հանդիսացող հողամասերը կառուցապատման իրավունքով օգտագործման տրամադրելը: Նման հողամասերը կարող են փոխանցվել միայն սեփականության իրավունքով, բացառությամբ Հայաստանի Հանրապետության հողային օրենսգրքով սահմանված պետական և համայնքային սեփականություն հանդիսացող այն հողամասերի, որոնց փոխանցումը սեփականության իրավունքով արգելված է:
