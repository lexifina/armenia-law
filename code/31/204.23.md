# Հոդված 204²³. Բողոք ներկայացնելու կարգը

2. Բողոքին կցվում են նոր հանգամանքը հաuտատող ապացույցը (ապացույցները), ինչպեu նաև լրացուցիչ այլ ապացույցներ, որոնք նախկինում չեն ներկայացվել: Բողոքին կցվում է նաև դատական ակտի վերանայման հետ կապված պետական տուրքի վճարումը հաuտատող ապացույցը:
3. Բողոքը ներկայացնող անձը դրա պատճենը նոր հանգամանքը հաuտատող ապացույցի (ապացույցների) պատճենի (պատճենների) հետ պատշաճ ձևով ուղարկում է գործին մաuնակցող անձանց:
