# Հոդված 204¹⁸. Բողոքի քննության արդյունքում կայացված որոշումները
1. Բողոքի քննության արդյունքում դատարանը, պարզելով սույն օրենսգրքի 204¹¹ հոդվածով նախատեսված հիմքերից որևէ մեկի առկայությունը, որոշում է կայացնում նոր երևան եկած հանգամանքներով դատական ակտի վերանայման մասին: Դատարանը, գտնելով, որ դատական ակտը ենթակա է վերանայման միայն որոշակի մասով, որոշում է կայացնում դատական ակտի համապատասխան մասի վերանայման վերաբերյալ:
2. Սույն օրենսգրքի 204¹¹ հոդվածով նախատեսված հիմքերի բացակայության դեպքում դատարանը որոշում է կայացնում բողոքը մերժելու մասին:
3. Սույն հոդվածով նախատեսված որոշումները կայացման պահից հնգօրյա ժամկետում պատշաճ ձևով ուղարկվում են բողոք ներկայացրած անձին ու գործին մասնակցող անձանց և նրանց կողմից ստանալու պահից տասնօրյա ժամկետում կարող են բողոքարկվել վերաքննիչ դատարան:
(Վերնագիրը փոփ. 26.12.08 ՀՕ-233-Ն)
(204¹⁸ հոդվածը լրաց. 28.11.07 ՀՕ-277-Ն)
