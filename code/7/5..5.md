# Հոդված 5.⁵. Քրեական գործի կարճումը գործը ընկերական դատարանին հանձնելու կապակցությամբ
Դատարանը, դատախազը, ինչպես նաև քննիչը և հետաքննական մարմինը` դատախազի համաձայնությամբ, Հայաստանի Հանրապետության քրեական օրենսգրքի 47 հոդվածում նշված հիմքերով իրավունք ունեն գործը քրեական կարգով կարճելու և այն հանձնելու ընկերական դատարանի քննությանը:
Գործի կարճման մասին, այն մինչև ընկերական դատարանի քննությանը հանձնելը, տեղյակ են պահվում մեղադրյալը, ինչպես նաև տուժողը և նրա ներկայացուցիչը, որոնք իրավունք ունեն հինգ օրվա ընքացքում գանգատարկելու դատարանի, դատախազի, քննիչի, հետաքննության մարմնի որոշումը համապատասխանորեն վերադաս դատարանին կամ վերադաս դատախազին:
