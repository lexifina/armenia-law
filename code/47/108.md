# Հոդված 108. Ցմահ ազատազրկման դատապարտված անձի` պատիժը կրելու առանձնահատկությունները
1. Ցմահ ազատազրկման դատապարտված անձինք պահվում են խցերում` որպես կանոն, յուրաքանչյուր խցում չորս դատապարտյալից ոչ ավելի: Դատապարտյալի խնդրանքով կամ նրա անձնական անվտանգությանը սպառնացող վտանգի դեպքում, ուղղիչ հիմնարկի պետի որոշմամբ, դատապարտյալը կարող է պահվել մենախցում: Տվյալ դատապարտյալի աշխատանքը կազմակերպվում է՝ հաշվի առնելով դատապարտյալին խցում պահելու` ուղղիչ հիմնարկների ներքին կանոնակարգով սահմանված պահանջները:
2. Դատապարտյալն ամենօրյա մեկ ժամ տևողությամբ զբոսանքի իրավունք ունի:
3. Դատապարտյալի զբոսանքի ընթացքում պահպանվում են անջատ պահելու՝ սույն օրենսգրքի 68-րդ հոդվածով սահմանված պահանջները:
