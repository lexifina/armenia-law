# Հոդված 174. Նախնական դատական նիստն ավարտելու և դատաքննություն նշանակելու մասին որոշումը
1. Դատարանը, համարելով գործը դատաքննության նախապատրաստված, նախնական դատական նիստում որոշում է կայացնում նախնական դատական նիստն ավարտելու և գործը դատաքննության նշանակելու մասին, որում նշվում են դատական նիստի ժամանակն ու վայրը:
2. Դատարանն իրավունք ունի գործին մասնակցող անձանց համաձայնությամբ նախնական դատական նիստից անմիջապես անցնելու դատաքննության, եթե գործին մասնակցող բոլոր անձինք կամ նրանց ներկայացուցիչները ներկա են նախնական դատական նիստին, բացառությամբ սույն օրենսգրքով նախատեսված հեռակա դատաքննություն կիրառելու դեպքերի:
3. Նախնական դատական նիստն ավարտելու և դատաքննություն նշանակելու մասին որոշումը դատարանը երեք օրվա ընթացքում ուղարկում է նախնական դատական նիստին չներկայացած գործին մասնակցող անձանց:
