# Հոդված 273. Մշակումն արգելված թմրանյութեր, հոգեմետ, խիստ ներգործող կամ թունավոր նյութեր պարունակող բույսեր ապօրինի ցանելը կամ աճեցնելը
1. Մշակումն արգելված թմրանյութեր, հոգեմետ, խիստ ներգործող կամ թունավոր նյութեր պարունակող բույսեր ապօրինի ցանելը կամ աճեցնելը խոշոր չափերով՝
պատժվում է տուգանքով՝ նվազագույն աշխատավարձի երեքհարյուրապատիկից հինգհարյուրապատիկի չափով, կամ կալանքով՝ մեկից երեք ամիս ժամկետով, կամ ազատազրկմամբ՝ առավելագույնը երկու տարի ժամկետով:
2. Նույն արարքները, որոնք կատարվել են՝
1) մի խումբ անձանց կողմից նախնական համաձայնությամբ,
2) կազմակերպված խմբի կողմից,
2.1) կրկին անգամ,
