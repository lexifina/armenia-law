# Հոդված 124⁶. Տրանսպորտային միջոցների վարորդների կողմից ճանապարհային երթևեկության կանոնները խախտելը, որի հետևանքով առաջացել է ճանապարհատրանսպորտային պատահար
Տրանuպորտային միջոցների վարորդների կողմից ճանապարհային երթևեկության կանոնները խախտելը, որի հետևանքով առաջացել է ճանապարհատրանսպորտային պատահար`
առաջացնում է տուգանքի նշանակում` uահմանված նվազագույն աշխատավարձի քսանապատիկի չափով:
Սույն հոդվածի առաջին մասով նախատեսված իրավախախտումներով վարչական վարույթ իրականացվում է պատահարի մասնակցի` պատահարի վայրում արտահայտած գրավոր պահանջով:
Պատահարի մասնակիցների կողմից սույն հոդվածի երկրորդ մասով նախատեսված պահանջի բացակայությունը փաստվում է գրավոր համաձայնությամբ:
Գրավոր պահանջի և գրավոր համաձայնության ձևաթղթերը սահմանվում են Հայաuտանի Հանրապետության ոստիկանության պետի հրամանով:
(124⁶ հոդվածը լրաց. 21.02.07 ՀՕ-73-Ն)
