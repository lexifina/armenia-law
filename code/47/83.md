# Հոդված 83. Դատապարտյալի բուժսանիտարական օգնությունը
1. Դատապարտյալի բուժսանիտարական և բուժկանխարգելիչ օգնությունը կազմակերպվում է Հայաստանի Հանրապետության առողջապահության ոլորտը կարգավորող օրենսդրությանը համապատասխան։ Դատապարտյալի բուժսանիտարական և բուժկանխարգելիչ օգնությունը կազմակերպելու կարգը սահմանում է պետական կառավարման լիազորված մարմինը: Առողջապահական մարմինների բուժական հիմնարկներից օգտվելու և այդ նպատակով դրանց բժշկական անձնակազմին ներգրավելու կարգը սահմանում է Հայաստանի Հանրապետության կառավարությունը:
2. Դատապարտյալին բուժսանիտարական և բուժկանխարգելիչ օգնություն արդյունավետ ապահովելու նպատակով կազմակերպվում է բուժական ուղղիչ հիմնարկ:
3. Ուղղիչ հիմնարկի վարչակազմն ապահովում է դատապարտյալի առողջության պահպանմանն ուղղված սանիտարահիգիենիկ և հակահամաճարակային միջոցառումների կատարումը։
