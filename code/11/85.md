# Հոդված 85. պետական տուրքը վերադարձնելը
վճարված պետական տուրքը ենթակա է վերադարձման մասնակիորեն կամ լրիվ հետևյալ դեպքերում`
1) եթե տուրքը մուծվել է ավելի, քան պահանջվում է գործող օրենսդրությամբ.
2) եթե դիմումը (գանգատը) վերադարձվել է կամ մերժվել է նրա ընդունումը.
3) եթե գործի վարույթը կարճվել է գործը դատարանի քննության ենթակա չլինելու, ինչպես նաև դատարան դիմած շահագրգռված անձի կողմից տվյալ կատեգորիայի գործերի համար օրենքով սահմանված` վեճի նախնական արտադատարանական լուծման կարգը չպահպանվելու պատճառով (սույն օրենսգրքի 218 հոդվածի 1-ին և 2-րդ կետեր).
4) եթե դիմումը թողնվել է առանց քննության, դատարան դիմած շահագրգռված անձի կողմից տվյալ կատեգորիայի գործերի համար օրենքով սահմանված` գործի նախնական արտադատարանական լուծման կարգը չպահպանելու կամ դիմումը անգործունակ անձի կողմից տրվելու պատճառող (սույն օրենսգրքի 220 հոդվածի 1-ին և 2-րդ կետեր):
այդ հոդվածի առաջին մասի 1-ին կետով նախատեսված դեպքում պետական տուրքը վերադարձվում է ավելի մուծված գումարի չափով:
պետական տուրքը դատարանի կամ դատավորի որոշման հիման վրա ֆինանսական մարմինների կողմից վերադարձվում է, եթե տուրքը վերադարձնելու վերաբերյալ դիմումը դատարանին է տրվել գումարը բյուջե փոխանցելու օրից մեկ տարվա ժամկետում:
(28.05.80 խմբագրությամբ)
