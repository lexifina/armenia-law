# Հոդված 92. Հայցի ապահովման մասին որոշման կատարումը
1. Հայցի ապահովման մասին վարչական դատարանի որոշումը կատարվում է անհապաղ` «Կատարողական վարույթի մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով։
2. Անշարժ գույքի նկատմամբ կամ դրա կապակցությամբ հայցի ապահովման միջոցներ կիրառելու մասին որոշումն անշարժ գույքի պետական ռեգիստր ուղարկելու դեպքում դատարանն այն անշարժ գույքի պետական ռեգիստր է ուղարկում էլեկտրոնային եղանակով՝ Կառավարության սահմանած կարգով:
(92-րդ հոդվածը փոփ. 11.04.24 ՀՕ-194-Ն, լրաց. 22.10.25 ՀՕ-352-Ն)
(11.04.24 ՀՕ-194-Ն օրենքն ունի անցումային դրույթ)
