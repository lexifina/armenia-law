# Հոդված 131.1. Անհատական շարժունակության (տեղաշարժման) միջոցների երթևեկությանը ներկայացվող պահանջները խախտելը
(հոդվածը 02.10.24 ՀՕ-362-Ն օրենքի լրացման մասով ուժի մեջ է մտնում նույն օրենքի պաշտոնական հրապարակումից մեկ ամիս հետո, բացառությամբ սույն հոդվածի 3-րդ մասի, որն ուժի մեջ է մտնում 2025 թվականի սեպտեմբերի 1-ից)
