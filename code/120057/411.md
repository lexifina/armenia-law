# Հոդված 411. Գործի նոր վարույթ հարուցելը
1. Դատարանի եզրափակիչ դատական ակտը բեկանելու և գործը նոր քննության ուղարկելու մասին դատական ակտ կայացնելու դեպքում դատարանը գործն ստանալուց հետո` եռօրյա ժամկետում, կայացնում է գործը վարույթ ընդունելու մասին որոշում:
2. Գործը վարույթ ընդունելու մասին որոշումը ուղարկվում է գործին մասնակցող անձանց։
