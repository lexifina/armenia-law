# Հոդված 149. Խնամակալության կամ հոգաբարձության սահմանումը այն անչափահասի նկատմամբ, որի ծնողները հրաժարվում են նրան դաստիարակելուց
Այն դեպքում, երբ երեխան չի ապրում իր ծնողների հետ միասին և ծնողները հրաժարվում են նրան դաստիարակելու պարտականություններից, երեխայի նկատմամբ սահմանվում խնամակալություն կամ հոգաբարձություն: Այդ դեպքում խնամակալության և հոգաբարձության մարմինները իրավունք ունեն դատական կարգով պահանջելու ծնողներին զրկել ծնողական իրավունքներից: (29.05.85 խմբագրությամբ)
