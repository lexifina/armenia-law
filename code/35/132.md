# Հոդված 132. Ընտրատարածքային ընտրական հանձնաժողովում տեղամասային արձանագրություններն ամփոփելու կարգը

2. (2-րդ կետն ուժը կորցրել է 22.12.06 ՀՕ-1-Ն)
3. Քվեարկության արդյունքների ամփոփիչ արձանագրությունները կազմվում են սույն օրենսգրքի 63¹ հոդվածով սահմանված կարգով և ժամկետում:
4. Քվեարկության արդյունքների ամփոփիչ արձանագրությունն ստորագրում են ընտրատարածքային ընտրական հանձնաժողովի անդամները: Արձանագրությունը կնքվում է հանձնաժողովի կնիքով: Եթե հանձնաժողովի որևէ անդամի ստորագրություն բացակայում է, ապա այդ մասին նշվում է արձանագրությունում:
