# Հոդված 36. գյուղատնտեսական ձեռնարկություններին ու կազմակերպություններին, կոլտնտեսություններին օգտագործման իրավունքով հող հատկացնելը
գյուղատնտեսական ձեռնարկություններին և կազմակերպություններին օգտագործման իրավունքով հող հատկացնում են սույն օրենսգրքի 14 Հոդվածին համապատասխան հողամասեր հատկացնելու իրավունք ունեցող պատգամավորների համապատասխան խորհուրդները: կոլտնտեսությունների հողօգտագործումն իրականացվում է վարձակալական հիմունքներով: գյուղատնտեսական ձեռնարկություններն ու կազմակերպությունները կարող են վարձակալել և վարձակալության տալ հողամասեր:
