# Հոդված 107. Դիմումների և միջնորդությունների քննարկումը
1. Դատավարության մասնակիցների դիմումները և միջնորդությունները գործի քննության հետ կապված բոլոր հարցերով վարչական դատարանը լուծում է դատավարության մյուս մասնակիցների կարծիքները լսելուց հետո։
2. Դիմումների և միջնորդությունների քննարկումից հետո դատարանը կայացնում է որոշում։
3. Քննարկման ենթակա չէ այն դիմումը կամ միջնորդությունը, որը միայն կրկնում է նախկինում մերժված նույնաբովանդակ դիմումի կամ միջնորդության հիմնավորումները։
