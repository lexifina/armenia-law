# Հոդված 21. Հասարակական հսկողությունը
1. Պատիժները կատարելու նկատմամբ հասարակական հսկողությունն իրականացվում է Հայաստանի Հանրապետության պետական կառավարման լիազորված մարմնի (այսուհետ` պետական կառավարման լիազորված մարմին) կազմավորած հասարակական դիտորդների խմբի միջոցով:
2. Հասարակական դիտորդների խմբի անդամների թիվը չի կարող գերազանցել քսանմեկը: Հասարակական դիտորդների խմբի անդամի լիազորությունների ժամկետը երեք տարի է:
3. Պատիժները կատարելու նկատմամբ հասարակական հսկողության իրականացման կարգը, ինչպես նաև հասարակական դիտորդների խմբի կազմը և իրավասությունը սահմանում է պետական կառավարման լիազորված մարմինը:
