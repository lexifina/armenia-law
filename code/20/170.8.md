# Հոդված 170⁸. Ակցիզային դրոշմանիշերով և (կամ) դրոշմապիտակներով դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) ապրանքներ իրացնելը
(վերնագիրը փոփ. 16.05.16 ՀՕ-82-Ն)
Ակցիզային դրոշմանիշերով և (կամ) դրոշմապիտակներով դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) ապրանքներ իրացնելը, եթե դրանց ընդհանուր արժեքը վաճառողի մոտ նշված (իսկ չնշված լինելու դեպքում` oրենսդրությամբ սահմանված կարգով որոշված) գներով չի գերազանցում հիսուն հազար դրամը`
