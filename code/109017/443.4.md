# Հոդված 443.4. Հաշվետու ֆինանսական հաստատությունների կողմից տեղեկությունների տրամադրումը
1. Հաշվետու ֆինանսական հաստատությունը մինչև յուրաքանչյուր օրացուցային տարվա հունիսի 30-ը ներառյալ էլեկտրոնային եղանակով հարկային մարմին է ներկայացնում նախորդ տարվա բոլոր հաշվետու հաշիվների վերաբերյալ տեղեկությունները: Հաշվետու ֆինանսական հաստատության կողմից հաշվետու հաշիվների վերաբերյալ հարկային մարմնին տեղեկությունների տրամադրման կարգը, ձևաչափը և դրա լրացման կարգը սահմանվում են հարկային մարմնի և Հայաստանի Հանրապետության կենտրոնական բանկի համատեղ իրավական ակտով:
2.
