# Հոդված 233.¹. Կարատեի ապօրինի ուսուցումը
Սպորտային կարատեի սեկցիաներ բացելու կամ դրանցում քաղաքացիներ հավաքագրելու սահմանված կանոնների խախտումը կամ սեկցիաներում սպորտային կանոններով արգելված ոճաձևերի ուսուցումը, ինչպես նաև ինքնակամ, առանց համապատասխան մարմինների թույլտվության, կարատեի ոճաձևերի ուսուցումը, որոնք կատարվել են նույնպիսի խախտումների համար վարչական տույժ կիրառելուց հետո`
պատժվում են ազատազրկմամբ մինչև երկու տարի ժամանակով կամ տուգանքով մինչև երեք հարյուր դրամ, իսկ շահադիտական նպատակների առկայության դեպքում` մինչև հինգ հարյուր դրամ:
Նույն գործողությունները, որոնք կատարվել են կարատեի ապօրինի ուսուցման համար նախկինում դատապարտված անձի կողմից կամ կապված են զգալի չափերով նյութական շահ ստանալու հետ`
