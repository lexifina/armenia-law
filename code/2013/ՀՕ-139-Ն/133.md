# Հոդված 133. Վերաքննիչ բողոք բերելու կարգը
1. Վերաքննիչ բողոքը և դրան կից փաստաթղթերն ուղարկվում են վերաքննիչ դատարան։ Բողոք բերողը վերաքննիչ բողոքը և դրան կից փաստաթղթերի պատճեններն ուղարկում է դատավարության մասնակիցներին, իսկ բողոքի պատճենը` դատական ակտը կայացրած վարչական դատարան։
2. Վարչական դատարանը բողոքի պատճենը ստանալու օրվանից ոչ ուշ, քան հաջորդ օրը, իսկ եթե դա հնարավոր չէ՝ հնարավորինս սեղմ ժամկետում, սակայն ոչ ուշ, քան բողոք բերելու ժամկետը լրանալու օրվան հաջորդող տասնօրյա ժամկետում, պարտավոր է գործն ուղարկել վերաքննիչ դատարան։
