# Հոդված 84. Գործի քննության ժամկետը
1. Վարչական դատարանում գործերը քննվում և լուծվում են հայցադիմումը (դիմումը) վարույթ ընդունվելու պահից ողջամիտ ժամկետում, բայց ոչ ավելի, քան վեց ամսվա ընթացքում, բացառությամբ այն դեպքերի, երբ առանձին գործերի քննության և լուծման համար սույն օրենսգրքով սահմանված են որոշակի ժամկետներ։
1.1. Վարչական դատարանը կարող է պատճառաբանված որոշմամբ ոչ ավելի, քան երկու անգամ երկարաձգել սույն հոդվածի 1-ին մասում նշված ժամկետը՝ յուրաքանչյուր դեպքում առավելագույնը վեց ամիս ժամկետով:
2. Դատաքննությունը, որպես կանոն, պետք է ավարտվի մեկ դատական նիստով՝ առանց հետաձգումների։
3. Սույն հոդվածի 1-ին մասում նշված ժամկետում չեն ներառվում գործի վարույթի կասեցման ժամանակահատվածը, հաշտության համար վարչական դատարանի նշանակած ժամկետը և դատական հանձնարարության կատարման ժամանակահատվածը:
(84-րդ հոդվածը փոփ., լրաց. 25.03.26 ՀՕ-109-Ն)
(25.03.26 ՀՕ-109-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
