# Հոդված 206.15. Փաստաթղթեր, տեղեկություններ և այլ նյութեր տրամադրելու վերաբերյալ Սահմանադրական դատարանի պահանջները չկատարելը կամ ոչ պատշաճ կատարելը կամ կատարման ժամկետները խախտելը
