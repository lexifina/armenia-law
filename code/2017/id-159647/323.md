# Հոդված 323. Բացատրությունների ստացումը
1. Բացատրությունների ստացումը մաքսային հսկողության ձև է, որը մաքսային մարմինների պաշտոնատար անձանց կողմից մաքսային հսկողության անցկացման համար նշանակություն ունեցող տեղեկությունների ստացումն է՝ փոխադրողներից, հայտարարատուներից և այդպիսի տեղեկություններ տիրապետող այլ անձանցից:
2. Բացատրությունները ձևակերպվում են Հանձնաժողովի կողմից որոշվող ձևի մաքսային փաստաթուղթ կազմելու միջոցով:
3. Բացատրությունների ստացման համար անձին կանչելու անհրաժեշտության դեպքում մաքսային մարմնի կողմից ձևակերպվում է ծանուցում, որը հանձնվում կամ ուղարկվում է կանչվող անձին:
