# Հոդված 121. Գործի նոր քննության կարգը
Գործի նոր քննությունը վարչական կամ վերաքննիչ դատարանում իրականացվում է համապատասխանաբար վարչական դատարանի կամ վերաքննության կարգով գործերի քննության համար սույն oրենսգրքով սահմանված կանոններով։ Սակայն գործի նոր քննության ժամանակ չեն կարող փոխվել հայցի հիմքը, առարկան կամ հայցային պահանջների չափը, չի կարող ներկայացվել հակընդդեմ հայց, ինչպես նաև չի կարող իրականացվել հայցից հրաժարում:
