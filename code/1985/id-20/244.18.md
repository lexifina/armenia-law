# Հոդված 244.18. Տիեզերական գործունեության բնագավառում վերահսկողություն իրականացնող տեսչական մարմինը
1. Տիեզերական գործունեության բնագավառում վերահսկողություն իրականացնող տեսչական մարմինը քննում է սույն օրենսգրքի 150.11-150.14-րդ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը:
2. Տիեզերական գործունեության բնագավառում վերահսկողություն իրականացնող տեսչական մարմնի անունից վարչական իրավախախտումների վերաբերյալ գործեր քննելու և վարչական տույժեր նշանակելու իրավունք ունի տիեզերական գործունեության բնագավառում վերահսկողություն իրականացնող տեսչական մարմնի ղեկավարը:
(244.18-րդ հոդվածը լրաց. 06.03.20 ՀՕ-156-Ն)
