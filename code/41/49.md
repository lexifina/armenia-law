# Հոդված 49. Ջրային համակարգի օգտագործման իրավունքի փոխանցման ձևերը
Ջրային համակարգի օգտագործման իրավունքը կարող է փոխանցվել հետևյալ ձևերով՝
1) հավատարմագրային կառավարման հանձնելու միջոցով.
2) կոնցեսիայի պայմանագրով.
3) առևտրային կազմակերպության ստեղծումով.
4) վարձակալությամբ.
5) գույքի անհատույց օգտագործման պայմանագրով:
Փոխանցման ձևերի կարգերը սահմանվում են օրենսդրությամբ:
(49-րդ հոդվածը լրաց. 24.10.11 ՀՕ-273-Ն)
