# Հոդված 47. Օգտակար հանածոների արդյունահանման նպատակով ընդերքի երկրաբանական ուսումնասիրության ընթացքում փորձնական հանույթի իրականացումը և օգտակար հանածոների փորձանմուշների տեղափոխումը
1.
