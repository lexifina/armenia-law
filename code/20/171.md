# Հոդված 171. Քաղաքացիների կողմից գիշակեր մուշտակամորթ գազաններ պահելը
Քաղաքացիների կողմից աղվեսներ, բևեռաղվեսներ, ջրաքիսներ և գիշակեր մուշտակամորթ և այլ գազաններ պահելը`
