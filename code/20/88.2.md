# Հոդված 88.2. Ֆիզիկական կամ իրավաբանական անձանց կողմից վայրի կենդանիների, այդ թվում` Հայաստանի Հանրապետության կենդանիների Կարմիր գրքում գրանցված կենդանիների, դրանց արգասիքների և մասերի առք ու վաճառքի պայմաններն ու պահանջները չպահպանելը
(հոդվածը 23.03.22 ՀՕ-75-Ն օրենքի լրացմամբ ուժի մեջ կմտնի «Կենդանական աշխարհի մասին» օրենքի 6-րդ հոդվածի 1-ին մասի «գ3» կետով սահմանված կարգի ընդունումից հետո)
