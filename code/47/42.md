# Հոդված 42. Ուղղիչ աշխատանքների ձևով պատիժը կրելու պայմանները
1. Դատապարտյալը պարտավոր է պահպանել պատիժը կրելու կարգն ու պայմանները, բարեխիղճ վերաբերմունք դրսևորել աշխատանքին, կատարել իր պարտականությունները, ըստ անհրաժեշտության ներկայանալ ազատությունից զրկելու հետ չկապված պատիժների կատարման ստորաբաժանում՝ վերջինիս կանչով:
2. Ուղղիչ աշխատանքների ձևով պատիժը կրելու ընթացքում դատապարտյալին արգելվում է առանց ազատությունից զրկելու հետ չկապված պատիժների կատարման ստորաբաժանման գրավոր թույլտվության, սեփական դիմումի համաձայն, ազատվել աշխատանքից: Թույլտվությունը կարող է տրամադրվել ազատման հիմնավորվածությունը պարզելուց հետո: Թույլտվություն տրամադրելու մերժումը պետք է պատճառաբանված լինի: Մերժման որոշումը կարող է բողոքարկվել օրենքով սահմանված կարգով:
3. Աշխատանք չունեցող դատապարտյալն իրավունք չունի հրաժարվելու զբաղվածության պետական ծառայության կամ ազատությունից զրկելու հետ չկապված պատիժների կատարման ստորաբաժանման առաջարկած աշխատանքից, իսկ առաջարկ չլինելու դեպքում նա պարտավոր է ինքնուրույն տեղավորվել աշխատանքի:
4. Աշխատանքը կամ բնակության վայրը փոխելու դեպքում դատապարտյալը պարտավոր է տասն օրվա ընթացքում այդ մասին տեղեկացնել ազատությունից զրկելու հետ չկապված պատիժների կատարման ստորաբաժանմանը:
5. Ուղղիչ աշխատանքների ձևով պատիժը կրելու ընթացքում աշխատանքային հարաբերությունները կարգավորվում են Հայաստանի Հանրապետության աշխատանքային օրենսդրությամբ, բացառությամբ սույն օրենսգրքով նախատեսված դեպքերի:
(42-րդ հոդվածը փոփ. 08.07.05 ՀՕ-161-Ն)
