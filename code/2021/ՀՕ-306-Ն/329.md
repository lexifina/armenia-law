# Հոդված 329. Անչափահաս տուժողի կամ վկայի հարցաքննության առանձնահատկությունները
1. Անչափահաս տուժողի կամ վկայի օրինական ներկայացուցիչն իրավունք ունի մասնակցելու տվյալ տուժողի կամ վկայի հարցաքննությանը:
2. Անչափահաս տուժողի կամ վկայի հարցաքննությունը կողմի միջնորդությամբ կամ դատարանի նախաձեռնությամբ կատարվում է հոգեբանի մասնակցությամբ:
3․ Անչափահաս տուժողը կամ վկան հոգեբանի առաջարկությամբ չի հարցաքննվում, եթե դա անհրաժեշտ է նրա իրավաչափ շահերի պաշտպանության համար, և պաշտպանության կողմը մինչդատական վարույթում հնարավորություն է ունեցել հարցեր տալու անչափահասին։
4. Մինչև տասնվեց տարեկան տուժողի կամ վկայի հարցաքննությունն սկսելուց առաջ նախագահողը նրանց բացատրում է վարույթի արդարացի իրականացման համար ճշմարտացի ցուցմունքներ տալու նշանակությունը, սակայն չի նախազգուշացնում ցուցմունք տալուց հրաժարվելու կամ սուտ ցուցմունք տալու համար սահմանված պատասխանատվության մասին:
5. Հարցաքննության ավարտին օրինական ներկայացուցիչն իրավունք ունի նախագահողի թույլտվությամբ հարցեր տալու անչափահաս տուժողին կամ վկային:
