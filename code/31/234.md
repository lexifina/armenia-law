# Հոդված 234. Վճռաբեկ դատարանում գործի քննության կարգը
1. Գործի քննությունը վճռաբեկ դատարանում սկսվում է վճռաբեկ դատարանի պալատի դատավորի զեկուցումով:
Զեկուցողը շարադրում է գործի հանգամանքները, դատարանի վճռի բովանդակությունը և վճռաբեկ բողոքի փաստարկները:
Վճռաբեկ դատարանի դատավորներն իրավունք ունեն հարցեր տալ զեկուցողին:
2. Բողոք բերած անձն իրավունք ունի ներկա գտնվել վճռաբեկ դատարանի նիստին:
3. Բացատրություններ տալու անհրաժեշտության դեպքում վճռաբեկ դատարանի նիստին կարող են կանչվել բողոք բերած անձը, ինչպես նաև գործին մասնակցող անձինք, որոնք պատշաճ ձևով ծանուցվում են նիստի ժամանակի և վայրի մասին: Նրանց չներկայանալն արգելք չէ գործի քննության համար:
