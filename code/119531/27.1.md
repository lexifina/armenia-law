# Հոդված 27.1. Վերաքննիչ դատարանում առանձին տեսակի գործերի քննությունը
1. Բարձրագույն դատական խորհուրդը սույն օրենսգրքի 21-րդ հոդվածի 4-րդ մասով նախատեսված առանձին տեսակի գործերի ցանկ սահմանելու դեպքում կարող է վերաքննիչ դատարանի դատավորներից ընտրել դատավորներ, որոնք, ի լրումն այլ գործերի, քննում են նշված ցանկում ներառված առանձին տեսակի գործեր։ Նման գործեր քննող դատավորների քանակը և ընտրության կարգը սահմանում է Բարձրագույն դատական խորհուրդը։
(27.1-ին հոդվածը լրաց. 03.03.21 ՀՕ-88-Ն)
