# Հոդված 147. Վերաքննիչ դատարանի լրացուցիչ որոշումը
1. Սույն օրենսգրքի 144-րդ հոդվածի 2-րդ մասով սահմանված դեպքում, երբ ապացույց չներկայացրած դատավարության մասնակիցը պետական կամ տեղական ինքնակառավարման մարմինն է կամ դրա պաշտոնատար անձը, վերաքննիչ դատարանը կայացնում է լրացուցիչ որոշում` սույն օրենսգրքի 128-րդ հոդվածով սահմանված կարգով։
