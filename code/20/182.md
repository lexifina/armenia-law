# Հոդված 182. Ոստիկանության ծառայողի օրինական պահանջը չկատարելը
(վերնագիրը փոփ. 07.02.12 ՀՕ-2-Ն, 24.10.24 ՀՕ-437-Ն)
Հասարակական կարգի պահպանության, հասարակական անվտանգության ապահովման, օբյեկտների պահպանության պարտականությունները կատարելու ընթացքում ոստիկանության ծառայողի օրինական պահանջը չկատարելը`
