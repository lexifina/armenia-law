# Հոդված 288. Վարչական իրավախախտման վերաբերյալ գործի որոշումը գանգատարկելու ժամկետը
Վարչական իրավախախտման վերաբերյալ գործի որոշման դեմ գանգատ կարող է տրվել որոշումը սույն օրենսգրքի 283-րդ հոդվածով սահմանված կարգով հանձնելու (հանձնված համարվելու) օրվանից հետո՝ երեսուն օրվա ընթացքում: Նշված ժամկետը հարգելի պատճառներով բաց թողնելու դեպքում այդ ժամկետը կարող է վերականգնվել գանգատը քննելու համար իրավազոր մարմնի (պաշտոնատար անձի) կողմից, այն անձի դիմումով, որի նկատմամբ ընդունված է որոշումը:
(288-րդ հոդվածը խմբ. 21.12.15 ՀՕ-178-Ն)
