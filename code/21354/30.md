# Հոդված 30. Անտառապատումը
1. Անտառապատումը, ոչ անտառածածկ անտառային հողերի, ինչպես նաև այլ նպատակային նշանակության հողերի վրա տնկման և ցանքի միջոցով արհեստական անտառային մշակույթների հիմնադրումն ու աճեցումն է:
2. Ոչ անտառածածկ անտառային հողերի անտառապատումն իրականացվում է անտառաշինական նախագծերի, անտառավերականգնման և անտառապատման իրականացման կարգի և անտառատնկարկներն անտառի շարք փոխադրելու կարգի համաձայն:
3. (մասն ուժը կորցրել է 25.05.22 ՀՕ-141-Ն)
