# Հոդված 27. Ջրօգտագործման թույլտվության վավերությունը
Ջրօգտագործման թույլտվությունը վավեր է, եթե այն ստորագրված է Ջրային ռեսուրսների կառավարման և պահպանության մարմնի ղեկավարի կողմից և գրանցված է պետական ջրային կադաստրում:
Ջրօգտագործման թույլտվության յուրաքանչյուր կողմ պարտավոր է կատարել ջրօգտագործման թույլտվությամբ սահմանված պարտավորությունները:
Ջրօգտագործման բոլոր թույլտվությունները պետք է լինեն գրավոր՝ Ջրային ռեսուրսների կառավարման և պահպանության մարմնի սահմանած ձևաթղթին համապատասխան:
