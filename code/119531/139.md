# Հոդված 139. Դատավորների գործունեության գնահատման կարգը
1. Դատավորների գործունեության գնահատումն իրականացնում է Բարձրագույն դատական խորհուրդը՝ սույն օրենսգրքով սահմանված չափանիշների հիման վրա:
2. Բարձրագույն դատական խորհուրդը սահմանում է դատավորների գործունեության գնահատման մեթոդաբանությունը, գնահատման համար անհրաժեշտ տվյալների հավաքման կարգը և դատավորների գործունեության գնահատման համար անհրաժեշտ այլ մանրամասները:
3. Բարձրագույն դատական խորհուրդը սահմանում է դատավորների գործունեությունը գնահատելու հերթական ժամանակացույցը՝ ըստ համապատասխան տարիների և դատավորների:
