# Հոդված 308. Վճարման կարգադրություն արձակելու գործերի ընդդատությունը
1. Վճարման կարգադրություն արձակելու գործն ընդդատյա է պարտապանի հաշվառման (գտնվելու) վայրի առաջին ատյանի դատարանին:
(հոդվածը 23.12.22 ՀՕ-576-Ն օրենքի փոփոխությամբ ուժի մեջ է մտնում վճարման կարգադրություն արձակելու վերաբերյալ դիմումը նոտարին էլեկտրոնային եղանակով ներկայացնելու համար անհրաժեշտ էլեկտրոնային համակարգի գործարկմանը հաջորդող օրվանից)
(23.12.22 ՀՕ-576-Ն օրենքն ունի անցումային դրույթ և եզրափակիչ մաս)
