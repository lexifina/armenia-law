# Հոդված 118.1. Դատական ակտերի վերանայումը վճռաբեկության կարգով
1. Վճռաբեկ դատարանը բողոքի հիման վրա սույն օրենսգրքով կամ այլ օրենքներով նախատեսված դեպքերում և կարգով վերանայում է վարչական դատարանի կայացրած և օրինական ուժի մեջ չմտած դատական ակտերը, իսկ վարչական դատավարական օրենսդրությամբ նախատեսված բացառիկ դեպքերում` նաև օրինական ուժի մեջ մտած դատական ակտերը:
2. Միջանկյալ դատական ակտերի դեմ բերված վճռաբեկ բողոքները քննվում են առանց դատական նիստ հրավիրելու:
(118.1-րդ հոդվածը լրաց. 07.04.09 ՀՕ-99-Ն)
