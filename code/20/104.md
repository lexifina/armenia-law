# Հոդված 104. Նոր կառուցվող և վերակառուցվող էլեկտրատեղակայանքները գործող ցանցերին առանց էլեկտրաէներգետիկական համակարգում և էլեկտրասպառման ոլորտում տեխնիկական վերահսկողություն իրականացնող լիազորված պետական մարմնի գործարկման եզրակացության միացնելը
Նոր կառուցվող և վերակառուցվող էլեկտրատեղակայանքները գործող ցանցերին առանց էլեկտրաէներգետիկական համակարգում և էլեկտրասպառման ոլորտում տեխնիկական վերահսկողություն իրականացնող լիազորված պետական մարմնի գործարկման եզրակացության միացնելը`
