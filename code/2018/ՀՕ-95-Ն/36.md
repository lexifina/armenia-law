# Հոդված 36. Դատական դեպարտամենտը
1. Բարձրագույն դատական խորհուրդը ձևավորում է իր աշխատակազմը՝ Դատական դեպարտամենտը, որն ապահովում է Բարձրագույն դատական խորհրդի, դատարանների, Ընդհանուր ժողովի և նրա հանձնաժողովների գործունեությունը:
2. Բարձրագույն դատական խորհրդի գործունեությունն ապահովում է Դատական դեպարտամենտի կենտրոնական մարմինը:
