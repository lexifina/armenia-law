# Հոդված 209. Երաշխիքները և հատուցումները ծառայողական գործուղումների դեպքում
1. Ծառայողական գործուղման մեկնած աշխատողներին երաշխավորվում է նրանց աշխատատեղի (պաշտոնի) և աշխատավարձի պահպանումը գործուղման ամբողջ ժամանակահատվածում, ինչպես նաև նրանց վճարվում է օրապահիկ, և հատուցվում են գործուղման հետ կապված ծախսերը:
2. Այդ վճարումների նվազագույն չափը և կարգը սահմանում է Հայաստանի Հանրապետության կառավարությունը: Պետական կամ համայնքի բյուջեների միջոցներից հատկացվող գործուղման ծախսերի վճարման դեպքում Հայաստանի Հանրապետության կառավարությունը սահմանում է նաև հատուցման առավելագույն չափը:
3. Մինչև տասնութ տարեկան աշխատողին արգելվում է ուղարկել ծառայողական գործուղման: Հղի կանայք և մինչև մեկ տարեկան երեխա խնամող աշխատողը կարող են ծառայողական գործուղման ուղարկվել միայն իրենց համաձայնությամբ:
