# Հոդված 167. Վճռաբեկ դատարանում գործի քննության հետաձգումը, գործի վարույթը կասեցնելը
1. Վճռաբեկ դատարանում գործի քննության հետաձգումը կատարվում է սույն օրենսգրքի 106-րդ հոդվածով սահմանված դեպքերում և կարգով։
2. Վճռաբեկ դատարանում գործի վարույթի կասեցման վրա տարածվում են սույն օրենսգրքի 94-րդ և 95-րդ հոդվածների կանոնները։
