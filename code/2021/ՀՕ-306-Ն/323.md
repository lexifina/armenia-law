# Հոդված 323. Հիմնական դատալսումների սկիզբը
1. Հիմնական դատալսումներն սկսվում են սույն օրենսգրքի 266-րդ հոդվածի 2-րդ մասով սահմանված կարգով դատական նիստը բացելով և դատաքննության մասնակիցների վերաբերյալ հաղորդումը լսելով: Այնուհետև նախագահողը կարգադրում է դատական նիստի ներկայացած վկաներին մինչև նրանց հարցաքննությունը լքել դահլիճը, իսկ դատական կարգադրիչներին հանձնարարում է միջոցներ ձեռնարկել, որ չհարցաքննված վկաները չհաղորդակցվեն արդեն հարցաքննված վկաների, ինչպես նաև դատական նիստերի դահլիճում գտնվող այլ անձանց հետ:
