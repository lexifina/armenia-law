# Հոդված 310. ԴԱՏԱԿԱՆ ՔՆՆՈՒԹՅԱՆ ՀԵՏԱՁԳՈՒՄԸ և ՔՐԵԱԿԱՆ ԳՈՐԾՈՎ ՎԱՐՈՒՅԹԻ ԿԱՍԵՑՈՒՄԸ
1. Դատական նիստին կանչված անձերից որևէ մեկի չներկայանալու կամ կողմերի միջնորդությամբ կամ դատարանի նախաձեռնությամբ նոր ապացույցներ պահանջվելու անհրաժեշտության հետևանքով գործի քննությունը հնարավոր չլինելու դեպքում դատարանը հետաձգում է քննությունը և միջոցներ է ձեռնարկում չներկայացած անձանց ներկայությունն ապահովելու կամ նոր ապացույցներ պահանջելու համար: Այդ դեպքում դատարանը սահմանում է ժամկետ, որով հետաձգվում է գործի քննությունը:
2.
