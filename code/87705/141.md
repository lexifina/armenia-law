# Հոդված 141. Գործի քննության կարգը վերաքննիչ դատարանում
1. Գործն ըստ էության լուծող դատական ակտի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են կոլեգիալ` 3 դատավորի կազմով, իսկ նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու և հանրության գերակա շահ ճանաչելու վերաբերյալ Կառավարության որոշումների իրավաչափությունը վիճարկելու վերաբերյալ գործերով բերված բողոքները` 5 դատավորի կազմով։
2. Վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են միանձնյա, իսկ նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու և հանրության գերակա շահ ճանաչելու վերաբերյալ Կառավարության որոշումների իրավաչափությունը վիճարկելու վերաբերյալ գործերով վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վերաքննիչ բողոքները՝ 5 դատավորի կազմով։
3. Վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են առանց դատական նիստ հրավիրելու։
(141-րդ հոդվածը լրաց. 30.07.21 ՀՕ-312-Ն, 11.02.26 ՀՕ-30-Ն)
