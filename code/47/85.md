# Հոդված 85. Աշխատանքն ուղղիչ հիմնարկում
1. Դատապարտյալը հնարավորության դեպքում ապահովվում է աշխատանքով կամ նրան իրավունք է վերապահվում ինքնուրույն իրեն ապահովելու աշխատանքով, որի կարգը և պայմանները սահմանվում են ուղղիչ հիմնարկների ներքին կանոնակարգով: Դատապարտյալին աշխատանքի ներգրավելիս ուղղիչ հիմնարկի վարչակազմը պարտավոր է հաշվի առնել նրա սեռը, տարիքը, աշխատունակությունը, առողջական վիճակը և հնարավորինս՝ մասնագիտությունը։ Դատապարտյալի աշխատանքային գործունեությունը չպետք է խոչընդոտի ուղղիչ հիմնարկի առջև դրված խնդիրներն իրականացնելուն:
