# Հոդված 93. Խաբեության կամ վստահությունն ի չարը գործադրելու միջոցով գույքին վնաս պատճառելը
Խաբեության կամ վստահությունը ի չարը գործադրելու միջոցով գույքային վնաս պատճառելը, եթե չկան հափշտակման հատկանիշներ`
պատժվում է տուգանքով երկու հազարից մինչև հինգ հազար դրամ կամ պաշտոնանկությամբ:
Նույն գործողությունները, որոնք պատճառել են խոշոր չափերի վնաս` պատժվում են ազատազրկմամբ մեկից մինչև երկու տարի ժամանակով` անձնական գույքի բռնագրավմամբ:
(29.12.82, 11.05.92 խմբագրությամբ)
