# Հոդված 224. Վճռաբեկ բողոքներով գործերը քննող դատարանը
Առաջին ատյանի դատարանների և վերաքննիչ դատարանի` օրինական ուժի մեջ մտած և վերաքննիչ դատարանի օրինական ուժի մեջ չմտած վճիռների դեմ բերված վճռաբեկ բողոքներով գործերը քննում է վճռաբեկ դատարանի քաղաքացիական և տնտեսական գործերի պալատը (այսուհետ` վճռաբեկ դատարան): (224-րդ հոդվածը լրաց. 13.06.00 ՀՕ-71)
