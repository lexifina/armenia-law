# Հոդված 147. Հայրության (մայրության) որոշումը և վիճարկումը
Հայաստանի Հանրապետության տարածքում հայրության (մայրության) որոշումը և վիճարկումն իրականացվում է Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով։ Այն դեպքերում, երբ Հայաստանի Հանրապետության օրենսդրությամբ թույլատրվում է հայրության (մայրության) որոշումը քաղաքացիական կացության ակտերի պետական գրանցում իրականացնող մարմիններում, երեխայի՝ Հայաստանի Հանրապետության տարածքից դուրս ապրող ծնողները, որոնցից թեկուզ մեկը համարվում է Հայաստանի Հանրապետության քաղաքացի, կարող են հայրությունը (մայրությունը) որոշելու մասին հայտարարությամբ դիմել Հայաստանի Հանրապետության հյուպատոսական հիմնարկներ։
(հոդվածը 19.01.21 ՀՕ-67-Ն օրենքի փոփոխությամբ ուժի մեջ կմտնի 16.05.21 թվականին)
