# Հոդված 408. Նախընտրական քարոզչություն կատարելու իրավունք չունեցող անձանց կողմից նախընտրական քարոզչություն կատարելը և քարոզչական նյութեր տարածելը
Նախընտրական քարոզչության իրականացման համար օրենքով սահմանված ժամանակահատվածում նախընտրական քարոզչություն կատարելու իրավունք չունեցող անձանց կողմից նախընտրական քարոզչություն կատարելը և ցանկացած բնույթի քարոզչական նյութ տարածելը`
