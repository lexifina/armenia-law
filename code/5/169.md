# Հոդված 169. Ցանքերի արածավերումը
Ցանքերի դիտավորյալ արածավերումը, ինչպես նաև դաշտապաշտպան անտառատնկուտների, պտղահատապտղային և այլ տնկուտների դիտավորյալ փչացումը, որը զգալի վնաս է պատճառել կոլտնտեսությանը, սովխոզին, կամ այլ պետական կամ հասարակական տնտեսությանը`
պատժվում են ազատազրկմամբ մինչև մեկ տարի ժամանակով, կամ ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով, կամ տուգանքով մինչև երեք հարյուր դրամ:
(29.12.82 խմբագրությամբ)
