# Հոդված 96. Ջրային համակարգերի օգտագործումը և պահպանությունն արտակարգ էկոլոգիական իրավիճակում
Ջրային համակարգի կամ դրա մասի վերաբերյալ հայտարարվում է արտակարգ էկոլոգիական իրավիճակ, եթե տեղի են ունենում այնպիսի փոփոխություններ, որոնք կարող են վտանգել մարդկանց առողջությունը և (կամ) բնական միջավայրի կայունությունը:
Ջրային համակարգի կառավարիչը, կառավարության հաստատած հրահանգի համաձայն, գործողություններ է իրականացնում՝
1) արտակարգ իրավիճակի տարածքը տեղայնացնելու,
2) ջրերը մաքրելու,
3) արտակարգ իրավիճակի հետևանքները նվազագույնի հասցնելու և վերացնելու ուղղությամբ:
