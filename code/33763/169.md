# Հոդված 169. Արդարադատության խորհրդի առաջարկի հիման վրա դատավորին որպես մեղադրյալ ներգրավելու համաձայնություն տալու դեպքում դատավորի լիազորությունների կասեցումը
1. Արդարադատության խորհրդի առաջարկի հիման վրա Հանրապետության Նախագահի կողմից դատավորին որպես մեղադրյալ ներգրավելու համաձայնություն տալու դեպքում դատավորի լիազորությունները համարվում են կասեցված` նախաքննության և դատաքննության ժամկետով: (նախադասությունները հանվել են. 10.06.14 ՀՕ-47-Ն) Դատավորի նկատմամբ հարուցված քրեական գործի կասեցման դեպքում դատավորը շարունակում է իրականացնել իր լիազորությունները մինչև քրեական գործի վերսկսման մասին որոշման կայացումը:
2. Դատավորի լիազորությունների կասեցման ընթացքում դատավորը ստանում է հատուցում` որպես ոչ աշխատողի մեղքով պարապուրդում գտնվող:
(169-րդ հոդվածը փոփ. 10.06.14 ՀՕ-47-Ն)
