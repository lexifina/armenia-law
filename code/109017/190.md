# Հոդված 190. Հայաստանի Հանրապետության ընդհանուր օգտագործման պետական ավտոմոբիլային ճանապարհներին գովազդ տեղադրելու համար ճանապարհային հարկի դրույքաչափերը
1. Հայաստանի Հանրապետության ընդհանուր օգտագործման պետական ավտոմոբիլային ճանապարհներին գովազդ տեղադրելու համար ճանապարհային հարկը հաշվարկվում է հետևյալ տարեկան դրույքաչափերով.
1) միջպետական նշանակության ավտոմոբիլային ճանապարհներին (այդ թվում` համայնքների վարչական սահմանների միջով անցնող տարանցիկ հատվածներում), ինչպես նաև այդ ճանապարհների օտարման շերտերում և պաշտպանական գոտիներում տեղադրվող գովազդային վահանակի մակերեսի յուրաքանչյուր քառակուսի մետրի համար` 10000 դրամ.
2) հանրապետական և մարզային նշանակության ավտոմոբիլային ճանապարհներին (այդ թվում` համայնքների վարչական սահմանների միջով անցնող տարանցիկ հատվածներում), ինչպես նաև այդ ճանապարհների օտարման շերտերում և պաշտպանական գոտիներում տեղադրվող գովազդային վահանակի մակերեսի յուրաքանչյուր քառակուսի մետրի համար` 7500 դրամ:
