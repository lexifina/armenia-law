# Հոդված 223.3. Հեռուստատեսության և ռադիոյի հանձնաժողովը
1․ Հեռուստատեսության և ռադիոյի հանձնաժողովը քննում է սույն օրենսգրքի 182.5-րդ հոդվածի 5-րդ, 7-րդ և 14-րդ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը, եթե դրանք վերաբերում են տեսալսողական մեդիածառայություն մատուցող լրատվական գործունեություն իրականացնողներին:
