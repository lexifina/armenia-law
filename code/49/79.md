# Հոդված 79. Ամուսիններից և նախկին ամուսիններից դատական կարգով բռնագանձվող ալիմենտի չափը
Ամուսինների (նախկին ամուսինների) միջև ալիմենտ վճարելու վերաբերյալ համաձայնության բացակայության դեպքում ամուսնուց (նախկին ամուսնուց) դատական կարգով բռնագանձվող ալիմենտի չափը` կայուն դրամական գումարով, որոշում է դատարանը` ելնելով ամուսինների (նախկին ամուսինների) գույքային ու ընտանեկան դրությունից և ուշադրության արժանի շահերից: Դա ենթակա է վճարման յուրաքանչյուր ամիս։
