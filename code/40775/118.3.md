# Հոդված 118.3. Վճռաբեկ բողոք բերելու ժամկետները
1. Գործն ըստ էության լուծող դատական ակտի դեմ վճռաբեկ բողոք կարող է բերվել մինչև այդ ակտի oրինական ուժի մեջ մտնելու համար սահմանված ժամկետը, բացառությամբ նոր կամ նոր երևան եկած հանգամանքների հիմքով կամ սույն հոդվածի 3-րդ կետով նախատեսված հիմքով դատական ակտը բողոքարկելու դեպքերի։
2. Միջանկյալ դատական ակտի դեմ վճռաբեկ բողոք կարող է բերվել միայն սույն oրենսգրքով նախատեսված դեպքերում` այն ստանալու պահից տասնհինգoրյա ժամկետում, եթե սույն oրենսգրքով կամ այլ oրենքով այլ ժամկետ սահմանված չէ։
3. Դատավարության մասնակից չդարձված այն անձինք, որոնց իրավունքների և պարտականությունների վերաբերյալ կայացվել է վերաքննիչ դատարանի գործն ըստ էության լուծող դատական ակտ, իրավունք ունեն վճռաբեկ բողոք բերելու` սկսած այն oրվանից` երեք ամսվա ընթացքում, երբ իմացել են կամ կարող էին իմանալ նման դատական ակտի կայացման մասին։
Սույն մասի առաջին պարբերությամբ նախատեսված դեպքում վերաքննիչ բողոք չի կարող բերվել, երբ դատական ակտի օրինական ուժի մեջ մտնելուց հետո անցել է քսան տարի։
