# Հոդված 140. Քվեաթերթիկները
1. Քվեաթերթիկի ձախ կողմում նշվում են կուսակցությունների անվանումները` ըստ այբբենական հերթականության, և ընտրական ցուցակի առաջին երեք թեկնածուների ազգանունները, անունները և հայրանունները, իսկ աջ կողմում նախատեսվում են դատարկ քառանկյուններ` ընտրողի կողմից նշում կատարելու համար:
(հոդվածը 07.05.21 ՀՕ-202-Ն օրենքի փոփոխությամբ ուժի մեջ կմտնի 01.01.2022 թվականին, իսկ մասը տեղական ինքնակառավարման մարմինների ընտրություններին վերաբերելի մասով ուժի մեջ կմտնի 26.06.21-ին` համաձայն նույն օրենքի 104-րդ հոդվածի 3-րդ մասի)
(07.05.21 ՀՕ-202-Ն օրենքն ունի անցումային դրույթ)
