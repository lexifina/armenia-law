# Հոդված 505.1. Հանրային պաշտպանի գրասենյակին կեղծ հայտարարագիր ներկայացնելը
1. «Փաստաբանության մասին» օրենքով նախատեսված դեպքերում անվճար իրավաբանական օգնություն ստանալու համար հանրային պաշտպանի գրասենյակ դիմելիս ներկայացված գրավոր հայտարարագրում կեղծ տվյալ ներառելը կամ ներկայացման ենթակա տվյալը թաքցնելը՝
պատժվում է տուգանքով՝ առավելագույնը քսանապատիկի չափով, կամ հանրային աշխատանքներով՝ ութսունից հարյուր հիսուն ժամ տևողությամբ, կամ ազատության սահմանափակմամբ` առավելագույնը երկու տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ` առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ առավելագույնը երկու տարի ժամկետով:
(505.1-ին հոդվածը լրաց. 05.10.22 ՀՕ-367-Ն)
