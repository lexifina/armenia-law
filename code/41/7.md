# Հոդված 7. Սույն օրենսգրքի խնդիրները
Սույն օրենսգրքի խնդիրներն են՝
1) ջրային ռեսուրսների կառավարման համապատասխան մեխանիզմների ստեղծումը.
2) ջրային ռեսուրսների պահպանումն ու պաշտպանությունը` ապահովելով աղտոտման նվազեցումը, ջրերի ստանդարտների ու ազգային ջրային պաշարի մակարդակի պահպանումը և վերահսկողության իրականացումը.
3) ջրերի վնասակար ներգործության կանխարգելումը.
4) ջրային ռեսուրսների հաշվառման ապահովումը.
5) բնակչությանն ու տնտեսությանը կարգավորվող սակագներով անհրաժեշտ քանակի և որակի ջրով ապահովումը.
6) ջրամատակարարման և ջրահեռացման համակարգերի անվտանգ ու անխափան աշխատանքը և դրանց օգտագործման ու պահպանման բնականոն պայմանների ապահովումը և վերահսկողության իրականացումը.
7) ՀՏԿ-ների անվտանգ և անխափան օգտագործման ու պահպանման պայմանների ապահովումը և վերահսկողության իրականացումը.
