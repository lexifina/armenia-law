# Հոդված 443. Ապօրինի հարստանալը
1. Ապօրինի հարստանալը՝ Կոռուպցիայի կանխարգելման հանձնաժողով հայտարարագիր ներկայացնելու պարտականություն ունեցող անձի՝ հաշվետու ժամանակահատվածում գույքի ավելացումը, պարտավորությունների նվազումը կամ ծախսը, որոնք էականորեն գերազանցում են նրա օրինական եկամուտները և ողջամտորեն չեն հիմնավորվում դրանցով, եթե ապօրինի հարստացման համար հիմք հանդիսացող այլ հանցանքի հատկանիշները բացակայում են՝
պատժվում է ազատազրկմամբ՝ երեքից վեց տարի ժամկետով:
2. Սույն հոդվածում էական է համարվում 3 միլիոն Հայաստանի Հանրապետության դրամը գերազանցող գումարը (արժեքը):
3. Սույն հոդվածի իմաստով՝ Կոռուպցիայի կանխարգելման հանձնաժողով հայտարարագիր ներկայացնելու պարտականություն ունեցող անձ են համարվում «Հանրային ծառայության մասին» օրենքի իմաստով` հայտարարատու պաշտոնատար անձինք, նրանց ընտանիքի անդամները, «Կուսակցությունների մասին» սահմանադրական օրենքի իմաստով` հայտարարատու պաշտոնատար անձինք, ինչպես նաև պաշտոնեական պարտականությունների դադարեցումից հետո՝ երկու տարվա ընթացքում, Կոռուպցիայի կանխարգելման հանձնաժողովի պահանջով իրավիճակային հայտարարագիր ներկայացնող պաշտոնատար անձինք:
(443-րդ հոդվածը խմբ., լրաց. 25.03.26 ՀՕ-132-Ն)
