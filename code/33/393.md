# Հոդված 393. Դատական ակտ ԿԱՅԱՑՆԵԼԸ
(վերնագիրը փոփ. 28.11.07 ՀՕ-270-Ն)
1. Բողոքը քննելու արդյունքում` վերաքննիչ դատարանը կայացնում է դատական ակտ, որն ամբողջությամբ կամ մասամբ փոխարինում է առաջին ատյանի դատարանի դատական ակտին:
2. Վերաքննիչ դատարանը դատական ակտը կայացնում է սույն օրենսգրքով սահմանված ընդհանուր կանոններով` հաշվի առնելով սույն հոդվածում շարադրված պահանջները:
3. Վերաքննիչ դատարանը գործը կոլեգիալ կազմով քննելիս դատական ակտը կայացնում է սույն օրենսգրքի 361¹ հոդվածով սահմանված կանոններով` հաշվի առնելով սույն հոդվածում շարադրված պահանջները:
4. Վերաքննիչ դատարանի դատական ակտում պետք է նշվեն, թե ինչ հիմքերով է առաջին ատյանի դատարանի դատական ակտը համարվում ճիշտ, իսկ բողոքում բերված եզրահանգումները` անհիմն, ինչն է հիմք ծառայել առաջին ատյանի դատարանի դատական ակտն ամբողջությամբ կամ մի մասով բեկանելու կամ փոխելու համար:
