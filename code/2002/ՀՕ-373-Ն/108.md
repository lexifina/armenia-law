# Հոդված 108. Ջրհավաք ավազանները
Ջրհավաք ավազաններում արգելվում է՝
1) սառցածածկույթների, սառույցների, ձնածածկույթների և հարող տարածքների աղբոտումն արտադրական, կենցաղային կամ այլ թափոններով, ինչպես նաև դրանց աղտոտումը նավթամթերքով, թունաքիմիկատներով և վնասակար այլ նյութերով.
2) ջրային ռեսուրսների որակի վրա անուղղակի վնասակար ազդեցություն ունեցող թափոնների թաղման տեղամասերի, աղբանոցների, գերեզմանոցների և այլ օբյեկտների տեղադրումը.
3) ջրապահպան գոտիների անտառներում փայտանյութի պատրաստումը, բացառությամբ ծառերի սանիտարական հատումների, ինչպես նաև անտառային գործունեության իրականացման և ջրային ռեսուրսների պահպանության դեպքերի:
