# Հոդված 108. Բույսերի կարանտին վնասակար օրգանիզմների դեմ պայքարի կանոնները խախտելը
(վերնագիրը խմբ. 25.10.23 ՀՕ-343-Ն)
Բույսերի կարանտին վնասակար օրգանիզմների դեմ պայքարի կանոնները խախտելը՝
