# Հոդված 141. Գործի քննության կարգը վերաքննիչ դատարանում
1. Գործն ըստ էության լուծող դատական ակտի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են կոլեգիալ` 3 դատավորի կազմով, իսկ նորմատիվ իրավական ակտերի իրավաչափությունը վիճարկելու վերաբերյալ գործերով բերված բողոքները` 5 դատավորի կազմով։
2. Վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են միանձնյա։
3. Վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վերաքննիչ բողոքները քննվում և որոշումները կայացվում են առանց դատական նիստ հրավիրելու։
