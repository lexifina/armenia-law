# Հոդված 170⁸. Ակցիզային դրոշմանիշերով և (կամ) հսկիչ նշաններով (դրոշմապիտակներով) դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) ապրանքներ իրացնելը
Ակցիզային դրոշմանիշերով և (կամ) հսկիչ նշաններով (դրոշմապիտակներով) դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) ապրանքներ իրացնելը, եթե դրանց ընդհանուր արժեքը վաճառողի մոտ նշված (իսկ չնշված լինելու դեպքում` օրենսդրությամբ սահմանված կարգով որոշված) գներով չի գերազանցում հիսուն հազար դրամը`
