# Հոդված 74. Ընդերքի օգտագործումն ու պահպանությունն իրականացնող պետական մարմինը
1. Ընդերքի օգտագործման և պահպանության պետական վերահսկողության իրականացումն ապահովում է լիազոր մարմինը` ընդերքի պետական տեսչական համակարգի միջոցով, որի կառուցվածքը սահմանում է կառավարությունը:
2. Ընդերքի պետական տեսչական համակարգն ընդերքի պետական տեսչության կառուցվածքային և տարածքային ստորաբաժանումների ամբողջությունն է:
3. Տարածքային ստորաբաժանումներն ընդերքօգտագործման վերաբերյալ օրենսդրության պահանջների կատարման նկատմամբ վարչատարածքային սկզբունքով վերահսկողական գործառույթներ իրականացնող կառույցներն են:
