# Հոդված 373. Վերաքննիչ բողոքից հրաժարվելը
1. Վերաքննիչ բողոքը վարույթ ընդունելուց հետո մինչև բողոքի քննության ավարտի մասին հայտարարելը վերաքննիչ բողոք բերած անձն իրավունք ունի դիմում ներկայացնելու վերաքննիչ բողոքից հրաժարվելու մասին։
2. Բողոք բերած անձի կողմից վերաքննիչ բողոքից հրաժարվելու դեպքում վերաքննիչ դատարանը կայացնում է վերաքննիչ վարույթը կարճելու մասին որոշում։ Եթե դատական ակտը բողոքարկել են նաև այլ անձինք, ապա վարույթը կարճվում է միայն տվյալ բողոքի մասով:
3. Վերաքննիչ վարույթը կարճելու մասին վերաքննիչ դատարանի որոշման կայացման պահից առաջին ատյանի դատարանի դատական ակտը մտնում է օրինական ուժի մեջ, եթե այն չեն բողոքարկել այլ անձինք:
4. Վերաքննիչ վարույթը կարճելու մասին վերաքննիչ դատարանի որոշմամբ վերաքննիչ վարույթի հետ կապված դատական ծախսերը դրվում են վերաքննիչ բողոքից հրաժարված անձի վրա, բացառությամբ սույն օրենսգրքի 109-րդ հոդվածի 2-րդ մասում նշված դեպքերի:
