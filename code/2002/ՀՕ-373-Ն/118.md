# Հոդված 118. Հուսալիության երաշխիքները
Սույն օրենսգրքի պահանջներն ապահովելու համար սույն օրենսգրքով լիազորված մարմինները կարող են պահանջել պատշաճ հուսալիության երաշխիք: Հուսալիության երաշխիքը կարող է լինել որևէ բանկից վարկի տրամադրման մասին երաշխավորագրի, բանկային երաշխիքի, ապահովագրության կամ հուսալիության ապահովման որևէ այլ ընդունված փաստաթղթի տեսքով:
(118-րդ հոդվածը խմբ. 23.06.15 ՀՕ-108-Ն)
