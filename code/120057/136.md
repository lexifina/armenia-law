# Հոդված 136. Հայցի ապահովման միջոցների պահպանումը
1. Հայցը բավարարելու մասին վճիռ կայացվելու դեպքում հայցի ապահովման միջոցները պահպանվում են մինչև վճռի կատարումը: Հայցը բավարարելու մասին վճռի կայացումից հետո հայցի ապահովման միջոցը դատարանի որոշմամբ կարող է վերացվել հայցի ապահովում պահանջած անձի միջնորդությամբ:
2. Հայցը մերժելու մասին վճիռ կայացվելու դեպքում հայցի ապահովման միջոցները պահպանվում են մինչև վճռի օրինական ուժի մեջ մտնելը:
3. Հայցը մասնակիորեն բավարարվելու դեպքում դատարանը, ելնելով գործի հանգամանքներից, լուծում է հայցի ապահովման միջոցն ամբողջությամբ կամ մասնակիորեն վերացնելու հարցը:
