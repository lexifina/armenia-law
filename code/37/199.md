# Հոդված 199. Հետագա արտահանման կամ հետագա ներմուծման պարտավորությունների խախտումը
1. Հետագա արտահանման պարտավորությամբ Հայաստանի Հանրապետություն ներմուծված ապրանքները և տրանսպորտային միջոցները սահմանված ժամկետում չարտահանելը կամ հետագա ներմուծման պարտավորությամբ արտահանված ապրանքները և տրանսպորտային միջոցները սահմանված ժամկետում Հայաստանի Հանրապետություն չվերադարձնելը`
