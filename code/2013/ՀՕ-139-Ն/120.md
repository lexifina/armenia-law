# Հոդված 120. Արագացված դատաքննություն կիրառելու մասին դատարանի որոշումը
1. Արագացված դատաքննություն կիրառելու մասին դատարանը կայացնում է որոշում, որի մասին եռօրյա ժամկետում ծանուցվում են դատավարության մասնակիցները:
2. Արագացված դատաքննություն կիրառելու մասին որոշում կարող է կայացվել գործի քննության յուրաքանչյուր փուլում։
