# Հոդված 243. ՓՈՐՁԱՔՆՆՈՒԹՅՈՒՆ ՆՇԱՆԱԿԵԼՈՒ և ԿԱՏԱՐԵԼՈՒ ՀԻՄՔԵՐԸ
