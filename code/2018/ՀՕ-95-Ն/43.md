# Հոդված 43. Վերաքննիչ դատարանում գործերի բաշխումը
1. Կոլեգիալ և միանձնյա կարգով քննվող գործերը Համակարգչային ծրագրում մուտքագրվում և բաշխվում են միմյանցից առանձին:
2. Ձևավորված դատական կազմերը փոփոխվում են յուրաքանչյուր տարվա հունվարի 1-ի դրությամբ:
2.1. Վերաքննիչ հակակոռուպցիոն դատարանում կոռուպցիոն հանցագործությունների գործերով կայացված ակտերի վերանայման գործերը բաշխվում են միայն կոռուպցիոն հանցագործությունների քննության մասնագիտացմամբ, իսկ հակակոռուպցիոն քաղաքացիական գործերով կայացված ակտերի վերանայման գործերը՝ միայն հակակոռուպցիոն քաղաքացիական գործերի քննության մասնագիտացմամբ դատավորների միջև:
