# Հոդված 237. Լրագրողի մասնագիտական օրինական գործունեությունը խոչընդոտելը
1. Լրագրողին տեղեկություն տարածելուն կամ տարածելուց հրաժարվելուն հարկադրելը կամ նրա մասնագիտական օրինական գործունեությունն այլ կերպ խոչընդոտելը՝
պատժվում է տուգանքով` առավելագույնը քսանապատիկի չափով, կամ հանրային աշխատանքներով` ութսունից հարյուր հիսուն ժամ տևողությամբ, կամ որոշակի պաշտոններ զբաղեցնելու կամ որոշակի գործունեությամբ զբաղվելու իրավունքից զրկելով` առավելագույնը երեք տարի ժամկետով, կամ ազատության սահմանափակմամբ` առավելագույնը երկու տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ առավելագույնը երկու տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը կատարվել է իշխանական կամ ծառայողական լիազորությունները կամ դրանցով պայմանավորված ազդեցությունն օգտագործելով`
պատժվում է տուգանքով` քսանապատիկից հիսնապատիկի չափով, կամ հանրային աշխատանքներով` հարյուր հիսունից երկու հարյուր յոթանասուն ժամ տևողությամբ, կամ որոշակի պաշտոններ զբաղեցնելու կամ որոշակի գործունեությամբ զբաղվելու իրավունքից զրկելով` երեքից յոթ տարի ժամկետով, կամ ազատության սահմանափակմամբ` մեկից երեք տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ` մեկից երկու ամիս ժամկետով, կամ ազատազրկմամբ` երկուսից հինգ տարի ժամկետով:
