# Հոդված 112⁷. Պարտադիր հակահամաճարակային կանխարգելիչ (կենդանիների ախտորոշում, պատվաստում) միջոցառումները ոչ լիարժեք իրականացնելը և դրանցից հրաժարվելը
Պարտադիր հակահամաճարակային կանխարգելիչ (կենդանիների ախտորոշում, պատվաստում) միջոցառումները ոչ լիարժեք իրականացնելը և դրանցից հրաժարվելը, որը կարող է հիվանդությունների առաջացման պատճառ դառնալ`
առաջացնում է տուգանքի նշանակում ֆիզիկական անձանց նկատմամբ` սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով, պաշտոնատար անձանց նկատմամբ` հարյուրապատիկի չափով:
Տուգանքի վճարումը ֆիզիկական և պաշտոնատար անձանց չի ազատում թույլ տված խախտումները վերացնելու պարտականությունից:
(112⁷ հոդվածը լրաց. 04.05.05 ՀՕ-93-Ն)
