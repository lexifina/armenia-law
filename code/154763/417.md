# Հոդված 417. Անչափահասին վերագրվող հանցանքի վերաբերյալ դատական վարույթի առանձնահատկությունները
1. Անչափահասին վերագրվող հանցանքի վերաբերյալ վարույթով դատական նիստերն անցկացվում են դռնփակ:
2. Դռնբաց դատական նիստ կարող է անցկացվել միայն անչափահաս մեղադրյալի, նրա պաշտպանի կամ օրինական ներկայացուցչի միջնորդությամբ, եթե դա ինքնին չի վնասի անչափահասի իրավաչափ շահերին: Ամեն դեպքում, դռնբաց դատական նիստ անցկացնելիս դատարանը պարտավոր է միջոցներ ձեռնարկել անչափահաս մեղադրյալի իրավաչափ շահերը պաշտպանելու համար:
3. Կողմի միջնորդությամբ կամ իր նախաձեռնությամբ և հոգեբանի կարծիքը լսելուց հետո դատարանը կարող է որոշում կայացնել անչափահաս մեղադրյալին դատական նիստի դահլիճից հեռացնելու մասին, եթե հետազոտման ենթակա հանգամանքները կարող են նրա վրա բացասական ազդեցություն ունենալ:
4. Դատական նիստի դահլիճ մեղադրյալի վերադառնալուց հետո նախագահողը պաշտպանին հնարավորություն է ընձեռում մեղադրյալին առանձին պարզաբանելու կատարված գործողությունների բովանդակությունը, ինչպես նաև նրա հետ քննարկելու մեղադրյալի բացակայությամբ հարցաքննված անձանց հարցեր տալու անհրաժեշտությունը:
