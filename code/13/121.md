# Հոդված 121. Որդեգրողների գրանցումը որպես որդեգրվողի ծնողներ
Որդեգրողների խնդրանքով ծնունդների գրանցման մատյաններում նրանք կարող են գրանցվել որպես որդեգրվողի ծնողներ:
Տասը տարեկան դարձած որդեգրվողի նկատմամբ այդպիսի գրանցում կատարելու համար անհրաժեշտ է նրա համաձայնությունը, բացառությամբ սույն օրենսգրքի 117 հոդվածի երկրորդ մասով նախատեսված դեպքերի: Այդպիսի գրանցման մասին մատնանշվում է որդեգրման վերաբերյալ որոշման մեջ (սույն օրենսգրքի 112 հոդված):
