# Հոդված 170. Ջրօգտագործման կանոնները խախտելը
Ջրի ինքնագլուխ զավթումը ոռոգման ջրանցքների ափերը փորելու, ջրարգելակները բանալու, արտածծող առուներ կառուցելու, ստորերկրյա խողովակներ կամ այլ հարմարանքներ դնելու միջոցով, ինչպես նաև ջրօգտագործման կանոնների այլ խախտումը, եթե դա էական վնաս է պատճառել`
պատժվում է ազատազրկմամբ մինչև մեկ տարի ժամանակով, կամ ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով, կամ տուգանքով մինչև երկու հազար դրամ:
