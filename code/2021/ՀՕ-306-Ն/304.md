# Հոդված 304. Մինչդատական ակտի վիճարկման վարույթի արդյունքով կայացվող որոշումները
1. Մինչդատական ակտի վիճարկման վարույթի արդյունքով դատարանը որոշմամբ ամբողջությամբ կամ մասնակի բավարարում է բողոքը կամ մերժում է այն:
2. Ամեն դեպքում, բողոքը բավարարվում է, եթե վարույթի հանրային մասնակիցը չի ներկայացրել դատարանի պահանջած նյութերը: Բողոքը կարող է բավարարվել, եթե վարույթի հանրային մասնակիցը դատարանի պահանջով չի ներկայացել դատարան:
3. Բողոքը բավարարելու դեպքում դատարանը վարույթի հանրային մասնակցի վրա դնում է անձի իրավունքների խախտումը վերացնելուն ուղղված կոնկրետ վարութային ակտեր կայացնելու (կատարելու) պարտականություն:
4. Բանավոր ընթացակարգով բողոքի քննության դեպքում որոշման եզրափակիչ մասը հրապարակվում է դատական նիստում։ Որոշումն անհապաղ հանձնվում կամ ուղարկվում է բողոքը ներկայացրած անձին, վիճարկվող վարութային ակտը կայացրած (կատարած) հանրային մասնակցին, քննիչին և հսկող դատախազին:
