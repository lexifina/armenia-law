# Հոդված 189.18. Կրթական, գիտական և հետազոտական ծրագրերի շրջանակներում սովորողի կողմից ինքնուրույն կատարման ենթակա առաջադրանքները, հետազոտությունները և այլ գործնական աշխատանքները կատարելու, մշակելու, պատրաստելու ծառայությունների գովազդը
