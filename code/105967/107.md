# Հոդված 107. Համայնքի ղեկավարի և ավագանու անդամի թեկնածուներին առաջադրվող պահանջները
1. Համայնքի ղեկավար և ավագանու անդամ կարող են ընտրվել սույն օրենսգրքի 2-րդ հոդվածի համաձայն` տեղական ինքնակառավարման մարմինների ընտրության ժամանակ ընտրելու իրավունք ունեցող անձինք:
2. Համայնքի ղեկավարի և ավագանու անդամի թեկնածու չեն կարող առաջադրվել դատավորները, դատախազները, քննչական կոմիտեի, հատուկ քննչական, դատական ակտերի հարկադիր կատարման ծառայության ծառայողները, ոստիկանությունում, ազգային անվտանգությունում, փրկարարական, հարկային, մաքսային մարմիններում, քրեակատարողական ծառայությունում, պրոբացիայի ծառայությունում, փրկարար ծառայությունում ծառայողները, զինծառայողները, ընտրական հանձնաժողովների անդամները:
(107-րդ հոդվածը լրաց. 04.05.18 ՀՕ-318-Ն)
