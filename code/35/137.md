# Հոդված 137. Նոր ընտրություն նշանակելը և անցկացնելը
Համայնքի ղեկավար կամ ավագանու անդամ առաջադրված թեկնածուների ընտրությունները չկայացած ճանաչելու մասին ընտրատարածքային ընտրական հանձնաժողովի որոշումն ընդունելուց կամ դատարանի վճիռն օրինական ուժի մեջ մտնելուց հետո` երեսուներորդ օրը, անցկացվում է նոր ընտրություն: Նոր ընտրությունն անցկացվում է թեկնածուների նոր առաջադրմամբ` արտահերթ ընտրության համար սույն օրենսգրքի 138 հոդվածով սահմանված կարգով:
