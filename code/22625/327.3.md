# Հոդված 327³. Այլընտրանքային աշխատանքային ծառայողի կողմից անդամախեղվելու, հիվանդության սիմուլյացիայի կամ ապօրինի այլ եղանակով այլընտրանքային աշխատանքային ծառայությունից խուսափելը
