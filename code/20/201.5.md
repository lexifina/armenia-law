# Հոդված 201.5. Թափոնների գոյացման, վերամշակման և օգտահանման օբյեկտների ռեեստրային գրանցման հաշվետվություն չներկայացնելը
Թափոնների գոյացման, վերամշակման և օգտահանման օբյեկտների ռեեստրային գրանցման հաշվետվություն սահմանված կարգով չներկայացնելը՝
առաջացնում է տուգանքի նշանակում ֆիզիկական անձանց և անհատ ձեռնարկատերերի նկատմամբ՝ սահմանված նվազագույն աշխատավարձի երեսնապատիկի չափով, իսկ իրավաբանական անձանց նկատմամբ՝ հիսնապատիկի չափով:
(201.5-րդ հոդվածը լրաց. 22.06.15 ՀՕ-107-Ն)
Հոդված 201.6․ | Չափումների, հաշվետվողականության և հավաստագրման համակարգում ներառման նպատակով «Կլիմայի մասին» օրենքի 27-րդ հոդվածի 3-րդ մասի 3-րդ կետով նախատեսված ջերմոցային գազեր արտանետող իրավաբանական անձանց և անհատ ձեռնարկատերերի կողմից տվյալներ չտրամադրելը կամ ոչ հավաստի տվյալներ տրամադրելը կամ ժամկետի խախտմամբ տվյալներ տրամադրելը
(հոդվածը 20.01.26 ՀՕ-19-Ն օրենքի լրացման մասով ուժի մեջ է մտնում «Կլիմայի մասին» օրենքն ուժի մեջ մտնելու օրվանից մեկ տարի հետո)
Հոդված 201.7․ | Ֆիզիկական և իրավաբանական անձանց կողմից «Կլիմայի մասին» օրենքով և դրանից բխող այլ իրավական ակտերով սահմանված որակի վավերացման (վալիդացման) կամ որակի ստուգման (վերիֆիկացման) գործունեության իրականացումը առանց հավատարմագրման
(հոդվածը 20.01.26 ՀՕ-19-Ն օրենքի լրացման մասով ուժի մեջ է մտնում «Կլիմայի մասին» օրենքն ուժի մեջ մտնելու օրվանից մեկ տարի հետո)
