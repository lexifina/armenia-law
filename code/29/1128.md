# Հոդված 1128. Ծառայողական ստեղծագործության նկատմամբ հեղինակային իրավունքը
1. Ծառայողական առաջադրանքով ստեղծված ստեղծագործության (ծառայողական ստեղծագործության) նկատմամբ հեղինակային իրավունքը պատկանում է ստեղծագործության հեղինակին:
2. Ծառայողական ստեղծագործությունն օգտագործելու իրավունքն առաջադրանքի նպատակով պայմանավորված եղանակով ու դրանից բխող սահմաններում պատկանում է այն անձին, ում առաջադրանքով ստեղծվել է ստեղծագործությունը և ում հետ հեղինակը գտնվում է աշխատանքային հարաբերությունների մեջ (գործատու), եթե այլ բան նախատեսված չէ վերջինիս ու հեղինակի միջև պայմանագրով: Գործատուն իրավունք ունի ծառայողական ստեղծագործությունն օգտագործելու իրավունքը փոխանցել այլ անձի:
Հեղինակի հետ կնքած գործատուի պայմանագիրը կարող է նախատեսել հեղինակին ծառայողական ստեղծագործությունն օգտագործելու համար վարձատրություն և պարունակել այն օգտագործելու այլ պայմաններ:
3. Ստեղծագործությունը ներկայացնելու պահից տասը տարի անց, իսկ գործատուի համաձայնության դեպքում` նաև ավելի վաղ, հեղինակը, անկախ գործատուի հետ կնքած պայմանագրից, ձեռք է բերում ստեղծագործությունն ամբողջ ծավալով օգտագործելու և հեղինակային վարձատրություն ստանալու իրավունք:
4. Առաջադրանքի նպատակով չպայմանավորված եղանակով ծառայողական ստեղծագործությունն օգտագործելու հեղինակի իրավունքը չի սահմանափակվում:
