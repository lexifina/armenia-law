# Հոդված 88. Դատապարտյալին չվարձատրվող աշխատանքների ներգրավելը
1. Ուղղիչ հիմնարկի պետի որոշմամբ դատապարտյալն առանց վարձատրության կարող է ներգրավվել ուղղիչ հիմնարկի կամ դրան հարող տարածքների բարեկարգման աշխատանքներին։
2. Դատապարտյալը չվարձատրվող աշխատանքների ներգրավվում է հերթականությամբ՝ ոչ հանգստյան ժամերին՝ օրական երկու ժամից ոչ ավելի ժամանակով:
3. Առաջին կամ երկրորդ կարգի հաշմանդամ, հղի, կենսաթոշակային տարիքի հասած դատապարտյալին չվարձատրվող աշխատանքների ներգրավելն արգելվում է։
