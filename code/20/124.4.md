# Հոդված 124.4. Տրանսպորտային միջոցների վարորդների կողմից սահմանված արագությունը գերազանցելը
1. Երթևեկության սահմանված արագությունը 11-20 կմ/ժ-ով գերազանցելը`
առաջացնում է տուգանքի նշանակում` նվազագույն աշխատավարձի տասնապատիկի չափով:
2. Երթևեկության սահմանված արագությունը 21-40 կմ/ժ-ով գերազանցելը`
առաջացնում է տուգանքի նշանակում` նվազագույն աշխատավարձի երեսնապատիկի չափով:
3. Երթևեկության սահմանված արագությունը 41-60 կմ/ժ-ով գերազանցելը`
առաջացնում է տուգանքի նշանակում` նվազագույն աշխատավարձի հիսնապատիկի չափով:
4. Երթևեկության սահմանված արագությունը 61 կմ/ժ-ով և ավելի գերազանցելը`
առաջացնում է տուգանքի նշանակում` նվազագույն աշխատավարձի յոթանասունապատիկի չափով:
