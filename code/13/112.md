# Հոդված 112. Որդեգրում սահմանող մարմինը
Որդեգրումը կատարվում է համապատասխան տեղական ինքնակառավարման մարմնի որոշմամբ` երեխային որդեգրել ցանկացող անձի (անձանց) խնդրանքով: Մինչև Սահմանադրությամբ նախատեսված տեղական ինքնակառավարման մարմինների կազմավորումը քաղաքներում և գյուղերում որդեգրումն իրականացնում են համապատասխանաբար պատգամավորների քաղաքային և գյուղական խորհուրդների գործադիր մարմինները, իսկ երևան քաղաքում` երևանի քաղաքապետարանը:
