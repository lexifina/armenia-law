# Հոդված 52. Դատարանի շենքում ապացուցողական գործողություններ կատարելու վերաբերյալ Բարձրագույն դատական խորհրդին իրազեկելը
(վերնագիրը փոփ. 09.06.22 ՀՕ-151-Ն)
1. Քրեական վարույթի շրջանակներում ապացուցողական գործողություններ կատարելու նպատակով դատարանի շենք մուտք գործելուց առաջ մինչդատական քրեական վարույթի օրինականության նկատմամբ հսկողություն իրականացնող դատախազն անհապաղ իրազեկում է Բարձրագույն դատական խորհրդին։
2. Առանց Բարձրագույն դատական խորհրդին իրազեկելու դատարանի շենք մուտք գործելու դեպքում Բարձրագույն դատական խորհուրդը համապատասխան անձանց պատասխանատվության ենթարկելու միջնորդությամբ դիմում է գլխավոր դատախազին կամ քննչական մարմնի ղեկավարին:
3. Գլխավոր դատախազից կամ քննչական մարմնի ղեկավարից ողջամիտ ժամկետում պատասխան չստանալու դեպքում Բարձրագույն դատական խորհուրդը հանդես է գալիս պաշտոնական հայտարարությամբ:
(52-րդ հոդվածը փոփ. 09.06.22 ՀՕ-151-Ն)
