# Հոդված 173. Դատական դպրոցի գույքը և ֆինանսավորումը
1. Դատական դպրոցը ֆինանսավորվում է պետական բյուջեից` առանձին բյուջետային տողով:
2. Հիմնադիրը Դատական դպրոցին անժամկետ և անհատույց օգտագործման իրավունքով ամրացնում է գործունեության համար անհրաժեշտ գույք:
3. Դատական դպրոցը հիմնադրի կողմից իրեն ամրացրած գույքն իրավունք ունի պետության անունից հանձնելու վարձակալության` սույն օրենսգրքով և Դատական դպրոցի կանոնադրությամբ սահմանված կարգով:
