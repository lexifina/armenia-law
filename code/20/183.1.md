# Հոդված 183¹. Պետական ծառայողների կողմից պետական մարմնի անունից, մինչև տվյալ հարցի վերաբերյալ որոշում ընդունելը, պաշտոնական հայտարարությամբ կամ հաղորդմամբ հանդես գալը
