# Հոդված 231. Առարկայի, փաստաթղթի, կենդանու, դիակի ճանաչումը
1. Ճանաչման ենթակա առարկան ճանաչողին ներկայացվում է առնվազն երեք միատեսակ այլ առարկաների շարքում: Այն առարկայի ճանաչումը, որին նման առարկաներ անհնար կամ դժվար է ձեռք բերել, ինչպես նաև փաստաթղթի, կենդանու, մարդու կամ կենդանու դիակի, դրա առանձին մասերի ճանաչումը կատարվում են ներկայացված մեկ օբյեկտով:
2. Մինչև առարկան ճանաչման ներկայացնելն այն կարող է մաքրվել կեղտից, ժանգից և այլ կողմնակի նյութերից, եթե դա բացասաբար չի ազդի ճանաչման արդյունքի վրա:
3. Եթե ճանաչվում է մարդու դիակ, որին ճանաչողը ողջ է տեսել, ապա թույլատրվում է հանգուցյալին շպար անել: Դիակի կամ դրա առանձին մասերի ճանաչումը կատարվում է բժշկության բնագավառի ձեռնհաս փորձագետի մասնակցությամբ:
4. Եթե ճանաչվող առարկան ճանաչողին է ներկայացվել այլ առարկաների շարքում, ապա ճանաչողին առաջարկվում է մատնացույց անել այն առարկան, որը նա կարող է ճանաչել:
5. Ճանաչողին առաջարկվում է բացատրել, թե ինչ հատկանիշներով է ճանաչել առարկան, փաստաթուղթը, կենդանուն կամ դիակը:
