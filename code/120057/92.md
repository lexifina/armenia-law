# Հոդված 92. Մասնագետի հարցաքննությունը
1. Մասնագետի հարցաքննությունը կատարվում է վկայի հարցաքննության համար սույն օրենսգրքով սահմանված կարգով:
2. Առաջին ատյանի դատարանը նախազգուշացնում է մասնագետին ակնհայտ կեղծ բացատրություն տալու համար նախատեսված քրեական պատասխանատվության մասին։ Առաջին ատյանի դատարանը մասնագետից ստորագրություն է վերցնում նախազգուշացման մասին, որը կցվում է դատական նիստի արձանագրությանը։
