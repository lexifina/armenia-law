# Հոդված 209. Զինվորական հաշվառման չներկայացած զինապարտներին և զորակոչիկներին աշխատանքի (սովորելու) ընդունելը
Ըստ բնակության վայրի զինվորական հաշվառման չներկայացած զինապարտներին հիմնարկների, կազմակերպությունների և ուսումնական հաստատությունների ղեկավարների կամ մյուս պաշտոնատար անձանց կողմից աշխատանքի ( սովորելու) ընդունելը`
առաջացնում է տուգանքի նշանակում սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով:
Սույն հոդվածի առաջին մասով նախատեսված խախտումը մեկ տարվա ընթացքում կրկին կատարելը, որի համար անձն արդեն ենթարկվել է վարչական տույժի`
