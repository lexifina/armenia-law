# Հոդված 147.1. Վերաքննիչ դատարանի որոշման մեջ առկա վրիպակների, գրասխալների և թվաբանական սխալների ուղղումը, լրացուցիչ որոշումը
1. Վերաքննիչ դատարանի որոշման մեջ առկա վրիպակների, գրասխալների, թվաբանական սխալների ուղղման և լրացուցիչ որոշման վրա տարածվում են Հայաստանի Հանրապետության քաղաքացիական դատավարության օրենսգրքի վրիպակների, գրասխալների և թվաբանական սխալների ուղղմանը և լրացուցիչ որոշմանը վերաբերող համապատասխան կանոնները, եթե սույն օրենսգրքով այլ բան նախատեսված չէ։
(147.1-ին հոդվածը լրաց. 02.05.24 ՀՕ-220-Ն)
(02.05.24 ՀՕ-220-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
