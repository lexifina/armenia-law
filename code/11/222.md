## ԴԱՏԱՐԱՆԻ ՈՐՈՇՈՒՄՆԵՐԸ
# Հոդված 222. ՈՐՈՇՈՒՄՆԵՐ ԿԱՅԱՑՆԵԼԸ

Դատարանը որոշումները կայացնում է խորհրդակցական սենյակում, սույն օրենսգրքի 16 հոդվածով նախատեսված կարգով:
