# Հոդված 223¹. Հայաստանի Հանրապետության արդարադատության նախարարության մարմինները
Հայաստանի Հանրապետության արդարադատության նախարարության մարմինները քննում են սույն օրենսգրքի 169¹⁸-րդ և 189-րդ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը։
Հայաստանի Հանրապետության արդարադատության նախարարության անունից վարչական իրավախախտումների վերաբերյալ գործերը քննելու և վարչական տույժեր նշանակելու իրավունք ունի նախարարության աշխատակազմի իրավաբանական անձանց պետական ռեգիստրի գործակալության պետը:
