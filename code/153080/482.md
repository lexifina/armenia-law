# Հոդված 482. Ակնհայտ անարդար դատավճիռ, վճիռ կամ դատական այլ ակտ կայացնելը
1. Շահադիտական, անձնական այլ շահագրգռվածությունից կամ խմբային շահերից ելնելով՝ դատավորի կողմից ակնհայտ անարդար դատավճիռ, վճիռ կամ դատական այլ ակտ կայացնելը՝
պատժվում է որոշակի պաշտոններ զբաղեցնելու կամ որոշակի գործունեությամբ զբաղվելու իրավունքից զրկելով՝ երեքից յոթ տարի ժամկետով, կամ ազատության սահմանափակմամբ՝ մեկից երեք տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ մեկից երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ մեկից չորս տարի ժամկետով։
