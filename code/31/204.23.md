# Հոդված 204²³. Բողոք ներկայացնելու կարգը
1. Բողոքը ներկայացվում է սույն օրենսգրքի 204²⁶ հոդվածով սահմանված կարգով իրավասու դատարան:
2. Բողոքին կցվում են նոր հանգամանքը հաստատող ապացույցը (ապացույցները), ինչպես նաև լրացուցիչ այլ ապացույցներ, որոնք նախկինում չեն ներկայացվել: Բողոքին կցվում է նաև դատական ակտի վերանայման հետ կապված պետական տուրքի վճարումը հաստատող ապացույցը:
3. Բողոքը ներկայացնող անձը դրա պատճենը նոր հանգամանքը հաստատող ապացույցի (ապացույցների) պատճենի (պատճենների) հետ պատշաճ ձևով ուղարկում է գործին մասնակցող անձանց:
