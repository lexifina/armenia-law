# Հոդված 431. Լիազորված տնտեսական օպերատորների ռեեստրը
1. Մաքսային մարմինները վարում են լիազորված տնտեսական օպերատորների ռեեստրը՝ Հանձնաժողովի կողմից սահմանվող ձևով, տեղադրում են այն Ինտերնետ ցանցում՝ իրենց պաշտոնական կայքերում և ապահովում են դրա՝ ամիսն առնվազն մեկ անգամ թարմացումը:
2. Հանձնաժողովը մաքսային մարմինների կողմից վարվող՝ լիազորված տնտեսական օպերատորների ռեեստրների հիման վրա ձևավորում է լիազորված տնտեսական օպերատորների ընդհանուր ռեեստրը, տեղադրում է այն Ինտերնետ ցանցում՝ Միության պաշտոնական կայքում և ապահովում է դրա՝ ամիսն առնվազն մեկ անգամ թարմացումը:
