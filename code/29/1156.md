# Հոդված 1156. Արտոնագրի տիրոջ իրավունքների սահմանափակումը
Արտոնագրի տիրոջ իրավունքները սահմանափակելու հիմքերը, արտոնագիրը դադարեցնելու (չեղյալ հայտարարելու), այն անվավեր ճանաչելու, հարկադրական լիցենզիաներ տալու պայմանները սահմանվում են «Արտոնագրերի մասին» Հայաստանի Հանրապետության օրենքով:
Արտոնագիրը հասարակության և պետության կարիքների համար կարող է օտարվել միայն Հայաստանի Հանրապետության Սահմանադրությամբ նախատեսված դեպքերում և օրենքով սահմանված կարգով:
(1156-րդ հոդվածը խմբ. 27.11.06 ՀՕ-187-Ն)
