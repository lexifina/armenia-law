# Հոդված 992. Պարտադիր ապահովագրություն իրականացնելը
1. Պարտադիր ապահովագրությունն ապահովագրողի հետ ապահովագրության պայմանագիր կնքելու միջոցով իրականացնում է այն անձը (ապահովագրվողը), ում վրա դրված է այդպիսի ապահովագրության պարտականությունը:
2. Պարտադիր ապահովագրությունն իրականացվում է ապահովագրվողի հաշվին, բացառությամբ ուղևորների պարտադիր ապահովագրության, որն օրենքով նախատեսված դեպքերում կարող է իրականացվել նրանց հաշվին:
3. Պարտադիր ապահովագրության ենթակա օբյեկտները, այն ռիսկերը, որոնցից դրանք պետք է ապահովագրվեն, և ապահովագրական գումարների նվազագույն չափերը սահմանվում են օրենքով:
