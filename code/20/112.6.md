# Հոդված 112⁶. Առանց համապատասխան փաստաթղթերի (անասնաբուժական տեղեկանք կամ անասնաբուժական վկայական) պետական անասնաբուժական հսկողության ենթակա ապրանքների (բեռների) տեղափոխումը հանրապետության վարչական տարածքներով
