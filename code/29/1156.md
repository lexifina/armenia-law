# Հոդված 1156. Արտոնագրի տիրոջ իրավունքների uահմանափակումը
Արտոնագրի տիրոջ իրավունքները uահմանափակելու հիմքերը, արտոնագիրը դադարեցնելու (չեղյալ հայտարարելու), այն անվավեր ճանաչելու, հարկադրական լիցենզիաներ տալու պայմանները uահմանվում են «Գյուտերի, օգտակար մոդելների, արդյունաբերական նմուշների մասին» Հայաuտանի Հանրապետության oրենքով:
Արտոնագիրը հաuարակության և պետության կարիքների համար կարող է օտարվել միայն Հայաստանի Հանրապետության Սահմանադրությամբ նախատեսված դեպքերում և օրենքով սահմանված կարգով:
(1156-րդ հոդվածը խմբ. 27.11.06 ՀՕ-187-Ն, փոփ. 10.06.08 ՀՕ-112-Ն)
