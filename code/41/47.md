# Հոդված 47. Ջրային համակարգի օգտագործման թույլտվության փոխանցելը կամ պայմանագրային կարգով այլ անձանց հանձնելը
Ջրային համակարգի օգտագործման թույլտվությունը և դրան առնչվող իրավունքներն ու պարտականությունները օրենսդրությամբ սահմանված կարգով կարող են մասնակիորեն կամ ամբողջովին վաճառվել կամ այլ կերպ փոխանցվել մեկ այլ անձի, եթե այլ բան նախատեսված չէ օգտագործման թույլտվության պայմաններով։
