# Հոդված 224.1. Հայաստանի Հանրապետության ազգային անվտանգության ծառայությունը
1. Հայաստանի Հանրապետության ազգային անվտանգության ծառայության մարմինները ձերբակալվածներին պահելու վայրերում քննում են սույն օրենսգրքի 186-րդ հոդվածով նախատեսված` ձերբակալվածներին պահելու վայրերում վարչական իրավախախտումների վերաբերյալ գործերը և սույն օրենսգրքի 201-րդ հոդվածի 1-ին մասով նախատեսված այն վարչական իրավախախտումների վերաբերյալ գործերը, որոնք հայտնաբերվել են պետական սահմանի անցման կետերում:
2. Սույն օրենսգրքի 186-րդ հոդվածով նախատեսված վարչական իրավախախտումների վերաբերյալ գործեր քննելու, վարչական տույժեր նշանակելու իրավունք ունի ձերբակալվածներին պահելու վայրի պետը:
3. Հայաստանի Հանրապետության ազգային անվտանգության ծառայության անունից սույն օրենսգրքի 201-րդ հոդվածի 1-ին մասով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը քննելու և վարչական տույժեր նշանակելու իրավունք ունի սահմանապահ զորքերի սահմանային վերահսկողության ստորաբաժանման պետը կամ սահմանային վերահսկողության ստորաբաժանման խմբի պետը:
(224.1-ին հոդվածը լրաց. 01.03.17 ՀՕ-49-Ն, խմբ. 06.07.22 ՀՕ-332-Ն)
