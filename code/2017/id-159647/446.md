1. Սույն Օրենսգրքի 28-31-րդ հոդվածների, 36-րդ հոդվածի 6-րդ կետի, 49-րդ հոդվածի 4-րդ կետի, 109-րդ հոդվածի 7-րդ և 10-րդ կետերի ու 314-րդ հոդվածի դրույթները կիրառվում են՝ հաշվի առնելով «Միության մասին» պայմանագրի 102-րդ հոդվածի 1-ին, 3-5-րդ կետերը:
2.
