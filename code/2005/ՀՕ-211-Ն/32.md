## ԱՆՏԱՌՕԳՏԱԳՈՐԾՈՒՄ
# Հոդված 32. Անտառները կամ անտառային հողերն օգտագործման տրամադրելը
1. Անտառների և անտառային հողերի սեփականատերերն անտառները կամ անտառային հողերն օգտագործման են տրամադրում անհատույց կամ վարձակալության իրավունքով, ինչպես նաև սույն օրենսգրքով նախատեսված այլ նպատակներով:
2. Պետական անտառները կամ անտառային հողերն անհատույց օգտագործման են տրամադրվում օրենքով և այլ նորմատիվ իրավական ակտերով նախատեսված դեպքերում:
3. Վարձակալության և օգտագործման իրավունքի հետ կապված հարաբերությունները կարգավորվում են Քաղաքացիական, Հողային և սույն օրենսգրքերով:
4. Պետական անտառները և անտառային հողերն օգտագործման տալու կարգը սահմանում է Հայաստանի Հանրապետության կառավարությունը:
