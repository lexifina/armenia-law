# Հոդված 222.25. Դիմումին ներկայացվող պահանջները և կցվող փաստաթղթերը
1. Սույն օրենսգրքի 222.24-րդ հոդվածում նշված գործերով դիմումը ձևակերպվում է գրավոր և բովանդակում է՝
1) նշում այն մասին, որ դիմումը ներկայացվում է վարչական դատարան.
2) դիմողի անվանումը և հասցեն.
3) դիմումը ներկայացնող պաշտոնատար անձի անունը, պաշտոնը.
4) դիմումի էության հակիրճ նկարագրությունը.
5) այն փաստերը, որոնց վրա հիմնվում է դիմողի պահանջը.
6) դիմողի պահանջը հիմնավորող փաստարկները.
7) դիմողի պահանջը.
8) գրավոր ապացույցների ցանկը, եթե այդպիսիք կցվում են դիմումին.
9) հարցման մեջ նշված անձին նույնականացնող տվյալները.
10) դիմումը ներկայացնելու տարին, ամիսը, ամսաթիվը:
2. Դիմումն ստորագրում է դիմողի պաշտոնատար անձը կամ վերջինիս լիազորած անձը:
