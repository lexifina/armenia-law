# Հոդված 134. Անշարժ և շարժական գույքը
1. Անշարժ գույք են համարվում հողամասերը, ընդերքի մասերը, մեկուսի ջրային օբյեկտները, անտառները, բազմամյա տնկիները, ստորգետնյա և վերգետնյա շենքերը, շինությունները և հողին ամրակցված այլ գույքը, այսինքն՝ այն օբյեկտները, որոնք անհնար է հողից անջատել՝ առանց այդ գույքին կամ հողամասին վնա պատճառելու կամ դրանց նշանակության փոփոխման, դադարման կամ նպատակային նշանակությամբ հետագա օգտագործման անհնարինության:
2. Շարժական գույք է համարվում անշարժ չհամարվող գույքը:
