# Հոդված 170⁸. Ակցիզային դրոշմանիշներով դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) ապրանքներ իրացնելը
Ակցիզային դրոշմանիշներով դրոշմավորման ենթակա չդրոշմավորված (չվերադրոշմավորված) չդրոշմավորված ապրանքներ իրացնելը, եթե այդ ապրանքների ընդհանուր արժեքը վաճառողի մոտ նշված (չնշված լինելու դեպքում` օրենսդրությամբ սահմանված կարգով որոշված) գներով չի գերազանցում երկու հարյուր հազար դրամը`
