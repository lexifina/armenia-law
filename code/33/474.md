# Հոդված 474. ԴԱՏԱՎԱՐԱԿԱՆ ԳՈՐԾՈՂՈՒԹՅՈՒՆՆԵՐ ԿԱՏԱՐԵԼՈՒ ՄԱՍԻՆ ՀԱՆՁՆԱՐԱՐՈՒԹՅՈՒՆՆԵՐ ՏԱԼԸ
1. Օտարերկրյա պետության տարածքում հարցաքննություն, զննություն, առգրավում, խուզարկություն, փորձաքննություն և սույն օրենսգրքով նախատեսված այլ քննչական և դատական գործողություններ կատարելու անհրաժեշտության դեպքում դատարանը, դատախազը, քննիչը, հետաքննության մարմինը դրանց կատարումը հանձնարարում են օտարերկրյա պետության համապատասխան մարմիններին` իրավական օգնության մասին միջազգային պայմանագրի առկայության դեպքում:
2. Առանձին քննչական գործողություններ կատարելու մասին հանձնարարությունն ուղարկվում է Հայաստանի Հանրապետության գլխավոր դատախազի միջոցով, իսկ դատական գործողություններինը` Հայաստանի Հանրապետության արդարադատության նախարարի կամ համապատասխանաբար` նրանց տեղակալների միջոցով:
