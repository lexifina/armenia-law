# Հոդված 239. Իրավաբանական նշանակություն ունեցող փաստի հաստատման համար անհրաժեշտ պայմանը
1. Դատարանն իրավաբանական նշանակություն ունեցող փաստը հաստատում է միայն այն դեպքում, եթե դիմողը հնարավորություն չունի այլ արտադատական կարգով, բացառությամբ իրավաբանական նշանակություն ունեցող փաստը նոտարի կողմից հաստատելու կարգի, ստանալու այդ փաստը հավաստող պատշաճ փաստաթղթեր կամ անհնար է վերականգնել կորցրած փաստաթղթերը:
(239-րդ հոդվածը լրաց. 16.07.20 ՀՕ-392-Ն)
