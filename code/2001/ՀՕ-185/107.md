2. Բնակավայրերի սահմանագծերում ընդգրկված հողերում ընդերքի ու բնական պաշարների օգտագործումը սահմանափակվում կամ արգելվում է, եթե նման գործողությունները կարող են վտանգ ստեղծել մարդկանց կյանքի ու առողջության համար և վնաս պատճառել շրջակա բնական միջավայրին:
