# Հոդված 57. ԴԱՏԱՐԱՆՆԵՐԻ ԴԱՏԱԿԱՆ ԱԿՏԵՐԸ ՀՐԱՊԱՐԱԿԵԼԸ և ԴՐԱՆՑ ՈՒԺԻ ՄԵՋ ՄՏՆԵԼԸ
(վերնագիրը փոփ. 05.12.13 ՀՕ-146-Ն)
1. Օրենքին կամ այլ իրավական ակտերին հակասող, իրավաբանական և ֆիզիկական անձանց իրավունքներն ու օրենքով պաշտպանվող շահերը խախտող պետական կամ տեղական ինքնակառավարման մարմնի իրավական ակտն անվավեր ճանաչելու մասին դատարանի դատական ակտը պետք է հրապարակվի նույն կարգով, որով հրապարակվել է անվավեր ճանաչված իրավական ակտը:
2. Օրենքին կամ այլ իրավական ակտերին հակասող, ֆիզիկական կամ իրավաբանական անձի իրավունքներն ու օրենքով պաշտպանվող շահերը խախտող պետական կամ տեղական ինքնակառավարման մարմնի իրավական ակտն անվավեր ճանաչելու մասին դատարանի դատական ակտն ուժի մեջ է մտնում Հայաստանի Հանրապետության քաղաքացիական դատավարության օրենսգրքով սահմանված կարգով:
3. Սույն հոդվածով նախատեսված` դատարանի դատական ակտերը հրատարակման է ուղարկում ակտերն ընդունած դատարանը` դրանց ուժի մեջ մտնելու օրվան հաջորդող երեք օրվա ընթացքում:
4. Դատարանների անհատական իրավական ակտերն ուժի մեջ են մտնում դրանց ընդունման օրվան հաջորդող օրվանից, եթե այդ ակտերով ավելի ուշ ժամկետ նախատեսված չէ:
(57-րդ հոդվածը փոփ. 05.12.13 ՀՕ-146-Ն)
