# Հոդված 214. Սերվիտուտի համար վճարը
1. Սերվիտուտով ծանրաբեռնված հողամասի սեփականատերն իրավունք ունի հողամասն օգտագործելու համար վճար պահանջել այն անձանցից, ի շահ որոնց սահմանվել է սերվիտուտը, եթե այլ բան նախատեսված չէ օրենքով կամ պայմանագրով:
2. Կամավոր սերվիտուտի վճարի չափը որոշվում է կողմերի համաձայնությամբ, իսկ հարկադիր սերվիտուտի դեպքում` դատարանի վճռով կամ օրենքով:
(214-րդ հոդվածը լրաց. 20.03.01 ՀՕ-159)
