# Հոդված 189. Առանց համապատասխան գրանցման մամուլի և զանգվածային լրատվության մյուս միջոցների թողարկումը, հրապարակումը կամ տարածումը
Առանց համապատասխան գրանցման մամուլի և զանգվածային լրատվության մյուս միջոցների թողարկումը, հրապարակումը կամ տարածումը`
