# Հոդված 77. Ընդերքի օգտագործման և պահպանության պետական վերահսկողության ձևերը
1. Ընդերքի օգտագործման և պահպանության պետական վերահսկողությունն իրականացվում է տեսչական ստուգումների, ստուգումների և ուսումնասիրությունների միջոցով` «Հայաստանի Հանրապետությունում ստուգումների կազմակերպման և անցկացման մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով և սույն օրենսգրքի դրույթներին համապատասխան:
2. Ընդերքի պետական տեսուչը սույն օրենսգրքի 76-րդ հոդվածի 1-ին մասի 10-րդ կետով նախատեսված տեղեկանքների պատճենը պարտավոր է ուղարկել հարկային մարմին:
3. Լիազոր մարմինը պարտավոր է հարկային մարմնին տեղեկություններ տրամադրել կնքված ընդերքօգտագործման պայմանագրերի վերաբերյալ:
