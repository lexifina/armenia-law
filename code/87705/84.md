# Հոդված 84. Գործի քննության ժամկետը
1. Գործը դատաքննության նախապատրաստելը և բուն դատաքննությունը պետք է իրականացվեն ողջամիտ ժամկետներում, բացառությամբ այն դեպքերի, երբ առանձին գործերի քննության և լուծման համար սույն օրենսգրքով սահմանված են որոշակի ժամկետներ։
2. Դատաքննությունը, որպես կանոն, պետք է ավարտվի մեկ դատական նիստով՝ առանց հետաձգումների։
