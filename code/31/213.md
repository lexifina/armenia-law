# Հոդված 213. Վերաքննիչ բողոքը վարույթ ընդունելու մասին որոշումը
1. Վերաքննիչ բողոքն ստանալու օրվանից եռօրյա ժամկետում բողոքը չվերադարձնելու դեպքում վերաքննիչ դատարանը կայացնում է վերաքննիչ բողոքն ընդունելու մասին որոշում:
2. Որոշման մեջ նշվում են գործի քննության ժամանակը և վայրը:
3. Որոշումը պատշաճ ձևով ուղարկվում է գործին մասնակցող անձանց:
(213-րդ հոդվածը խմբ. 18.02.04 ՀՕ-36-Ն)
