# Հոդված 89. Դատապարտյալի կրթությունը
1. Ուղղիչ հիմնարկի վարչակազմը միջոցներ է ձեռնարկում դատապարտյալի հիմնական և հեռակա բարձրագույն, հետբուհական մասնագիտական կրթությունը կազմակերպելու համար: Դատապարտյալի կրթությունը կազմակերպվում է ուղղիչ հիմնարկների ներքին կանոնակարգով սահմանված կարգով:
2. Ուսանող դատապարտյալը քննություններ հանձնելու կապակցությամբ աշխատանքից ազատվում է Հայաստանի Հանրապետության աշխատանքային օրենսդրությամբ սահմանված կարգով։
