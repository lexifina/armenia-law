# Հոդված 18. Արարքը
1. Սույն օրենսգրքով նախատեսված արարք է համարվում պատժի սպառնալիքով արգելված գործողությունը կամ անգործությունը։
2. Անգործությամբ կատարված արարքը քրեական պատասխանատվություն է առաջացնում, եթե անձի վրա իրավական ակտով դրված է եղել գործողություն կատարելու պարտականություն, կամ այդ պարտականությունը բխել է նրա ստանձնած պարտավորությունից կամ բխել է օրենքով պաշտպանվող շահերը վտանգի ենթարկած կամ դրանց վնաս պատճառած իր նախորդ վարքագծից:
