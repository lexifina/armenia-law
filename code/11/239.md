# Հոդված 239. դիմում տալը
քաղաքացիներից հարկերի և վճարումների, ինքնահարկման և պետական պարտադիր ապահովագրության ապառքները բռնագանձելու վերաբերյալ դիմումը տրվում է համապատասխանորեն պատգամավորների շրջանային, քաղաքային կամ քաղաքի շրջանային խորհրդի գործադիր կոմիտեի ֆինանսական բաժնի, կամ պատգամավորների ավանային կամ գյուղական խորհրդի գործադիր կոմիտեի, կամ պետական ապահովագրության մարմնի կողմից` ապառքատիրոջ բնակության վայրի կամ նրա գույքի գտնվելու վայրի ժողովրդական դատարանին:
