# Հոդված 220. Դատական կարգադրիչի նյութական ապահովությունը
1. Յուրաքանչյուր դատական կարգադրիչ ունի ծառայության համար համարժեք դրամական բավարարման, ինչպես նաև հանդերձանքի և իր ցանկությամբ պարենային ապահովման կամ դրա փոխարեն դրամական փոխհատուցման իրավունք:
2. Դատական կարգադրիչին տրվող դրամական բավարարման չափը և հաշվարկման կարգը որոշվում են «Քրեակատարողական ծառայության մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով՝ ըստ սույն օրենսգրքի 203-րդ հոդվածով նախատեսված պաշտոնների համապատասխանությանը:
(220-րդ հոդվածը խմբ. 07.04.09 ՀՕ-91-Ն)
