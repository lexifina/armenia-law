# Հոդված 152.4. Հանրության գերակա շահերի ապահովման նպատակով օտարվող սեփականության ձեռքբերողի կողմից սեփականության օտարման նպատակի իրագործման ժամկետները խախտելը
1. Հանրության գերակա շահերի ապահովման նպատակով օրենքով սահմանված կարգով օտարվող սեփականության ձեռքբերողի (եթե ձեռքբերողը Հայաստանի Հանրապետությունը կամ համայնքը չէ) կողմից սեփականության օտարման նպատակի իրագործումը «Հանրության գերակա շահերի ապահովման նպատակով սեփականության օտարման մասին» օրենքով սահմանված ժամկետում չսկսելը`
առաջացնում է տուգանքի նշանակում` օտարված յուրաքանչյուր գույքի համար՝ սահմանված նվազագույն աշխատավարձի չորսհազարապատիկից հինգհազարապատիկի չափով։
2. Հանրության գերակա շահերի ապահովման նպատակով օրենքով սահմանված կարգով օտարվող սեփականության ձեռքբերողի (եթե ձեռքբերողը Հայաստանի Հանրապետությունը կամ համայնքը չէ) կողմից սեփականության օտարման նպատակի իրագործումը գերակա շահ ճանաչելու վերաբերյալ Հայաստանի Հանրապետության կառավարության որոշմամբ սահմանված ժամկետում չավարտելը`
առաջացնում է տուգանքի նշանակում` օտարված յուրաքանչյուր գույքի համար՝ սահմանված նվազագույն աշխատավարձի չորսհազարապատիկից հինգհազարապատիկի չափով։
3. Հանրության գերակա շահերի ապահովման նպատակով օրենքով սահմանված կարգով օտարվող սեփականության ձեռքբերողի (եթե ձեռքբերողը Հայաստանի Հանրապետությունը կամ համայնքը չէ) կողմից հանրության գերակա շահ ճանաչելու մասին Հայաստանի Հանրապետության կառավարության որոշումը և դրանից բխող բոլոր իրավական փաստաթղթերն օրենքի ուժով ուժը կորցրած համարվելու հիմք համարվող՝ «Հանրության գերակա շահերի ապահովման նպատակով սեփականության օտարման մասին» օրենքով սահմանված արարք կատարելը՝
առաջացնում է տուգանքի նշանակում` օտարված յուրաքանչյուր գույքի համար՝ սահմանված նվազագույն աշխատավարձի չորսհազարապատիկից հինգհազարապատիկի չափով։
(152.4-րդ հոդվածը լրաց. 11.02.26 ՀՕ-31-Ն)
