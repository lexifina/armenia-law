# Հոդված 3. «Հայրենիքին մատուցած ծառայությունների համար» մեդալով պարգևատրելու միջնորդությունները ներկայացնում են համապատասխան հանրապետական գործադիր մարմինների ղեկավարները։ Հոդված 4. «Հայրենիքին մատուցած ծառայությունների համար» մեդալը կրում են կրծքի ձախ կողմում, շքանշանների առկայության դեպքում՝ շքանշաններից հետո, Մարտական ծառայության մեդալի առկայության դեպքում` դրանից հետո։
(4-րդ հոդվածը փոփ. 02.05.06 ՀՕ-57-Ն)
