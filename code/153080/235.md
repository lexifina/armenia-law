# Հոդված 235. Նվիրատուի կողմից կուսակցությանը նվիրատվություն կատարելու՝ օրենքով սահմանված առավելագույն չափը գերազանցելը
1. Նվիրատուի կողմից կուսակցությանը նվիրատվություն կատարելու՝ օրենքով սահմանված առավելագույն չափը խոշոր չափերով գերազանցելը՝
պատժվում է տուգանքով՝ առավելագույնը քսանապատիկի չափով, կամ ազատության սահմանափակմամբ՝ առավելագույնը երկու տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ առավելագույնը երկու ամիս ժամկետով։
