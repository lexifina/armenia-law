# Հոդված 116. Բաժնետիրական ընկերության վերակազմակերպումը և լուծարումը

Բաժնետիրական ընկերությունը վերակազմակերպելու և լուծարելու այլ հիմքերն ու կարգը սահմանվում են սույն օրենսգրքով և այլ օրենքներով:
