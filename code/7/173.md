# Հոդված 173. ԶՆՆՄԱՆ և ՔՆՆՄԱՆ ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆԸ
Զննում և քննում կատարելու մասին քննիչը կազմում է արձանագրություն, պահպանելով սույն օրենսգրքի 87 և 88 հոդվածներով սահմանված կանոնները:
Արձանագրության մեջ նկարագրվում են քննիչի բոլոր գործողությունները, ինչպես նաև զննման ու քննման պահին ամբողջ հայտաբերվածը այն հաջորդականությամբ, ինչպես կատարվել է զննումը և հատկապես այն վիճակում, ինչ վիճակում հայտաբերվածը դիտվել է զննման կամ քննման պահին:
