# Հոդված 244.26. Կրթության բնագավառի նկատմամբ վերահսկողություն իրականացնող տեսչական մարմինը
1. Կրթության բնագավառի նկատմամբ վերահսկողություն իրականացնող տեսչական մարմինը քննում է սույն օրենսգրքի 189.29-րդ և 189.30-րդ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը:
2. Սույն հոդվածի 1-ին մասում նշված հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործեր քննելու և վարչական տույժեր նշանակելու իրավունք ունի տեսչական մարմնի ղեկավարը:
(244.26-րդ հոդվածը լրաց. 12.05.25 ՀՕ-110-Ն)
