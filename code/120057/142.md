# Հոդված 142. Դատական նիստը նախագահողը
1. Գործը միանձնյա քննող դատավորը նախագահում է դատական նիստը:
2. Գործի կոլեգիալ քննության դեպքում դատական նիստը նախագահում է դատավորներից մեկը:
3. Դատական նիստը նախագահողը ղեկավարում է դատական նիստը` մերժելով այն ամենը, ինչն առնչություն չունի քննվող գործի հետ:
4. Դատական նիստը նախագահողն անհրաժեշտ միջոցներ է ձեռնարկում դատական նիստում պատշաճ կարգ ապահովելու համար:
5. Դատական նիստը նախագահողի կարգադրությունները պարտադիր են դատավարության մասնակիցների և դատական նիստերի դահլիճում ներկա այլ անձանց համար:
