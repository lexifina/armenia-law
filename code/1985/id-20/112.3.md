# Հոդված 112³. Անասնաբուժասանիտարական փորձաքննության չենթարկված կենդանական ծագման մթերքի և հումքի, վերամշակված կերերի, լրացակերերի արտադրությունը, վերամշակումը, պետական գրանցում չստացած անասնաբուժական դեղամիջոցների արտադրությունը, իրացումը, պետական գրանցում ստացած անասնաբուժական դեղամիջոցների իրացումը` առանց ծագումը և ձեռքբերումը հավաստող փաստաթղթերի
(վերնագիրը փոփ. 09.11.06 ՀՕ-173-Ն)
Անասնաբուժասանիտարական փորձաքննության չենթարկված կենդանական ծագման մթերքի և հումքի, վերամշակված կերերի, լրացակերերի արտադրությունը, վերամշակումը, պետական գրանցում չստացած անասնաբուժական դեղամիջոցների արտադրությունը, իրացումը, պետական գրանցում ստացած անասնաբուժական դեղամիջոցների իրացումը` առանց ծագումը և ձեռքբերումը հավաստող փաստաթղթերի`
