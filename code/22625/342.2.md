# Հոդված 342.2. Ուսումնասիրության տվյալները հրապարակելը
1․ «Ապօրինի ծագում ունեցող գույքի բռնագանձման մասին» Հայաստանի Հանրապետության օրենքի հիման վրա իրականացվող ուսումնասիրության հիմքերի վերաբերյալ տվյալները և դրա ընթացքի ու արդյունքների մասին տեղեկություններն առանց իրավասու մարմնի թույլտվության հրապարակելը՝
պատժվում է տուգանքով՝ նվազագույն աշխատավարձի հարյուրապատիկից երեքհարյուրապատիկի չափով, կամ կալանքով՝ առավելագույնը մեկ ամիս ժամկետով:
(342.2-րդ հոդվածը լրաց. 16.04.20 ՀՕ-249-Ն)
