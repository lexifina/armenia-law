# Հոդված 77. Դատավորի` կրթական ծրագրերին մասնակցելու իրավունքը
1. Պարտադիր վերապատրաստման ծրագրերին մասնակցելուց բացի, դատավորն իրավունք ունի մասնակցելու այլ կրթական վերապատրաստման ծրագրերի, համաժողովների և իրավաբանների մասնագիտական այլ հավաքների:
2. Աշխատանքային ժամերին այդպիսի միջոցառումներին մասնակցելու կապակցությամբ մինչև հինգ օր տևողությամբ բացակայելու թույլտվությունը տալիս է դատարանի նախագահը: Դրանից ավելի ժամկետով թույլտվություն ստանալու համար դատավորը դիմում է Դատարանների նախագահների խորհրդի ուսումնական հարցերով հանձնաժողովին:
3. Այն դեպքում, երբ դատավորը ստացել է դատարանի նախագահի կամ դատարանների նախագահների խորհրդի ուսումնական հարցերով հանձնաժողովի համաձայնությունը, այդպիսի միջոցառումներին մասնակցելու կապակցությամբ դատավորի բացակայությունը համարվում է հարգելի` աշխատավարձի պահպանմամբ:
