# Հոդված 241. դիմումի քննարկումը
գործը քննելիս դատարանը պետք է ստուգի, թե վճարման տվյալ տեսակը արդյոք նախատեսված է օրենքով. օրինական հիմքեր կան արդյոք բռնագանձող մարմինների կողմից քաղաքացուն ենթարկելու տվյալ վճարմանը. պահպանված է արդյոք քաղաքացուն վճարման ենթարկելու օրենքով սահմանված կարգը. բռնագանձող մարմինների կողմից նկատի առնվել են արդյոք այն արտոնությունները, որոնց իրավունքը քաղաքացին ունի ըստ օրենքի, գույքի վերգրումը համապատասխանում է արդյոք հարկերի և ոչ հարկային վճարումների բռնագանձման վերաբերյալ ԽՍՀ Միության օրենսդրության պահանջներին:
եթե գործի քննության ժամանակ դատարանը կասկածներ ունենա վճարման չափը հաշվարկելու ճշտության վերաբերյալ, նա իր որոշմամբ կասեցնում է գործի վարույթը և նյութն ուղարկում է բռնագանձման մարմնին` ստուգելու համար: գործի վարույթը վերսկսվում է բռնագանձող մարմնի կողմից վճարման չափի վերահաշվարկում կատարելուց կամ նրա վերադաս մարմնի կողմից բռնագանձման վերաբերյալ դիմումը հաստատելուց հետո:
(26.08.81 խմբագրությամբ)
