# Հոդված 160. Ամենամյա երկարացված արձակուրդը
Երկարացված` մինչև 35 օր տևողությամբ (բացառիկ դեպքերում` մինչև 48 օր տևողությամբ) ամենամյա արձակուրդ տրամադրվում է աշխատանքի հատուկ պայմաններում աշխատող առանձին կատեգորիայի աշխատողների, որոնց աշխատանքը կապված է մտավոր և հուզական գերլարվածության կամ մասնագիտական ռիսկի հետ: Նման արձակուրդի իրավունք ունեցող առանձին կատեգորիայի աշխատողների ցանկը սահմանում է Հայաստանի Հանրապետության կառավարությունը:
