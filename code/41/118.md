# Հոդված 118. Հուսալիության երաշխիքները
Սույն օրենսգրքի պահանջներն ապահովելու, ջրօգտագործման թույլտվության կամ ջրային համակարգի օգտագործման թույլտվության պայմանների կատարումը երաշխավորելու համար ջրօգտագործման թույլտվություն կամ ջրային համակարգի օգտագործման թույլտվություն տալու համար սույն օրենսգրքով լիազորված մարմինները կարող են պահանջել պատշաճ հուսալիության երաշխիք՝ որպես ջրօգտագործման թույլտվության կամ ջրային համակարգի օգտագործման թույլտվության տրման պայման: Հուսալիության երաշխիքը կարող է լինել որևէ բանկից վարկի տրամադրման մասին երաշխավորագրի, բանկային երաշխիքի, ապահովագրության կամ հուսալիության ապահովման որևէ այլ ընդունված փաստաթղթի տեսքով:
