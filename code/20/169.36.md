# Հոդված 169.36. Առանց հավաստագրվելու սոցիալական ծառայություններ մատուցելը
1. «Սոցիալական աջակցության մասին» օրենքով սահմանված դեպքերում սոցիալական աջակցության ոլորտի սոցիալական ծառայություններ տրամադրող կազմակերպությունների և անհատ ձեռնարկատերերի կողմից սոցիալական ծառայություններ մատուցելն առանց պետական լիազոր մարմնում հավաստագրվելու՝
առաջացնում է տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի հինգհարյուրապատիկից հազարապատիկի չափով։
2․ Սույն հոդվածի 1-ին մասով նախատեսված արարքը վարչական տույժի նշանակման օրվանից հետո՝ մեկ տարվա ընթացքում, կրկին կատարելը՝
