# Հոդված 99. Դատական նիստը նախագահելը
1. Գործը միանձնյա քննող դատավորը նախագահում է դատական նիստը։
2. Գործի կոլեգիալ քննության դեպքում դատական նիստը նախագահում է դատավորներից մեկը։
3. Դատական նիստը նախագահողը կազմակերպում և ղեկավարում է դատական նիստը` ապահովելով կարգը դատական նիստում, ստեղծում է պայմաններ ապացույցների լրիվ, օբյեկտիվ և բազմակողմանի հետազոտման համար, կատարում է գործի պատշաճ քննությունն ու լուծումն ապահովելուն ուղղված այլ գործողություններ։
4. Դատական նիստը նախագահողը պարզաբանում է վարչական դատարանի գործողությունները։
