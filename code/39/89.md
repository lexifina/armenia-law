# Հոդված 89. ՀՈՂԱՄԱՍԵՐԻ ՆՎԻՐԱՏՎՈՒԹՅՈՒՆԸ
1. Հողամասի սեփականատերն իրավունք ունի հողամասը կամ դրա բաժանելի մասը նվիրատվության պայմանագրով փոխանցել քաղաքացուն, իրավաբանական անձին, ինչպես նաև պետությանը կամ համայնքներին:
2. Պետական կառավարման և տեղական ինքնակառավարման մարմիններն իրավունք չունեն հրաժարվել նվիրատվության կարգով պետությանը կամ համայնքներին անցնող հողամասերից, բացառությամբ մարդկանց կյանքի ու առողջության համար վտանգ սպառնացող կամ հողամասերի շուկայական գինը գերազանցող պարտքերով ծանրաբեռնված հողամասերի նվիրատվության դեպքերի:
3. Հողամասերի նվիրատվության ընթացքում ծագող իրավահարաբերությունները կարգավորվում են Քաղաքացիական օրենսգրքով:
