# Հոդված 27. Տուգանք
Տուգանքը դրամական տուժանք է, որ դատարանը նշանակում է սույն օրենսգրքով նախատեսված դեպքերում ու սահմաններում:
Տուգանքի չափը սահմանվում է, ելնելով կատարած հանցագործության ծանրությունից, հանցավորի գույքային դրությունից` մինչև քսանհինգ հազար դրամի սահմաններում: Հայաստանի Հանրապետության օրենսդրական ակտերով նախատեսված բացառիկ դեպքերում առանձին հանցագործությունների համար կարող են սահմանվել նաև տուգանքի ավելի բարձր չափեր:
Այն դեպքում, երբ անձը չարամտորեն խուսափում է որպես հիմնական պատիժ նշանակված տուգանքը վճարելուց, դատարանը կարող է տուգանքի չվճարված գումարը փոխարինել առանց ազատազրկման ուղղիչ աշխատանքներով` հաշվելով տուգանքի հարյուր դրամի դիմաց մեկ ամիս ուղղիչ աշխատանքներ, սակայն երկու տարուց ոչ ավելի ժամանակով: Տուգանքի վճարումն անհնարին լինելու դեպքում դատարանը կարող է որոշում կայացնել տուգանքը փոխարինելու պատճառված վնասը հարթելու պարտականություն դնելով կամ հասարակական պարսավանքով:
Տուգանքի փոխարինումը ազատազրկմամբ և ազատազրկումը` տուգանքով, չի թույլատրվում:
Այն առարկաները, որոնք ենթակա չեն բռնագրավման, տուգանքը բռնագանձելիս վերցվել չեն կարող:
