# Հոդված 78. Դատապարտյալի զբոսանքը
1. Դատապարտյալի զբոսանքը կազմակերպվում է ցերեկային ժամերին՝ դրա համար նախատեսված բացօթյա տարածքում:
2. Դատապարտյալի զբոսանքի տևողությունը սահմանվում է սույն օրենսգրքով՝ հաշվի առնելով ուղղիչ հիմնարկի տեսակը:
3. Դատապարտյալի զբոսանքի տևողությունը չի կարող պակաս լինել օրական մեկ ժամից:
