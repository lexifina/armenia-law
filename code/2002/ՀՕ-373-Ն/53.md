# Հոդված 53. Կոնցեսիայի պայմանագրի տրամադրման միջոցով ջրային համակարգի օգտագործման իրավունքի փոխանցումը
Կոնցեսիայի պայմանագրով կարող է տրամադրվել ջրային համակարգը կամ դրա մասը:
Կոնցեսիայի պայմանագրով ջրային համակարգի կառավարումն ստանձնող անձի և Ջրային համակարգերի կառավարման մարմնի միջև կնքվում է պայմանագիր:
Կոնցեսիայի պայմանագրի տրամադրման դեպքում Ջրային համակարգերի կառավարման մարմինը կարող է՝
