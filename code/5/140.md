# Հոդված 140. Հեղինակային և գյուտարարական իրավունքները խախտելը
Ուրիշի գիտական, գրական, երաժշտական կամ գեղարվեստական երկն իր անունով լույս ընծայելը կամ հեղինակի իրավունքի այլ յուրացումը, այդպիսի երկի ապօրինի վերարտադրելն ու տարածելը`
պատժվում են ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով, կամ տուգանքով մինչև երեք հարյուր դրամ, կամ առաջ են բերում հասարակական ներգործության միջոցների կիրառում:
Առանց գյուտարարի համաձայնության գյուտի հրապարակումը հայտարքից առաջ, գյուտի հեղինակային իրավունքի յուրացումը, ինչպես նաև ռացիոնալիզատորական առաջարկության հեղինակային իրավունքի յուրացումը, կամ համահեղինակության հարկադրելը, կամ համահեղինակության մեջ այնպիսի անձանց մտցնելը, որոնք չեն մասնակցել հայտնագործության, գյուտի կամ ռացիոնալիզատորական առաջարկության ստեղծագործական աշխատանքին`
