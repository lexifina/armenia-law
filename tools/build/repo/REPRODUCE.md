# Reproducing this repository

Everything in this history comes from ARLIS (www.arlis.am) and can be rebuilt from it. The same downloaded texts give the same commit hashes.

## What this build used

- Retrieved on {{TODAY}}: {{LAWS}} laws ({{CONSTITUTIONS}} constitutions, {{CODES}} codes, {{LAWS_ORDINARY}} laws) and {{TEXTS}} texts (original acts plus consolidated texts).
- Pages used: about 870 search pages (6 orderings × 145 pages), {{LAWS}} law pages and {{TEXTS}} print views.

## What the build produced

- {{COMMITS}} commits on `main`: {{ORIGINAL}} original acts, {{AMENDMENT}} amendments and this documentation commit. A further {{FUTURE_COMMITS}} are on `future`.
- The sha256 of every downloaded text (gzip of the HTML as served) is in `data/texts-sha256.tsv`; the sha256 of that list is {{TEXTS_SHA256}}.
- Build scripts, copied to `tools/build/`, with their sha256:
  - `parse_text.py` {{SHA_PARSE_TEXT_PY}}
  - `build.py` {{SHA_BUILD_PY}}
  - `docs.py` {{SHA_DOCS_PY}}
- Tools: Python {{V_PYTHON}} with lxml {{V_LXML}}; {{V_GIT}}.

## Steps

```sh
cd tools/build
# the retrieved texts (sha256 in data/texts-sha256.tsv), where build.py reads them
python build.py ../../../armenia-law-rebuilt --today {{TODAY}}
```

`--today` is the retrieval day. It is required: it dates the documentation commit and divides `main` from `future`, so a rebuild never depends on the day it is run. The builder refuses to build into a directory that holds anything except an earlier build. On a rebuild it keeps the `origin` remote.

ARLIS adds texts as laws change, so a later retrieval gives a longer history. To rebuild this exact history, use texts whose sha256 match `data/texts-sha256.tsv`.

## Decisions

- **Which laws:** ARLIS search, act types 1 (Constitution), 3 (constitutional law), 5 (code) and 7 (law), with "exclude changing acts". ARLIS's paging is not stable when sort keys tie, so six orderings are paged and their results combined. Several orderings agreed on the same count.
- **Which texts:** the law's original act (`/hy/acts/<id>`), plus every text on the "Ինկորպորացիա" side of its change history.
- **Dates:** a consolidated text's in-force date is the start of the period in its status line. The original act's is its "Ուժի մեջ մտնելու ամսաթիվ" (date of entry into force). Commits are dated noon at +0400. Texts dated after `--today` go on `future`.
- **Units:** an article starts at "Հոդված N." (in ARLIS's two-cell heading table, or on a line of its own). Centred lines between articles are headings of the next article. "Հավելված N" starts an appendix. Each <P> is one line. ARLIS's ⚖ case-law links are dropped.
- **Normalised away:** whitespace (a text that differs only in whitespace is not a change), curly quotes and soft hyphens.
- **Language guard:** a text that is less than half Armenian letters is skipped and listed in `data/unreadable.csv`.
- **Crediting:** see the README. Changes no act explains would be `Kind: unexplained`. ARLIS pairs every text with an act, so there are {{UNEXPLAINED}} of them.
- **Order:** by in-force date. On one date, original acts come first, then amendments by ARLIS act id.
