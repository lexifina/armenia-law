# Հոդված 231. Կուսակցության օգտին խոշոր չափերով ապօրինի նվիրատվություն ներգրավելը
1. Կուսակցության անդամի կողմից կուսակցության օգտին օրենքով չթույլատրված աղբյուրից խոշոր չափերով կամ օրենքով սահմանված առավելագույն չափը խոշոր չափերով գերազանցող նվիրատվություն ներգրավելը՝
