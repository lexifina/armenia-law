# Հոդված 68. Ընդերքի պահպանության միջոցառումների ֆինանսավորումը
1. Շրջակա միջավայրի և ընդերքի պահպանության, ինչպես նաև ընդերքօգտագործման թափոնների կառավարման միջոցառումների ֆինանսավորումը կատարվում է ընդերքօգտագործողների միջոցների հաշվին:
2. Սույն օրենսգրքի 55.1-ին հոդվածի 1-ին մասով նախատեսված դեպքերում ընդերքի պահպանության միջոցառումներն իրականացվում են պետական ծրագրերով` պետական բյուջեի կամ Հայաստանի Հանրապետության օրենսդրությամբ չարգելված այլ ֆինանսական աղբյուրների միջոցների հաշվին` որպես ընդհանուր բնապահպանական ծրագրի մաս:
(68-րդ հոդվածը փոփ. 21.06.14 ՀՕ-112-Ն, լրաց. 18.10.16 ՀՕ-161-Ն, փոփ. 25.05.22 ՀՕ-143-Ն)
