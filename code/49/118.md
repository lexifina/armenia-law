# Հոդված 118. Երեխային որդեգրելու համար ծնողների համաձայնությունը
1. Երեխային որդեգրելու համար անհրաժեշտ է նրա ծնողների գրավոր համաձայնությունը։ Անչափահաս ծնողների երեխային որդեգրելիս անհրաժեշտ է նաև նրանց ծնողների կամ խնամակալների (հոգաբարձուների) համաձայնությունը, իսկ ծնողների կամ խնամակալի (հոգաբարձուի) բացակայության դեպքում՝ խնամակալության և հոգաբարձության մարմնի համաձայնությունը։
Երեխային որդեգրելու համար ծնողների համաձայնությունը պետք է արտահայտվի դիմումով` հաստատված նոտարական կարգով կամ այն կազմակերպության ղեկավարի կողմից, որտեղ գտնվում է առանց ծնողական խնամքի մնացած երեխան, կամ խնամակալության և հոգաբարձության մարմնի կողմից՝ ըստ երեխային որդեգրելու վայրի կամ ծնողների բնակության վայրի, ինչպես նաև համաձայնությունը կարող է արտահայտվել անմիջականորեն դատարանում որդեգրման վարույթի ժամանակ։
