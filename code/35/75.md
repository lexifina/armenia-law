# Հոդված 75. Հանրապետության Նախագահի թեկնածու առաջադրված քաղաքացու գրանցումը մերժելու կամ Հանրապետության Նախագահի թեկնածուի գրանցումն անվավեր ճանաչելու մասին որոշումների բողոքարկման կարգը
(վերնագիրը փոփ. 22.12.06 ՀՕ-1-Ն)
1. Հանրապետության Նախագահի թեկնածու առաջադրված քաղաքացու գրանցումը մերժելու կամ Հանրապետության Նախագահի թեկնածուի գրանցումն անվավեր ճանաչելու մասին կենտրոնական ընտրական հանձնաժողովի որոշումը կարող է բողոքարկվել Հայաստանի Հանրապետության վարչական դատավարության օրենսգրքով սահմանված կարգով և ժամկետներում:
2. Հանրապետության Նախագահի թեկնածու առաջադրված քաղաքացու գրանցումը մերժելու կամ Հանրապետության Նախագահի թեկնածուի գրանցումն անվավեր ճանաչելու մասին որոշումն անօրինական ճանաչելու մասին դատարանի վճռի հիման վրա անձը ճանաչվում է գրանցված կամ վերագրանցված` որպես Հանրապետության Նախագահի թեկնածու:ուղղ
