# Հոդված 102. Բժշկական բնույթի հարկադրանքի միջոցներ կիրառելու ժամկետը հաշվակցելը
Հանցանք կատարելուց հետո հոգեկան խանգարմամբ հիվանդացած անձի բուժվելու դեպքում պատիժ նշանակելիս կամ պատիժը կրելը վերականգնելիս նրա նկատմամբ հոգեբուժական կազմակերպությունում հարկադիր բուժում կիրառելու ժամկետը հաշվակցվում է պատժի ժամկետին՝ հոգեբուժական կազմակերպությունում գտնվելու մեկ օրը հաշվելով ազատազրկման մեկ օրվա դիմաց:
(102-րդ հոդվածը փոփ. 07.10.09 ՀՕ-186-Ն)
