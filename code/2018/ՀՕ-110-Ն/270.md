# Հոդված 270. Դատարանի վճիռը
1. Դիմումի քննության արդյունքներով առաջին ատյանի դատարանը կայացնում է դիմումը բավարարելու կամ մերժելու մասին վճիռ, որն օրինական ուժի մեջ է մտնում հրապարակման պահից:
2. Դիմումը բավարարելու մասին վճիռը հիմք է քաղաքացուն հոգեբուժական կազմակերպություն ոչ հոժարակամ հոսպիտալացնելու համար` առավելագույնը վեց ամիս ժամկետով:
3. Դիմումը մերժելու մասին վճիռը հիմք է քաղաքացուն հոգեբուժական կազմակերպությունից անհապաղ դուրս գրելու համար:
(270-րդ հոդվածը լրաց. 18.06.20 ՀՕ-349-Ն)
