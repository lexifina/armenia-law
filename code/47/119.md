# Հոդված 119. Պատժից ազատված անձանց իրավական դրությունը
Պատժից ազատված անձինք օգտվում են այն իրավունքներից և կրում են այն պարտականությունները, որոնք սահմանված են Հայաստանի Հանրապետության քաղաքացիների համար, բացառությամբ դատվածություն ունեցող անձանց, օտարերկրյա քաղաքացիների կամ քաղաքացիություն չունեցող անձանց համար օրենքով նախատեսված սահմանափակումների։
