# Հոդված 1139. Հարակից իրավունքների օբյեկտները
Հարակից իրավունքները տարածվում են բեմադրությունների, կատարումների, ձայնագրման և տեսակատարումների, տեսագրումների, հեռարձակող կազմակերպությունների եթերային և կաբելային հաղորդումների վրա:
Հարակից իրավունքների ծագման և իրականացման համար որևէ ձևականություն չի պահանջվում:
(1139-րդ հոդվածը լրաց. 07.02.00 ՀՕ-29)
