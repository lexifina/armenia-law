# Հոդված 35. Վարույթի հանրային մասնակիցների ինքնուրույնությունը և պատասխանատվությունը
1. Քրեական վարույթի ընթացքում իր լիազորություններն իրականացնելիս վարույթի հանրային մասնակիցը գործում է ինքնուրույն` հիմնվելով օրենքի, իսկ օրենքով նախատեսված դեպքերում` նաև իրավասու անձի հանձնարարությունների վրա: Վարույթի հանրային մասնակիցը պատասխանատու է ներքին համոզմունքի վրա հիմնված իր վարութային ակտերի համար:
2.
