# Հոդված 203.⁴. Արգելված առարկաների ապօրինի հանձնումը ուղղիչ աշխատանքային հիմնարկներում, քննչական մեկուսարաններում, դաստիարակչական աշխատանքային, բուժաշխատանքային և բուժդաստիարակչական պրոֆիլակտորիումներում պահվող անձանց
