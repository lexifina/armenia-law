# Հոդված 125. Որդեգրողներին որպես որդեգրված երեխայի ծնողներ գրառելը
1. Որդեգրողների խնդրանքով դատարանը կարող է որոշում կայացնել ծննդի պետական գրանցման գրքում որդեգրողներին որպես որդեգրված երեխայի ծնողներ գրառելու մասին։
2. Տասը տարին լրացած որդեգրված երեխայի նկատմամբ նման գրառում կատարելու համար անհրաժեշտ է երեխայի համաձայնությունը, բացի սույն օրենսգրքի 121-րդ հոդվածի 2-րդ մասով նախատեսված դեպքերից։
3. Որպես որդեգրված երեխայի ծնողներ գրառվելու անհրաժեշտությունը նշվում է երեխային որդեգրելու մասին դատարանի վճռի մեջ։
