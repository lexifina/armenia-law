# Հոդված 114. Որդեգրման ենթակա երեխաների և երեխաներ որդեգրել ցանկացող անձանց հաշվառումը
1. Որդեգրման ենթակա երեխաների հաշվառումն իրականացվում է սույն օրենսգրքի 110-րդ հոդվածի 3-րդ մասով սահմանված կարգով։
1.1. Ամուսնության մեջ գտնվող անձանցից յուրաքանչյուրը պարտավոր է հաշվառվել որպես որդեգրող:
2. Երեխաներ որդեգրել ցանկացող անձանց հաշվառումն իրականացվում է փաստաթղթային և էլեկտրոնային եղանակով` Հայաստանի Հանրապետության կառավարության սահմանած կարգով:
(114-րդ հոդվածը լրաց. 08.07.05 ՀՕ-144-Ն, լրաց., խմբ. 21.12.17 ՀՕ-10-Ն)
