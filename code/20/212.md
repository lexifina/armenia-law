# Հոդված 212. Անձի ֆունկցիոնալության գնահատման ոլորտում իրավասու պետական մարմնի պաշտոնատար անձանց կողմից զինապարտների և զորակոչիկների հաշմանդամության վերաբերյալ տեղեկություններ չհաղորդելը
(վերնագիրը փոփ. 02.10.24 ՀՕ-352-Ն)
Անձի ֆունկցիոնալության գնահատման ոլորտում իրավասու պետական մարմնի պաշտոնատար անձանց կողմից, որոնց վրա դրված է հաշմանդամություն ունեցող անձ ճանաչված բոլոր զինապարտների մասին, անկախ հաշմանդամության խմբից կամ ֆունկցիոնալության սահմանափակման աստիճանից, զինվորական կոմիսարիատներին տեղեկություններ հաղորդելու պարտականությունը, այդ տեղեկությունները չհաղորդելը`
առաջացնում է տուգանքի նշանակում սահմանված նվազագույն աշխատավարձի հիսնապատիկի չափով:
Սույն հոդվածի առաջին մասով նախատեսված խախտումը մեկ տարվա ընթացքում կրկին կատարելը, որի համար անձն արդեն ենթարկվել է վարչական տույժի`
