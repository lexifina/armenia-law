# Հոդված 18. ԿՈՄՈՒՆԱԼ ՕԲՅԵԿՏՆԵՐԻ ՀՈՂԵՐԸ
Կոմունալ օբյեկտների հողեր են համարվում կոմունալ օբյեկտների, ջրամատակարարման, ջրահեռացման, կոյուղագծերի, օրվա կարգավորիչ ջրամբարների, մաքրման կայանների, պոմպակայանների, աղբավայրերի, համայնքային և մասնավոր գերեզմանատների և այլ օբյեկտների կառուցման ու սպասարկման համար տրամադրված հողամասերը:
