# Հոդված 374. ԱՄԲԱՍՏԱՆՅԱԼԻՆ ԿԱԼԱՆՔԻՑ ԱԶԱՏԵԼԸ
Ամբաստանյալին արդարացնելու, ինչպես նաև պատիժը կրելուց ազատելով մեղադրական դատավճիռ կայացնելու, կամ պատիժը պայմանականորեն չկիրառելու, կամ պատիժը կրելը հետաձգելու, կամ նրան ազատազրկման հետ կապ չունեցող պատժի կամ այն ժամկետով ազատազրկման դատապարտելու դեպքում, որը չի գերազանցում ամբաստանյալի նախնական կալանքի տակ փաստացի գտնվելու ժամկետը, եթե ամբաստանյալը կալանքի տակ է գտնվում, դատարանը նրան անհապաղ ազատում է կալանքից դատական նիստի դահլիճում:
