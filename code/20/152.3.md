# Հոդված 152.3. Նոր կառուցվող կամ կառուցված բազմաբնակարան շենքի կառուցապատողի կողմից բազմաբնակարան շենքի կառավարման բնագավառում օրենքի պահանջները խախտելը
1. Նոր կառուցված և շահագործման հանձնված բազմաբնակարան շենքի նախագծային փաստաթղթերը կառուցապատողի կողմից օրենքով սահմանված կազմով կամ ժամկետում բազմաբնակարան շենքի կառավարման մարմնին չփոխանցելը, ինչպես նաև այդ փաստաթղթերի հանձնման-ընդունման ակտի օրինակը օրենքով սահմանված ժամկետում համայնքի ղեկավարին չներկայացնելը՝
առաջացնում է տուգանքի նշանակում կառուցապատողի նկատմամբ՝ սահմանված նվազագույն աշխատավարձի երկուհարյուրապատիկի չափով:
2. Սույն հոդվածի 1-ին մասում նշված խախտումը վարչական տույժի կիրառումից հետո՝ վեց ամսվա ընթացքում, չվերացնելը՝
