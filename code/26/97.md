# Հոդված 97. Ապրանքները և այլ առարկաները չհայտարարագրելը կամ դրանց հայտարարագրելը ոչ իրենց անվանումով
Հայաստանի Հանրապետության մաքսային սահմանով տեղափոխվող, այդ թվում Հայաստանի Հանրապետության տարածքով տարանցիկ տեղափոխվող ապրանքները և այլ առարկաները չհայտարարագրելը, այսինքն` այդպիսի ապրանքների և այլ առարկաների մասին ճշգրիտ տեղեկությունները սահմանված ձևով չհայտարարագրելը, հավասարապես նաև դրանց հայտարարագրումը ոչ իրենց անվանումով, մաքսանենգության հատկանիշների բացակայության դեպքում`
առաջացնում է տուգանքի նշանակում` այդ ապրանքների և այլ առարկաների արժեքի չափով:
