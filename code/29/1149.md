# Հոդված 1149. Ծառայողական գյուտերը, օգտակար մոդելները, արդյունաբերական նմուշները
Ծառայողական պարտականությունների կամ գործատուի առաջադրանքը կատարելու ժամանակ աշխատողի ստեղծած գյուտի, օգտակար մոդելի, արդյունաբերական նմուշի (ծառայողական գյուտի) արտոնագիր ստանալու իրավունքը պատկանում է գործատուին, եթե դա նախատեսված է նրանց միջև կնքված պայմանագրով:
(հոդվածը 03.03.21 ՀՕ-111-Ն օրենքի փոփոխությամբ ուժի մեջ կմտնի 01.07.2021 թվականին)
