# Հոդված 116. Արվամոլություն
Տղամարդու սեռական հարաբերությունը տղամարդու հետ (արվամոլություն)`
պատժվում է ազատազրկմամբ մինչև հինգ տարի ժամանակով:
Արվամոլությունը, եթե կատարվել է ֆիզիկական բռնություն, սպառնալիքներ գործածելով, կամ անչափահասի նկատմամբ, կամ տուժողի կախյալ վիճակն օկտագործելով`
