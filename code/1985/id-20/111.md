# Հոդված 111. Գյուղատնտեսական մեքենաների տեխնիկական շահագործման և անվտանգության տեխնիկայի կանոնների խախտումը օգտագործողների կողմից (վերնագիրը փոփ. 17.11.17 ՀՕ-204-Ն)
