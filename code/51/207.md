# Հոդված 207. Երաշխիքները դոնորներին
Արյան կամ դրա բաղադրիչների հանձնման օրը դոնորն ազատվում է աշխատանքային պարտականությունների կատարումից: Աշխատանքի չներկայանալու մասին աշխատողը պարտավոր է գործատուին տեղեկացնել ոչ ուշ, քան մեկ օր առաջ: Գործատուն կամ նրա ներկայացուցիչը չպետք է խոչընդոտի դոնորին արյունը կամ դրա բաղադրիչները հանձնելու համար:
