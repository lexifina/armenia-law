# Հոդված 226. Նյութական իրավունքի նորմերի խախտումը կամ սխալ կիրառումը
Նյութական իրավունքի նորմերը համարվում են խախտված կամ սխալ կիրառված, եթե դատարանը`
1) չի կիրառել այն օրենքը կամ Հայաստանի Հանրապետության միջազգային պայմանագիրը կամ իրավական այլ ակտը,որը պետք է կիրառեր.
2) կիրառել է այն օրենքը կամ Հայաստանի Հանրապետության միջազգային պայմանագիրը կամ իրավական այլ ակտը, որը չպետք է կիրառվեր.
3) սխալ է մեկնաբանել օրենքը կամ Հայաստանի Հանրապետության միջազգային պայմանագիրը կամ իրավական այլ ակտը:
(226-րդ հոդվածը լրաց. 18.02.04 ՀՕ-39-Ն)
