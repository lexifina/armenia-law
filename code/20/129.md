# Հոդված 129. Տրանսպորտային միջոցներ վարելու իրավունքից զրկված անձանց կողմից տրանսպորտային միջոցներ վարելը
Տրանսպորտային միջոցներ վարելու իրավունքից զրկված անձանց կողմից տրանսպորտային միջոցներ վարելը`
