# Հոդված 61. հողերի վիճակի վրա ազդող օբյեկտների, շինությունների ու կառուցվածքների տեղաբաշխմանը, նախագծմանը, կառուցմանն ու գործարկմանը ներկայացվող էկոլոգիական պահանջները
