# Հոդված 1132. Ստեղծագործությունը հանրային սեփականության վերածելը
1. Ստեղծագործության նկատմամբ հեղինակի գույքային իրավունքի ժամկետի ավարտից հետո այն վերածվում է հանրային սեփականության:
Այն ստեղծագործությունները, որոնք Հայաստանի Հանրապետության տարածքում երբևիցե պահպանության չեն տրամադրվել, համարվում են հանրային սեփականություն:
2. Հանրային սեփականություն համարվող ստեղծագործությունները կարող է ազատ օգտագործել յուրաքանչյուր անձ` առանց հեղինակային վարձատրություն վճարելու: Ընդ որում, պետք է պահպանվեն հեղինակության իրավունքը, անվան իրավունքը և ստեղծագործության անձեռնմխելիության իրավունքը:
(1132-րդ հոդվածը փոփ. 07.02.00 ՀՕ-29)
