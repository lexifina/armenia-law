# Հոդված 69. Պատժի ամբողջ ժամկետը մեկ ուղղիչ հիմնարկում կրելը
1. Դատապարտյալը պատժի ամբողջ ժամկետը, որպես կանոն, կրում է մեկ ուղղիչ հիմնարկում։
2.
