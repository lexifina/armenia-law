# Հոդված 43. ՀԱՄԱՅՆՔԻ ՂԵԿԱՎԱՐԻ ԻՐԱՎԱՍՈՒԹՅՈՒՆԸ ՀՈՂԵՐԻ ՕԳՏԱԳՈՐԾՄԱՆ և ՊԱՀՊԱՆՄԱՆ ՆԿԱՏՄԱՄԲ ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ ԲՆԱԳԱՎԱՌՈՒՄ
1. Համայնքի ղեկավարը վերահսկողություն է իրականացնում`
1) հողօգտագործողների կողմից հողային օրենսդրության պահանջների կատարման նկատմամբ.
2) հողամասերն ըստ նպատակային և գործառնական նշանակությամբ օգտագործելու նկատմամբ.
3) հողօգտագործման սահմանների և սահմանանիշերի պահպանման նկատմամբ.
4) հողերի պահպանմանն ուղղված միջոցառումների նկատմամբ.
