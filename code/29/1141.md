# Հոդված 1141. Հարակից իրավունքների պահպանության նշանները
Ձայնագրման և տեսագրում ստեղծողը ու կատարողն իրենց իրավունքների մասին ծանուցման նպատակով կարող են օգտագործել հարակից իրավունքների պահպանության նշանը, որը տեղադրվում է ձայնագրության և տեսագրության յուրաքանչյուր օրինակի և (կամ) այն պարունակող տուփի վրա ու կազմված է`
1) շրջանակի մեջ լատիներեն «P» տառից.
2) բացառիկ հարակից իրավունքների տիրոջ անունից (անվանումից).
3) ձայնագրման և տեսագրման առաջին անգամ լույս ընծայման տարեթվից:
