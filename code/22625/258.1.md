# Հոդված 258¹. Հասարակական կարգը խախտող խմբային գործողություններ կազմակերպելը, դրանց ակտիվորեն մասնակցելը
Խմբային այնպիսի ապօրինի գործողություններ կազմակերպելը կամ դրանց ակտիվորեն մասնակցելը, որոնք կոպիտ կերպով խախտում են հասարակական կարգը, այն է` առաջացրել են պետական կամ տեղական ինքնակառավարման մարմինների, կապի կազմակերպությունների կամ տրանսպորտի աշխատանքի խանգարում և զուգորդված են իշխանության ներկայացուցիչների օրինական պահանջներին բացահայտորեն չհնազանդվելու հետ, եթե բացակայում են ավելի ծանր հանցագործության հատկանիշներ`
