# Հոդված 813. Պահատվության պայմանագիր
1. Պահատվության պայմանագրով մի կողմը (պահառուն) պարտավորվում է պահել մյուս կողմի (պահատուի) կողմից իրեն հանձնված գույքը և այն վերադարձնել պահպանված վիճակում:
2.
