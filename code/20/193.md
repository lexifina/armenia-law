# Հոդված 193. Ողորկափող որսորդական հրազենը և ռազմամթերքը իրացնելուց խուսափելը
(վերնագիրը փոփ. 09.06.22 ՀՕ-155-Ն)
Ողորկափող որսորդական հրազենը և ռազմամթերքը իրացնելուց այն քաղաքացիների խուսափելը, որոնց զենք և ռազմամթերք պահելու թույլտվությունը չեղյալ է հայտարարվել ոստիկանության կողմից որսորդական ընկերություններից դուրս գալու կապակցությամբ`
առաջացնում է տուգանքի նշանակում սահմանված նվազագույն աշխատավարձի երեսնապատիկի չափով` զենքի և ռազմամթերքի հատուցմամբ առգրավումով:
(193-րդ հոդվածը խմբ. 02.09.93 ՀՕ-79, փոփ. 07.02.12 ՀՕ-2-Ն, 09.06.22 ՀՕ-155-Ն)
(հոդվածը 05.10.22 ՀՕ-378-Ն օրենքի փոփոխությամբ ուժի մեջ կմտնի «Զենքի շրջանառության կարգավորման մասին» օրենքն ուժի մեջ մտնելու օրվանից)
