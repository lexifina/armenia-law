# Հոդված 40.8. Քարոզչություն կատարելու իրավունք չունեցող անձանց կողմից նախընտրական կամ հանրաքվեի քարոզչություն կատարելը և քարոզչական նյութեր տարածելը
(վերնագիրը խմբ. 25.05.16 ՀՕ-55-Ն)
Քարոզչության իրականացման համար օրենքով սահմանված ժամանակահատվածում նախընտրական կամ հանրաքվեի քարոզչություն կատարելու իրավունք չունեցող անձանց կողմից նախընտրական քարոզչություն կատարելը և ցանկացած բնույթի քարոզչական նյութ տարածելը`
առաջացնում են տուգանքի նշանակում` նվազագույն աշխատավարձի հարյուրապատիկից մինչև երկուհարյուրապատիկի չափով:
