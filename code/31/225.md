# Հոդված 225. Վճռաբեկ բողոք բերելու հիմքերը
Վճռաբեկ բողոք բերելու համար հիմք են`
1) գործին մասնակցող անձանց նյութական կամ դատավարական իրավունքի խախտումը.
2) նոր երևան եկած հանգամանքները:
Սույն հոդվածի առաջին մասի 1-ին ենթակետով նախատեսված հիմքով վճռաբեկ բողոք կարող է ներկայացվել դատարանի վճիռը կամ որոշումն օրինական ուժի մեջ մտնելուց հետո` եռամսյա ժամկետում: (225-րդ հոդվածը լրաց. 20.02.01 ՀՕ-146)
