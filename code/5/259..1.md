# Հոդված 259.¹. Զենքի հետ, ինչպես նաև շրջապատի համար մեծ վտանգ ներկայացնող նյութերի և առարկաների հետ վարվելու կանոնների խախտումը
ա) Զենքի հետ, ինչպես նաև շրջապատի համար մեծ վտանգ ներկայացնող զինամթերքի, պայթուցիկ, ռադիոակտիվ և այլ նյութերի ու առարկաների հետ վարվելու կանոնների խախտումը, որի հետևանքով տուժողին մարմնական վնասվածքներ են պատճառվել`
պատժվում են ազատազրկմամբ մինչև երեք տարի ժամանակով:
բ) Նույն արարքը, եթե դրա հետևանքով մարմնական վնասվածքներ են պատճառվել մի քանի անձանց կամ մահացել է տուժողը`
պատժվում է ազատազրկմամբ մեկ տարուց մինչև տասը տարի ժամանակով:
գ) Սույն հոդվածի «ա» կետով նախատեսված արարքը,որ առաջացրել է մի քանի անձանց մահ կամ այլ ծանր հետևանքներ`
պատժվում է ազատազրկմամբ երեքից մինչև տասնհինգ տարի ժամանակով:
