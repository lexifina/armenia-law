# Հոդված 52. Դատապարտյալների նկատմամբ կիրառվող տույժի միջոցները
1. Կարգապահական գումարտակի ներքին կանոնակարգով սահմանված պատժի կրման կարգը և պայմանները խախտելու համար դատապարտյալի նկատմամբ սահմանված կարգով կարող են կիրառվել տույժի հետևյալ միջոցները.

2) խիստ նկատողություն.
3) կարգապահական կալանք՝ մինչև տասնհինգ օր ժամկետով:
2. Կարգապահական կալանքը դատապարտյալը կրում է կարգապահական գումարտակի կալանատան մենախցերում:
3. Կարգապահական կալանք կրելու ժամանակամիջոցում դատապարտյալին արգելվում են տեսակցությունները, հեռախոսակապից օգտվելը, դրամական փոխանցումներ, հանձնուքներ ու ծանրոցներ ստանալը և ուղարկելը, նամակագրություն վարելը, գրականությունից և զանգվածային լրատվությունից օգտվելը, աշխատելը, քաղաքացիաիրավական գործարքներին մասնակցելը։
