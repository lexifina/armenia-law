# Հոդված 228. Պոռնկագրական առարկաներ պատրաստելը կամ վաճառելը
Պոռնկագրական երկեր, տպագրական հրապարակություններ, նկարներ կամ պոռնկագրական բնույթի այլ առարկներ պատրաստելը, տարածելը կամ ռեկլամելը, այլև դրանց առևտուրը, կամ վաճառելու, կամ տարածելու նպատակով պահելը`
պատժվում են ազատազրկմամբ մինչև մեկ տարի ժամանակով , կամ տուգանքով մինչև երեք հարյուր դրամ` պոռնկագրական առարկների և դրանց արտադրման միջոցների բռնագրավումով:
(29.12.82 խմբագրությամբ)
