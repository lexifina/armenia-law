# Հոդված 47. ՀՈՂԱՄԱՍԻ ԱՆՀԱՏՈՒՅՑ (ՄՇՏԱԿԱՆ) ՕԳՏԱԳՈՐԾՄԱՆ ԻՐԱՎՈՒՆՔԸ
1. Հողամասի անհատույց (մշտական) օգտագործում է համարվում սեփականատիրոջ կողմից այլ անձի` օգտագործման իրավունքով անժամկետ տրամադրված հողամասի տիրապետման և օգտագործման իրավունքը:
2. Սույն օրենսգրքի 75-րդ հոդվածի 1-ին կետով նախատեսված դեպքերում անհատույց (մշտական) օգտագործման իրավունքով տրամադրված հողամասերի օգտագործողները, պետական կառավարման ու տեղական ինքնակառավարման մարմինների համաձայնությամբ կարող են հողամասերը հանձնել վարձակալության, ինչպես նաև կամովին հրաժարվել դրանցից, եթե այլ բան նախատեսված չէ պայմանագրով:
3. Անհատույց օգտագործման իրավունքի հետ կապված իրավահարաբերությունները կարգավորվում են Քաղաքացիական օրենսգրքով:
