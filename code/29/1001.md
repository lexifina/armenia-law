# Հոդված 1001. Ապահովագրողի` ապահովագրական ռիսկը գնահատելու իրավունքը
1. Գույքի ապահովագրության պայմանագիր կնքելիս ապահովագրողն իրավունք ունի ապահովագրվողի գույքը զննել, իսկ անհրաժեշտության դեպքում նշանակել փորձաքննություն` դրա իրական արժեքը պարզելու նպատակով:
