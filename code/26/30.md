# Հոդված 30. Մաքսային հսկողության գոտիները
Մաքսային հսկողության գոտիները սահմանում է Հայաստանի Հանրապետության կառավարությունը` մաքսային վարչության առաջարկությամբ: Մաքսային հսկողության ներքո ապրանքների և այլ առարկաների պահպանումն իրականացնող ձեռնարկությունների, հիմնարկների ու կազմակերպությունների տարածքում կամ շենքերում Հայաստանի Հանրապետության մաքսային վարչությունն է որոշում մաքսային հսկողության գոտիների տարածքը:
Ապրանքների և այլ առարկաների տեղափոխումը մաքսային սահմանով իրականացվում է մաքսատան կամ մաքսային կետի հսկողության ներքո:
