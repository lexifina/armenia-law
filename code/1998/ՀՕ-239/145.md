# Հոդված 145. Կենդանիներ
1. Կենդանիների նկատմամբ կիրառվում են գույքի մասին ընդհանուր կանոնները, եթե այլ բան նախատեսված չէ օրենքով կամ այլ իրավական ակտերով:
2. Իրավունքներն իրացնելիս կենդանիների նկատմամբ արգելվում է «Կենդանիների նկատմամբ պատասխանատու վերաբերմունքի մասին» օրենքի սկզբունքներին հակասող վերաբերմունքը:
(145-րդ հոդվածը խմբ. 25.03.26 ՀՕ-130-Ն)
