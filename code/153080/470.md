# Հոդված 470. Անօրինական միգրացիայի կազմակերպումը
1. Օտարերկրյա քաղաքացու կամ քաղաքացիություն չունեցող անձի մուտքը Հայաստանի Հանրապետություն, Հայաստանի Հանրապետությունում նրա գտնվելը կամ Հայաստանի Հանրապետության տարածքով տարանցումը (տեղափոխումը) շահադիտական նպատակով կազմակերպելը, որը կատարվել է մուտքի, գտնվելու կամ տարանցման համար օրենսդրությամբ սահմանված կարգը խախտելով, կամ մուտքի, գտնվելու կամ տարանցման պատշաճ թույլտվություն ստանալու համար կեղծ փաստաթուղթ կամ կեղծ տեղեկություն ներկայացնելով՝
պատժվում է տուգանքով՝ քսանապատիկից քառասնապատիկի չափով, կամ կարճաժամկետ ազատազրկմամբ` առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ մեկից չորս տարի ժամկետով:
2. Անձի՝ Հայաստանի Հանրապետությունից ելքը, օտարերկրյա պետություն մուտքը կամ օտարերկրյա պետությունում գտնվելը շահադիտական նպատակով կազմակերպելը, որը կատարվել է ելքի, մուտքի կամ գտնվելու համար օրենսդրությամբ սահմանված կարգը խախտելով, կամ ելքի, մուտքի կամ գտնվելու պատշաճ թույլտվություն ստանալու համար կեղծ փաստաթուղթ կամ կեղծ տեղեկություն ներկայացնելով՝
պատժվում է տուգանքով՝ քսանապատիկից քառասնապատիկի չափով, կամ կարճաժամկետ ազատազրկմամբ` առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ մեկից չորս տարի ժամկետով:
3. Սույն հոդվածի 1-ին կամ 2-րդ մասով նախատեսված արարքը, որը կատարվել է՝
1) մի խումբ անձանց կողմից նախնական համաձայնությամբ,
2) մարդու կյանքի կամ առողջության համար վտանգավոր կամ անձի պատիվն ու արժանապատվությունը նվաստացնող պայմաններում կամ
