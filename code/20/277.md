# Հոդված 277. Վարչական իրավախախտումների վերաբերյալ գործերի քննության ժամկետները
Վարչական իրավախախտումների վերաբերյալ գործերը քննվում են վարչական իրավախախտման վերաբերյալ արձանագրությունը և մյուս նյութերը գործի քննության համար լիազորված մարմնի (պաշտոնատար անձի) կողմից ստանալու օրվանից սկսած տասնհինգօրյա ժամկետում:
Սույն օրենսգրքի 40¹, 40³-40⁶, 44, 163, 172, 175, 180¹ և 182 հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը քննվում են մեկ օրվա ընթացքում, սույն օրենսգրքի 147, 162², 163 հոդվածներով նախատեսվածները` երեք օրվա ընթացքում, սույն օրենսգրքի 53 հոդվածով նախատեսվածները` հնգօրյա ժամկետում, սույն օրենսգրքի 103, 105, 106 հոդվածներով նախատեսվածները` յոթնօրյա ժամկետում:
ԽՍՀ Միության և Հայաստանի Հանրապետության օրենսդրությամբ կարող են նախատեսվել նաև վարչական իրավախախտումների վերաբերյալ գործերի քննության այլ ժամկետներ:
(28.05.86, 10.03.90, 02.08.91, 19.05.95 խմբագրությամբ)
