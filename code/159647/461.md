# Հոդված 461. Անցումային դրույթներ՝ սույն Օրենսգրքի 370-րդ հոդվածի վերաբերյալ
Մինչև տեղեկատվության փոխանակման սույն Օրենսգրքի 370-րդ հոդվածի 2-րդ կետով նախատեսված տեխնիկական պայմաններն ընդունելը կիրառվում են տեղեկատվության փոխանակման այն տեխնիկական պայմանները, որոնք հաստատված են «Մաքսային Միության անդամ պետությունների մաքսային մարմինների վերլուծական և հսկողական գործառույթներն իրականացնելու նպատակով տեղեկատվության փոխանակումը կազմակերպելու մասին» 2011 թվականի հոկտեմբերի 19-ի համաձայնագրի 4-րդ հոդվածին համապատասխան:
