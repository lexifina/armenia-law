# Հոդված 289. Դիմումին առաջադրվող պահանջները
1. Դիմումին կցվում են հաշտության համաձայնության բնօրինակը, հաշտության համաձայնությամբ տնօրինված իրավունքի վերաբերյալ իրավահաստատող փաստաթղթերը (առկայության դեպքում), արտոնագրված հաշտարարի մասնակցությամբ հաշտարարի վարձատրության վերաբերյալ ապացույցը (վճարած լինելու դեպքում), ինչպես նաև դիմումի օրինակը հաշտության համաձայնություն կնքած մյուս անձանց ուղարկելը հավաստող ապացույցներ։
