# Հոդված 144. Զինված ընդհարման ժամանակ մշակութային արժեքները ոչնչացնելը, վնասելը, հափշտակելը կամ առգրավելը կամ դրանց նպատակային նշանակությունը փոփոխելը
1. Միջազգային զինված ընդհարման կամ միջազգային բնույթ չկրող զինված ընդհարման ժամանակ մշակութային արժեքների պաշտպանությունը կանոնակարգող միջազգային փաստաթղթերով սահմանված մշակութային արժեքներ ոչնչացնելը, վնասելը, հափշտակելը, դրանց գտնվելու վայրից դրանք ապօրինաբար տեղափոխելը, այդ թվում՝ մի պետության տարածքից մյուսը, կամ ապօրինաբար տեղափոխված մշակութային արժեքները չվերադարձնելը կամ պատմական, մշակութային կամ գիտական ապացույցը ոչնչացնելու կամ թաքցնելու նպատակով մշակութային արժեքները կամ դրանց նպատակային նշանակությունը փոփոխելը՝
