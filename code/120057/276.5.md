# Հոդված 276.5. Դատարանի վճիռը
1. Առանց անձի համաձայնության հիվանդության օջախ մուտք գործելու վերաբերյալ դիմումի քննության արդյունքներով դատարանը կայացնում է դիմումը բավարարելու կամ մերժելու մասին վճիռ:
2. Առանց անձի համաձայնության հիվանդության օջախ մուտք գործելու վերաբերյալ դիմումը բավարարելու մասին դատարանի վճիռը հիմք է հիվանդության օջախ մուտք գործելու անձի կամ նրա ներկայացուցչի մասնակցությամբ, որին սեփականության իրավունքով կամ օրինական այլ հիմքով պատկանում է հիվանդության օջախ հանդիսացող վայրը (տարածքը, շինությունը, բնակարանը և այլն), և սույն գլխով սահմանված գործողություններն իրականացնելու համար:
3. Առանց անձի համաձայնության հիվանդության օջախ մուտք գործելու վերաբերյալ դիմումը բավարարելու մասին դատարանի վճռում նշվում է նաև վայրը, որտեղ պետք է կատարվեն սույն գլխով սահմանված գործողությունները, դրանց կատարման ժամկետը:
4. Առանց անձի համաձայնության հիվանդության օջախ մուտք գործելու վերաբերյալ դիմումը բավարարելու մասին դատարանի վճիռը հրապարակման պահից մտնում է օրինական ուժի մեջ:
