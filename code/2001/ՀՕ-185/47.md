# Հոդված 47. ՀՈՂԱՄԱՍԻ ԱՆՀԱՏՈՒՅՑ ՕԳՏԱԳՈՐԾՄԱՆ ԻՐԱՎՈՒՆՔԸ
(վերնագիրը փոփ. 18.04.25 ՀՕ-85-Ն)
1. Հողամասի անհատույց օգտագործում է համարվում սեփականատիրոջ կողմից այլ անձի` օգտագործման իրավունքով տրամադրված հողամասի տիրապետումն ու օգտագործումը:
2. Սույն օրենսգրքի 75-րդ հոդվածի 1-ին կետով նախատեսված դեպքերում անհատույց օգտագործման իրավունքով տրամադրված հողամասերի օգտագործողները, պետական կառավարման ու տեղական ինքնակառավարման մարմինների համաձայնությամբ կարող են հողամասերը հանձնել վարձակալության, ինչպես նաև կամովին հրաժարվել դրանցից, եթե այլ բան նախատեսված չէ պայմանագրով:
3. Անհատույց օգտագործման իրավունքի հետ կապված իրավահարաբերությունները կարգավորվում են Քաղաքացիական օրենսգրքով:
(47-րդ հոդվածը լրաց. 04.10.05 ՀՕ-199-Ն, խմբ. 23.06.11 ՀՕ-245-Ն, փոփ. 18.04.25 ՀՕ-85-Ն)
