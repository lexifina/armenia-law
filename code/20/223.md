# Հոդված 223. Առաջին ատյանի դատարանների դատավորները

Հայաստանի Հանրապետության գերագույն դատարանի դատավորները քննում են սույն օրենսգրքի 206¹, 206², 206³ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը, եթե այդ իրավախախտումները կատարվել են Հայաստանի Հանրապետության գերագույն դատարանի կողմից արդարադատություն իրականացնելու ժամանակ:
