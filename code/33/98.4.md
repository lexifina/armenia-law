# Հոդված 98⁴. Անձնական անվտանգությունն ապահովելը, բնակարանը և այլ գույքը պահպանելը
1. Քրեական վարույթն իրականացնող մարմինը, համագործակցելով այլ իրավասու մարմինների հետ, իրականացնում է պաշտպանվող անձի անձնական պահպանությունը, նրա բնակարանի կամ այլ գույքի պահպանությունը:
2. Պաշտպանվող անձի բնակարանը կամ այլ գույքը սարքավորվում են հակահրդեհային կամ ազդանշանային տեխնիկական միջոցներով, փոխվում են նրա բնակարանի կամ անձնական այլ հեռախոսահամարները կամ նրան պատկանող տրանսպորտային միջոցի (միջոցների) պետական համարանիշերը:
