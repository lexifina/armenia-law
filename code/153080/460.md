# Հոդված 460. Ինքնիրավչությունը
1. Ինքնիրավչությունը՝ օրենսդրությամբ սահմանված կարգի խախտմամբ իր իրական կամ ենթադրյալ իրավունքն ինքնակամ իրականացնելը, որն էական վնաս է պատճառել անձի կամ կազմակերպության իրավունքներին, ազատություններին կամ օրինական շահերին կամ հասարակության կամ պետության օրինական շահերին՝
պատժվում է տուգանքով՝ առավելագույնը տասնապատիկի չափով, կամ հանրային աշխատանքներով՝ առավելագույնը հարյուր ժամ տևողությամբ, կամ կարճաժամկետ ազատազրկմամբ՝ առավելագույնը մեկ ամիս ժամկետով, կամ ազատազրկմամբ՝ առավելագույնը մեկ տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը կատարվել է բռնություն գործադրելով կամ բռնություն գործադրելու սպառնալիքով՝
պատժվում է տուգանքով՝ տասնապատիկից երեսնապատիկի չափով, կամ հանրային աշխատանքներով՝ հարյուրից երկու հարյուր ժամ տևողությամբ, կամ կարճաժամկետ ազատազրկմամբ՝ մեկից երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ մեկից երեք տարի ժամկետով:
