# Հոդված 159. Ոգելից խմիչքների առևտրի կանոնները խախտելը
Առևտրական ձեռնարկությունների և հասարակական սննդի ձեռնարկությունների աշխատողների կողմից օղու և մյուս ոգելից խմիչքների առևտրի կանոնները խախտելը`
