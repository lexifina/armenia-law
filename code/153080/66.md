# Հոդված 66. Կարգապահական գումարտակում պահելը
1. Կարգապահական գումարտակում պահելը հանցանք կատարած զինծառայողին (բացառությամբ սպայական և ավագ ենթասպայական կազմերի) մեկուսացման պայմաններում անազատության մեջ պահելն է։
2. Կարգապահական գումարտակը նշանակվում է ոչ մեծ և միջին ծանրության հանցագործություններ կատարած զինծառայողի նկատմամբ` 3 ամսից 3 տարի ժամկետով, ինչպես նաև այն դեպքերում, երբ դատարանը, հաշվի առնելով գործի հանգամանքները և նախկինում ազատությունից զրկելու հետ կապված պատիժ չկրած դատապարտյալի անձնավորությունը, նպատակահարմար է համարում առավելագույնը 3 տարի ժամկետով ազատազրկման փոխարեն կիրառել կարգապահական գումարտակում պահելը՝ նույն ժամկետով:
