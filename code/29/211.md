# Հոդված 211. Կամավոր սերվիտուտ
1. Կամավոր սերվիտուտը սահմանվում է սերվիտուտ պահանջող անձի և հարևան կամ այլ հողամասի սեփականատիրոջ` նոտարական կարգով վավերացված գրավոր համաձայնությամբ:
2. Կամավոր սերվիտուտ սահմանելու մասին պայմանագրում պետք է նշվեն սերվիտուտի գործողության ժամկետը և պայմանները: Պայմանագրին կցվում է սերվիտուտով ծանրաբեռնված անշարժ գույքի հատակագիծը` սերվիտուտի տեղակայման նշումով:
(211-րդ հոդվածը լրաց. 20.03.01 ՀՕ-159)
