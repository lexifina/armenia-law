# Հոդված 210. Ուրիշի հողամասից սահմանափակ օգտվելու իրավունք (սերվիտուտ)
1. Հողամասի սեփականատերն իրավունք ունի հարևան հողամասի սեփականատիրոջից պահանջել իրեն տրամադրելու այդ հողամասի սահմանափակ օգտագործման իրավունք (սերվիտուտ):
2. Սերվիտուտ կարող է սահմանվել հարևան հողամասով անցնելու և երթևեկելու, էլեկտրահաղորդման, կապի գծերի և խողովակաշարերի անցկացման ու շահագործման, ջրամատակարարման և հողաբարելավման, ինչպես նաև անշարժ գույքի սեփականատիրոջ այլ կարիքների համար, որոնք չեն կարող ապահովվել առանց սերվիտուտի սահմանման:
