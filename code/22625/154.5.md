# Հոդված 154⁵. Վստահված անձին, ընտրական հանձնաժողովի անդամին, դիտորդին կամ զանգվածային լրատվության միջոցի ներկայացուցչին ընտրական փաստաթղթերին ծանոթանալուն խոչընդոտելը, ընտրական հանձնաժողովի արձանագրությունների պատճեններ չտալը
