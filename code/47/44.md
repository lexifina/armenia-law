# Հոդված 44. Դատապարտյալի աշխատավայրի վարչակազմի պարտականությունները
1. Դատապարտյալի աշխատավայրի վարչակազմն ապահովում է դատապարտյալի աշխատավարձից ճիշտ և ժամանակին պահումներ կատարելը և դրանք սահմանված կարգով փոխանցելը, ազատությունից զրկելու հետ չկապված պատիժների կատարման ստորաբաժանմանը տեղեկացնում է դատապարտյալի նկատմամբ կիրառված խրախուսանքի և տույժի միջոցների, դատապարտյալի` պատիժը կրելուց խուսափելու մասին, ինչպես նաև նախապես տեղեկացնում է դատապարտյալին այլ պաշտոնի փոխադրելու կամ աշխատանքից ազատելու մասին:
