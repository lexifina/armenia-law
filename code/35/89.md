# Հոդված 89. Հանրապետության Նախագահի թեկնածու առաջադրելու և գրանցելու ժամկետները
1. Կուսակցության կամ ինքնաառաջադրվող քաղաքացու կողմից Հանրապետության Նախագահի թեկնածու առաջադրելու համար անհրաժեշտ փաստաթղթերը կենտրոնական ընտրական հանձնաժողով են ներկայացվում ընտրության օրվանից ոչ շուտ, քան 90 և ոչ ուշ, քան 75 օր առաջ` մինչև ժամը 18.00-ն:
2. (2-րդ կետն ուժը կորցրել է 22.12.06 ՀՕ-1-Ն)
