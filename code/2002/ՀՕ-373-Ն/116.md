# Հոդված 116. Սույն օրենսգրքի պահանջների խախտման հետևանքով պատճառված վնասների հատուցումը
Սույն օրենսգրքի պահանջները խախտող անձինք պարտավոր են հատուցել իրենց գործունեության հետևանքով պատճառված վնասները՝ օրենքով սահմանված կարգով։
Պաշտոնատար անձինք, որոնց մեղքով ջրօգտագործողները կրել են վնասներ, պատասխանատվություն են կրում օրենսդրությամբ սահմանված կարգով։
