# Հոդված 201. Արհեստավարժ մարզամրցումների և հանդիսադիր առևտրային մրցույթների մասնակիցներին ու կազմակերպություններին կաշառելը
1. Մարզիկներին, մրցավարներին, մարզիչներին, թիմերի ղեկավարներին կամ արհեստավարժ մարզամրցումների մյուս մասնակիցներին ու կազմակերպություններին, ինչպես նաև հանդիսադիր առևտրային մրցույթների կազմակերպիչներին ու մրցանակաբաշխային հանձնաժողովի անդամներին կաշառելն այդ մրցույթների արդյունքների վրա ազդելու նպատակով՝
պատժվում է տուգանքով՝ նվազագույն աշխատավարձի երկուհարյուրապատիկից հինգհարյուրապատիկի չափով, կամ ուղղիչ աշխատանքներով՝ վեց ամսից մեկ տարի ժամկետով, կամ կալանքով՝ առավելագույնը երկու ամիս ժամկետով:
2. Նույն արարքները, որոնք կատարվել են մի խումբ անձանց կողմից նախնական համաձայնությամբ կամ կազմակերպված խմբի կողմից՝
պատժվում են ազատազրկմամբ՝ առավելագույնը հինգ տարի ժամկետով:
3.
