# Հոդված 15. Անտառաշինական նախագիծը
1. Անտառաշինության ընթացքում անտառային տնտեսության վարման նպատակով կազմվում են համապատասխան նախագծեր, որոնք տալիս են անցած ժամանակաշրջանի համար անտառային տնտեսության վարման և անտառօգտագործման ամբողջական գնահատականը, ինչպես նաև անտառային տնտեսության վարման առաջիկա 10 տարիներին իրականացվելիք միջոցառումները:
2. Անտառաշինական նախագծերի մշակման հրահանգը հաստատում է պետական կառավարման լիազորված մարմինը:
3. Անտառաշինական նախագծերը պետական կառավարման լիազորված մարմնի կողմից հաստատվելուց հետո համարվում են անտառային տնտեսության վարման ընթացիկ և հեռանկարային պլանավորման պարտադիր տեխնիկական փաստաթղթեր:
