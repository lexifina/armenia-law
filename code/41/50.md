# Հոդված 50. Հավատարմագրային կառավարման հանձնելու միջոցով ջրային համակարգի օգտագործման իրավունքի փոխանցումը
Հավատարմագրային կառավարման կարող է տրամադրվել ջրային համակարգը կամ դրա մասը:
Ջրային համակարգը հավատարմագրային կառավարման է տրամադրվում մրցութային եղանակով:
Հավատարմագրային կառավարման հանձնելու դեպքում ջրային համակարգը (այդ թվում՝ մրցույթի պայմանները կատարելու համար հավատարմագրային կառավարչի կողմից ձեռք բերված գույքը) մնում է պետական սեփականություն:
Ջրային համակարգը հավատարմագրային կառավարման տրամադրելու մրցույթի մասին հրապարակային հայտարարության մեջ նշվում են հավատարմագրային կառավարման ժամկետները, պահանջվող ներդրումների մեծությունը, հավատարմագրային կառավարչին հասանելիք վարձատրության մեկնարկային չափը, ջրային համակարգի օգտագործման, ինչպես նաև տվյալ ջրային համակարգի աշխատողների սոցիալական երաշխիքներին վերաբերող պահանջները:
Մրցույթին մասնակցելու համար հայտ ներկայացրած անձը պետք է ներկայացնի հավատարմագրային կառավարման ծրագիր, որը պետք է ներառի՝
1) առաջարկություններ ներդրումներ կատարելու վերաբերյալ.
2) հավատարմագրային կառավարչի վարձատրության չափը.
3) հավատարմագրային կառավարման կատարումն ապահովող գրավի չափը.
4) ջրապահպան միջոցառումների իրականացման ծրագիրը.
