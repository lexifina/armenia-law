# Հոդված 294. Հեռակա դատաքննության կիրառումը դադարեցնելը
1. Դատարանը որոշում է կայացնում հեռակա դատաքննության կիրառումը դադարեցնելու և գործի քննությունն ընդհանուր կարգով իրականացնելու մասին, եթե՝
1) գործը հեռակա դատաքննության կարգով քննելու ընթացքում գործին մասնակցող անձը ներկայացրել է նոր ապացույց՝ այն թույլատրելու միջնորդությամբ, կամ նոր ապացույց ձեռք բերելուն ուղղված միջնորդություն, և այդ միջնորդությունը դատարանը բավարարել է.
2) գործը հեռակա դատաքննության կարգով քննելու ընթացքում ի հայտ են եկել այլ հանգամանքներ, որոնք պարզելու համար անհրաժեշտ է գործի քննությունն անցկացնել ընդհանուր կարգով:
2. Սույն հոդվածի 1-ին մասով նախատեսված որոշումը կայացնելու դեպքում դատարանը վերսկսում է նախնական դատական նիստը:
3. Հեռակա դատաքննության կիրառումը դադարեցնելու և գործի քննությունն ընդհանուր կարգով իրականացնելու մասին որոշումը՝ նախնական դատական նիստի ժամանակի և վայրի մասին նշումով, եռօրյա ժամկետում ուղարկվում է գործին մասնակցող անձանց:
