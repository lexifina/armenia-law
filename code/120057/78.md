# Հոդված 78. Իրեղեն ապացույցները
1. Իրեղեն ապացույցներ են նյութական աշխարհի այն օբյեկտները, որոնք իրենց առկայությամբ, դրությամբ, արտաքին տեսքով, ներքին հատկություններով, գտնվելու վայրով կամ այլ հատկանիշներով կարող են գործի լուծման համար նշանակություն ունեցող փաստերի հաստատման կամ ժխտման միջոց դառնալ։
