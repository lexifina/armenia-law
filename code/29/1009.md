# Հոդված 1009. Համաապահովագրություն
Ապահովագրության օբյեկտը կարող է ապահովագրվել մեկ ապահովագրության պայմանագրով մի քանի ապահովագրողների կողմից համատեղ (համաապահովագրություն): Եթե այդպիսի պայմանագրում որոշված չեն ապահովագրողներից յուրաքանչյուրի իրավունքները և պարտականությունները, նրանք ապահովագրվողի (ապահովագրված անձի կամ շահառուի) առջև համապարտ պատասխանատվություն են կրում գույքային ապահովագրության պայմանագրով ապահովագրական հատուցում կամ անձնական ապահովագրության պայմանագրով ապահովագրական գումար վճարելու համար:
(1009-րդ հոդվածը լրաց. 11.06.04 ՀՕ-100-Ն)
