# Հոդված 290. Որոշման կատարման կասեցումը գանգատ տալու կամ բողոք բերելու կապակցությամբ
Սահմանված ժամկետում գանգատ տալը կասեցնում է վարչական տույժ նշանակելու որոշման կատարումը մինչև գանգատը քննելը, բացառությամբ սույն օրենսգրքի 25, 28.1 և 29, 31.1-ին հոդվածներով նախատեսված տույժի միջոցները կիրառելու մասին որոշումների, ինչպես նաև վարչական իրավախախտում կատարելու տեղում գանձվող տուգանք նշանակելու դեպքերում:
Դատախազի կողմից բողոք բերելը կասեցնում է որոշման կատարումը մինչև բողոքը քննելը:
