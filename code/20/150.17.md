# Հոդված 150.17. Ինտերնետ հասանելիության ծառայություններ մատուցող հանրային էլեկտրոնային հաղորդակցության ցանցի օպերատորների կողմից օտարերկրյա պետություններում կազմակերպված և Հայաստանի Հանրապետության օրենսդրությամբ սահմանված համապատասխան լիցենզիա չունեցող կազմակերպությունների կազմակերպած վիճակախաղի (տոտալիզատորի) և ինտերնետ շահումով խաղերի կայքերի՝ օրենքով սահմանված կարգով արգելափակման պարտականությունները չկատարելը կամ ոչ պատշաճ կատարելը
(հոդվածը 20.03.24 ՀՕ-134-Ն օրենքի լրացման մասով ուժի մեջ է մտնում նույն օրենքի պաշտոնական հրապարակումից վեց ամիս հետո)
