# Հոդված 26. Հանցանքն անզգուշությամբ կատարելը
1. Անզգուշությունը դրսևորվում է հանցավոր ինքնավստահությամբ կամ հանցավոր անփութությամբ:
2. Հանցանքը համարվում է հանցավոր ինքնավստահությամբ կատարված, եթե անձը նախատեսում է իր արարքի վտանգավոր հետևանքների առաջացման հնարավորությունը, սակայն առանց բավարար հիմքերի համոզված է լինում, որ տվյալ դեպքում դրանք կկանխվեն:
3. Հանցանքը համարվում է հանցավոր անփութությամբ կատարված, եթե անձը չի նախատեսում իր արարքի վտանգավոր հետևանքների առաջացման հնարավորությունը, թեև տվյալ իրադրությունում պարտավոր էր և կարող էր նախատեսել: Հանցանքը համարվում է անփութությամբ կատարված նաև սույն օրենսգրքի 28-րդ հոդվածի 7-րդ մասով նախատեսված պայմանների առկայության դեպքում:
