# Հոդված 128. Շահութահարկի նվազեցված դրույքաչափերը
(հոդվածն ուժը կորցրել է 21.06.18 ՀՕ-338-Ն)
(21.06.18 ՀՕ-338-Ն օրենքի 86-րդ հոդվածի համաձայն` մինչև 2019 թվականի հունվարի 1-ը Կառավարության հավանությանն արժանացած՝ Օրենսգրքի 128-րդ հոդվածով սահմանված ծրագիր իրականացնող ռեզիդենտ շահութահարկ վճարողի և այդ ծրագրում ընդգրկված Հայաստանի Հանրապետության այլ ռեզիդենտ շահութահարկ վճարողների նկատմամբ Օրենսգրքի 128-րդ հոդվածը շարունակում է կիրառվել մինչև 2029 թվականի դեկտեմբերի 31-ը ներառյալ:)
