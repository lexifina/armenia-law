# Հոդված 178. Երեխայի դաստիարակության, ուսուցման կամ խնամքի պարտականությունը չկատարելը կամ ոչ պատշաճ կատարելը
(վերնագիրը խմբ. 09.06.22 ՀՕ-155-Ն)
1. Ծնողի, այլ օրինական ներկայացուցչի կամ այլ անձի կողմից, որի վրա երեխայի դաստիարակության, ուսուցման կամ խնամքի պարտականություն է դրված, այդ պարտականությունը չկատարելը կամ ոչ պատշաճ կատարելը, ինչպես նաև անչափահասների կողմից թմրամիջոցներ օգտագործելն առանց բժշկի նշանակման կամ նրանց կողմից այլ իրավախախտումներ կատարելը`
