# Հոդված 301. Պարզեցված վարույթը դադարեցնելը
1. Եթե սույն օրենսգրքի 297-րդ հոդվածի 4-րդ մասով սահմանված հանգամանքներն ի հայտ են եկել պարզեցված վարույթ կիրառելու վերաբերյալ դատարանի որոշումը կայացնելուց հետո, բայց ոչ ուշ, քան մինչև եզրափակիչ դատական ակտ հրապարակելը, դատարանը որոշում է կայացնում գործն ընդհանուր հայցային վարույթի կարգով քննելու մասին և սույն օրենսգրքի 166-րդ հոդվածով սահմանված կարգով հրավիրում է նախնական դատական նիստ:
