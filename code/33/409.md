# Հոդված 409. ՎԱՐՈՒՅԹԻ ՀԱՐՈՒՑՈՒՄԸ ՆՈՐ Ի ՀԱՅՏ ԵԿԱԾ ՀԱՆԳԱՄԱՆՔՆԵՐԻ ՀԵՏևԱՆՔՈՎ
1. Նոր ի հայտ եկած հանգամանքների մասին քաղաքացիների հայտարարությունները և պաշտոնատար անձանց հաղորդումներն ուղարկվում են դատախազին կամ հատուկ արտոնագիր ունեցող և վճռաբեկ դատարանում գրանցված փաստաբանին:
2.
