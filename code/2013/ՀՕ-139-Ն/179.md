# Հոդված 179. Գործի նոր քննությունից հետո կայացված՝ գործն ըստ էության լուծող դատական ակտի օրինական ուժի մեջ մտնելը
1. Գործի նոր քննությունից հետո կայացված՝ գործն ըստ էության լուծող դատական ակտն օրինական ուժի մեջ է մտնում վարչական դատարանի՝ գործն ըստ էության լուծող դատական ակտի օրինական ուժի մեջ մտնելու համար սահմանված կարգով։
