# Հոդված 176.². Հարբած կամ թմրամիջոցներ օգտագործած վիճակում տրանսպորտային միջոց վարելը
Տրանսպորտային միջոցը հարբած կամ թմրամիջոցներ օգտագործած վիճակում գտնվող անձի կողմից վարելը, որ մեկ տարվա ընթացքում կատարվել է կրկին անգամ`
պատժվում է ազատազրկմամբ մինչև մեկ տարի ժամանակով, կամ ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով, կամ տուգանքով մեկ հազար հինգ հարյուրից մինչև երկու հազար դրամի չափով, վարորդին տրանսպորտային միջոցներ վարելու իրավունքից զրկելով երեքից մինչև հինգ տարի ժամանակով:
Նույն արարքը, որ կատարվել է սույն հոդվածով նախատեսված հանցագործության համար նախկինում դատապարտված անձի կողմից`
