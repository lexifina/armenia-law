# Հոդված 201. Աշխատանքային պայմանագիրը լուծելու մասին ծանուցում ստացած աշխատողների մասնագիտական ուսուցումը
Սույն օրենսգրքի 113-րդ հոդվածի 1-ին մասի 1-ին, 3-րդ և 4-րդ կետերով նախատեսված դեպքերում աշխատանքային պայմանագիրը լուծելու մասին ծանուցում ստացած աշխատողները կարող են ուղարկվել աշխատանքի շուկայի պահանջներին համապատասխանող մասնագիտություն սովորելու կամ որակավորումը բարձրացնելու: Նրանց մասնագիտական ուսուցման կամ որակավորումը բարձրացնելու կարգը սահմանվում է Հայաստանի Հանրապետության օրենսդրությամբ:
(201-րդ հոդվածը փոփ. 27.02.06 ՀՕ-39-Ն)
