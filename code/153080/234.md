# Հոդված 234. Իրավաբանական անձի անունից կուսակցությանը նվիրատվություն կատարելը
1. Իրավաբանական անձի անունից կուսակցությանը խոշոր չափով նվիրատվություն կատարելը՝
պատժվում է տուգանքով՝ առավելագույնը քսանապատիկի չափով, կամ ազատության սահմանափակմամբ՝ առավելագույնը երկու տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ առավելագույնը երկու ամիս ժամկետով։
