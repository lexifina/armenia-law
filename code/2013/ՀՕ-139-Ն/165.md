# Հոդված 165. Վճռաբեկ դատարանում գործի դատաքննության ժամկետը
1. Վճռաբեկ դատարանը գործը քննում և որոշում է կայացնում ողջամիտ ժամկետում։
2. Վերաքննիչ դատարանի միջանկյալ դատական ակտերի և վերաքննիչ դատարանում բողոքարկված՝ վարչական դատարանի միջանկյալ դատական ակտերի դեմ բերված վճռաբեկ բողոքները քննվում են դրանք վարույթ ընդունելուց հետո՝ երեք ամսվա ընթացքում:
