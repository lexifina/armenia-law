# Հոդված 149. Կապի գծերի և կառուցվածքների պահպանության կանոնները խախտելը
Կապի գծերի և կառուցվածքների պահպանության կանոնները խախտելը, ինչպես նաև կապի գծային և կաբելային կառուցվածքները փչացնելը`
