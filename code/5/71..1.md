# Հոդված 71.¹. Պաշտոնեական գաղտնիք հանդիսացող տեղեկությունների հանձնումն օտարերկրյա կազմակերպություններին
Պաշտոնեական գաղտնիք հանդիսացող տնտեսական, գիտատեխնիկական կամ այլ տեղեկություններ օտարերկրյա կազմակերպություններին կամ նրանց ներկայացուցիչներին հանձնելը կամ հանձնելու նպատակով հավաքելն այն անձի կողմից, որն այդ տեղեկությունները վստահված են եղել ծառայության կամ աշխատանքի բերումով կամ հայտնի են դարձել այլ ճանապարհով`
պատժվում են ազատազրկմամբ մինչև երեք տարի ժամանակով կամ ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով:
Նույն գործողությունները, եթե գույքային խոշոր վնաս են պատճառել պետական կամ հասարակական կազմակերպություններին կամ այլ ծանր հետևանքներ են առաջացրել`
