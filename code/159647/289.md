# Հոդված 289. Ընդհանուր դրույթներ Միության մաքսային սահմանով խողովակաշարային տրանսպորտով կամ էլեկտրահաղորդման գծերով տեղափոխվող ապրանքների տեղափոխման կարգի և պայմանների մասին
