# Հոդված 149. Վերաքննիչ դատարանի դատական ակտերի հրապարակումը և դրանք դատավարության մասնակիցներին ուղարկելը
1. Վերաքննիչ դատարանի դատական ակտերը կայացվում կամ հրապարակվում և դատավարության մասնակիցներին են ուղարկվում վարչական դատարանի դատական ակտերի համար սույն օրենսգրքով սահմանված կարգով, բացառությամբ սույն հոդվածով նախատեսված դեպքերի։
2. Վերաքննիչ դատարանի՝ գործն ըստ էության լուծող որոշումը հրապարակվում է գործի քննությունն ավարտվելուց հետո՝ 20 օրվա ընթացքում:
