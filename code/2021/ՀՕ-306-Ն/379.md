# Հոդված 379. Վերաքննությամբ եզրափակիչ դատական ակտի հրապարակմանը հաջորդող վարույթը
1. Վերաքննության արդյունքով կայացված դատական ակտն օրինական ուժի մեջ է մտնում հրապարակումից կամ կայացումից հետո՝ մեկամսյա ժամկետում:
2. Վերաքննության արդյունքով կայացված դատական ակտը հրապարակումից կամ կայացումից հետո՝ ոչ ուշ, քան երկշաբաթյա ժամկետում, ուղարկվում է տվյալ վարույթի մասնակիցներին:
3. Բողոքարկվող դատական ակտը վերաքննության կարգով բեկանվելու և վարույթն առաջին ատյանի դատարան փոխանցելու դեպքում վարույթն իրականացվում է ընդհանուր հիմունքներով` վերաքննիչ դատարանի սահմանած ծավալով:
(379-րդ հոդվածը փոփ. 25.03.26 ՀՕ-131-Ն)
(25.03.26 ՀՕ-131-Ն օրենքն ունի անցումային դրույթ)
