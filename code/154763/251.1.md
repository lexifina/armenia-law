# Հոդված 251.1. Վերահսկելի մատակարարումը և գնումը
1. Վերահսկելի մատակարարումը և գնումը ապրանքների և ծառայությունների շրջանառության վերահսկումն է ապրանքներն ու ծառայությունները գնելու կամ այդպիսիք վաճառելու միջոցով:
2. Սույն հոդվածով նախատեսված գաղտնի քննչական գործողությունը կարող է կատարվել միայն Հայաստանի Հանրապետության քրեական օրենսգրքի 335-րդ, 393-րդ, 394-րդ և 405-րդ հոդվածներով նախատեսված հանցանքների վերաբերյալ վարույթներով։
(251.1-ին հոդվածը լրաց. 06.05.26 ՀՕ-206-Ն)
