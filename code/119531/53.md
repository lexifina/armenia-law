# Հոդված 53. Քրեական հետապնդման մեջ չգտնվող դատավորի մասնակցությամբ քննչական գործողություններ կատարելու վերաբերյալ Բարձրագույն դատական խորհրդին իրազեկելը
1. Քրեական հետապնդման մեջ չգտնվող դատավորի մասնակցությամբ քննչական գործողություն կատարելու անհրաժեշտության դեպքում մինչդատական քրեական վարույթի օրինականության նկատմամբ հսկողություն իրականացնող դատախազը քննչական գործողությունն սկսելուց առնվազն մեկ օր առաջ իրազեկում է Բարձրագույն դատական խորհրդին և համապատասխան դատավորին։
2.
