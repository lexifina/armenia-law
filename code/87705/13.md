# Հոդված 13. Դատավորի ինքնաբացարկը
1. Դատավորի ինքնաբացարկի հետ կապված հարաբերությունների վրա տարածվում են «Հայաստանի Հանրապետության դատական օրենսգիրք» Հայաստանի Հանրապետության սահմանադրական օրենքի և Հայաստանի Հանրապետության քաղաքացիական դատավարության օրենսգրքի համապատասխան նորմերը։
(13-րդ հոդվածը փոփ. 23.03.18 ՀՕ-212-Ն)
