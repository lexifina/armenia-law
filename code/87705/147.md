# Հոդված 147. Վերաքննիչ դատարանի մասնավոր որոշումը
(վերնագիրը փոփ. 02.05.24 ՀՕ-220-Ն)
1. Սույն օրենսգրքի 144-րդ հոդվածի 2-րդ մասով սահմանված դեպքում, երբ ապացույց չներկայացրած դատավարության մասնակիցը պետական կամ տեղական ինքնակառավարման մարմինն է կամ դրա պաշտոնատար անձը, վերաքննիչ դատարանը կայացնում է մասնավոր որոշում` սույն օրենսգրքի 128-րդ հոդվածով սահմանված կարգով։
(147-րդ հոդվածը փոփ. 02.05.24 ՀՕ-220-Ն)
(02.05.24 ՀՕ-220-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
