# Հոդված 198. Առանց անձը հաստատող փաստաթղթի և առանց սոցիալական ապահովության քարտի կամ սոցիալական ապահովության քարտ չունենալու մասին տեղեկանքի ներկայացման աշխատանքի ընդունելը
Գործատուի կողմից առանց անձը հաստատող փաստաթղթի և առանց սոցիալական ապահովության քարտի կամ սոցիալական ապահովության քարտ չունենալու մասին տեղեկանքի ներկայացման քաղաքացիներին աշխատանքի ընդունելը`
առաջացնում է տուգանքի նշանակում գործատուի նկատմամբ` սահմանված նվազագույն աշխատավարձի քսանապատիկի չափով:
