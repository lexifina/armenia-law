# Հոդված 291. Դատարանի վճիռը
1. Դիմումի քննության արդյունքներով դատարանը սույն օրենսգրքով սահմանված՝ հաշտության համաձայնությունը հաստատելու կանոններով կայացնում է վճիռ՝ հաշտության համաձայնությունը հաստատելու կամ դիմումը մերժելու մասին։
2. Հաշտության համաձայնությունը հաստատելու մասին վճիռը պետք է պարունակի հաշտության համաձայնության բառացի շարադրանքը (տեքստը): Հաշտության համաձայնությունը հաստատելու մասին վճռով հաշտության համաձայնության տեքստը չի հրապարակվում:
3. Հաշտության համաձայնությունը հաստատելու մասին վճիռն օրինական ուժի մեջ է մտնում հրապարակման պահից:
(291-րդ հոդվածը լրաց. 22.10.25 ՀՕ-361-Ն)
