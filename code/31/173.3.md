# Հոդված 173³. Դիմումի քննությունը
Երեխաների որդեգրումը հաստատելու մասին գործերը դատարանը քննում է խնամակալության և հոգաբարձության մարմնի, որդեգրել ցանկացող անձի և տասնչորս տարին լրացած երեխայի պարտադիր մասնակցությամբ։ Անհրաժեշտության դեպքում դատարանը գործի մասնակցությանը կարող է ներգրավել որդեգրվող երեխայի ծնողներին (ծնողին) կամ այլ օրինական ներկայացուցիչներին և այլ շահագրգիռ անձանց, ինչպես նաև տասը տարին լրացած որդեգրվող երեխային:
