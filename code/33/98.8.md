# Հոդված 98⁸. Կասկածյալի կամ մեղադրյալի նկատմամբ խափանման միջոց ընտրելը
Քրեական վարույթն իրականացնող մարմինը օրենքով սահմանված կարգով կասկածյալի կամ մեղադրյալի նկատմամբ ընտրում է խափանման այնպիսի միջոց, որը կբացառի բռնության կամ այլ հանցանքի կատարման հնարավորությունը, ինչի մասին կայացվում է պատճառաբանված որոշում: Որոշման մասին տեղեկացվում է նաև պաշտպանվող անձը:
