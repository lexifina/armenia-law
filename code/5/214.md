# Հոդված 214. Զինապարտի խուսափելը վարժական կամ ստուգողական հավաքներից
Զինապարտի խուսափելը վարժական կամ ստուգողական հավաքներից`
պատժվում է ազատազրկմամբ մինչև մեկ տարի ժամանակով, կամ ուղղիչ աշխատանքներով նույն ժամանակով, կամ տուգանքով մինչև երկու հարյուր դրամ:
Նույն արարքը, որ կատարվել է իրեն որևէ վնասվածք (անդամախեղում) պատճառելու, հիվանդության սիմուլյացիայի, փաստաթղթեր կեղծելու, կամ այլ խաբեության միջոցով, այլև եթե կատարվել է ծանրացուցիչ այլ հանգամանքներում`
