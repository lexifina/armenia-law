# Հոդված 60.9. Ընդերքի օգտագործման հետ կապված՝ շրջակա միջավայրի ոլորտի պետական կառավարման լիազոր մարմնի կողմից անցկացվող տեսչական ստուգումները
(վերնագիրը փոփ. 04.03.20 ՀՕ-112-Ն)
