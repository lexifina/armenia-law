# Հոդված 137. Նոր ընտրություն նշանակելը և անցկացնելը
Համայնքի ղեկավարի կամ ավագանու անդամների ընտրությունները չկայացած ճանաչելու մասին ընտրատարածքային ընտրական հանձնաժողովի որոշումն ընդունելուց կամ դատարանի վճիռն օրինական ուժի մեջ մտնելուց հետո` երեսուներորդ օրը, անցկացվում է նոր ընտրություն: Նոր ընտրությունն անցկացվում է թեկնածուների նոր առաջադրմամբ` արտահերթ ընտրության համար սույն օրենսգրքի 138 հոդվածով սահմանված կարգով: Նոր ընտրություն նշանակում է մարզպետը (Երևանի քաղաքապետը):
