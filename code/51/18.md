# Հոդված 18. Գործատուն
1. Գործատուն աշխատանքային հարաբերության այն մասնակիցն է, որն աշխատանքային պայմանագրի հիման վրա և (կամ) օրենքով սահմանված կարգով օգտագործում է քաղաքացիների աշխատանքը:
2. Գործատու կարող է լինել աշխատանքային իրավունակություն և գործունակություն ունեցող իրավաբանական անձը` անկախ կազմակերպական-իրավական և սեփականության ձևից, գործունեության բնույթից և տեսակից:
