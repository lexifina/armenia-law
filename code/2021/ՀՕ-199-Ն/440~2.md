# Հոդված 440. Կաշառք ստանալու, կաշառքի միջնորդության կամ իրական կամ ենթադրյալ ազդեցությունը շահադիտական, անձնական այլ շահագրգռվածությունից կամ խմբային շահերից ելնելով օգտագործելու պատրվակով գույք, ներառյալ դրամական միջոց, արժեթուղթ, վճարային այլ գործիք, գույքի նկատմամբ իրավունք, ծառայություն կամ որևէ այլ առավելություն ստանալը
