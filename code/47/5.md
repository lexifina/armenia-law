# Հոդված 5. Քրեակատարողական օրենսդրության սկզբունքները
Հայաստանի Հանրապետության քրեակատարողական օրենսդրությունը հիմնվում է մարդասիրության, օրինականության, օրենքի առջև դատապարտյալների հավասարության, պատիժների կատարումը տարբերակելու և անհատականացնելու, պատիժների և ուղղման միջոցների զուգակցման սկզբունքների վրա։
