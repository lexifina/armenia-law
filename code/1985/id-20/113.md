# Հոդված 113. Քաղաքային համայնքի տարածքում կենդանիներ պահելու կարգը, պահանջները, պայմանները, սահմանափակումները և հաշվառման կարգը խախտելը
(վերնագիրը խմբ. 19.12.12 ՀՕ-247-Ն, 25.03.26 ՀՕ-124-Ն, 03.07.26 ՀՕ-406-Ն)
