# Հոդված 148. Գործին մասնակցող անձանց իրավունքները և պարտականությունները պարզաբանելը
1. Անհրաժեշտության դեպքում նախագահողը գործին մասնակցող անձանց և նրանց ներկայացուցիչներին բանավոր պարզաբանում է նրանց դատավարական իրավունքներն ու պարտականությունները:
2. Գործի քննությանը թարգմանչի մասնակցության դեպքում նրան իր իրավունքները և պարտականությունները պարզաբանվում են առաջնահերթության կարգով:
3. Նախագահողը ներկայացուցիչ-փաստաբանին չի պարզաբանում նրա իրավունքները և պարտականությունները:
4. Դատարանը գործին մասնակցող անձանց կարող է գրավոր պարզաբանել իրենց իրավունքները, պարտականությունները և դրանց իրացման կարգը:
