# Հոդված 209. Դատական կարգադրիչների վերապատրաստումը և հատուկ ուսուցումը
1. Դատական կարգադրիչներն անցնում են վերապատրաստում և հատուկ ուսուցում: Վերապատրաստումը և հատուկ ուսուցումն անցկացվում են Դատական դեպարտամենտի ղեկավարի կողմից սահմանված կարգով:
