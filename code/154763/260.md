# Հոդված 260. Առարկայական ընդդատությունը
1. Առաջին ատյանի ընդհանուր իրավասության դատարաններին ընդդատյա են առաջին ատյանի կարգով իրականացվող բոլոր վարույթները:
2. Վերաքննիչ քրեական դատարանին ընդդատյա են բոլոր այն վարույթները, որոնցով առաջին ատյանի դատարանների դատական ակտերի դեմ վերանայման բողոք է բերվել:
