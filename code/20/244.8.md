# Հոդված 244⁸. Տնտեսական մրցակցության պաշտպանության պետական մարմինը
Տնտեսական մրցակցության պաշտպանության պետական մարմինը քննում է սույն օրենսգրքի 171.1-171.11-րդ հոդվածներով նախատեսված գործերը:
Սույն հոդվածի առաջին մասում նշված մարմնի անունից վարչական իրավախախտումների վերաբերյալ գործերը քննելու և վարչական տույժեր նշանակելու իրավունք ունի Մրցակցության պաշտպանության հանձնաժողովը:
(244⁸ - րդ հոդվածը լրաց. 28.06.02 ՀՕ-397-Ն, փոփ. 23.03.18 ՀՕ-250-Ն, 03.03.21 ՀՕ-94-Ն)
(հոդվածը 03.07.25 ՀՕ-210-Ն օրենքի փոփոխության մասով ուժի մեջ է մտնում 2025 թվականի օգոստոսի 1-ից)
