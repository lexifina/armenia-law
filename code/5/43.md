# Հոդված 43. Նախնական կալանքի հաշվակցումը
Դատարանը նախնական կալանքը պատժի ժամանակի մեջ հաշվում է ազատազրկման կամ կարգապահական գումարտակ կամ դաստիրակչական-աշխատանքային պրոֆիլակտորիում ուղարկման դատապարտելիս մեկ օրը մեկ օրվա դիմաց, իսկ ուղղիչ աշխատանքների, աքսորի կամ արտաքսման դատապարտելիս` մեկ օրը երեք օրվա դիմաց:
Պատժի այլ միջոցներ նշանակելիս դատարանը, հաշվի առնելով նախնական կալանքը, կարող է համապատասխանորեն մեղմացնել իր նշանակած պատիժը կամ իսպառ ազատել պատիժը կրելուց:
