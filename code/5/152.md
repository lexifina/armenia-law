# Հոդված 152. Արտադրանքի մատակարարման պլաններն ու առաջադրանքները չկատարելը
Ձեռնարկությունների, տնտեսական կազմակերպությունների, ժողովրդական տնտեսության խորհրդի, նախարարությունների, գերատեսչությունների ղեկավարների և այլ պաշտոնատար անձանց կողմից մյուս տնտեսական վարչական շրջանների կամ միութենական հանրապետությունների, այլև ընդհանուր միութենական կարիքների համար արտադրանքի մատակարարման պլաններն ու առաջադրանքները առանց հարգելի պատճառների բազմիցս չկատարելը`
