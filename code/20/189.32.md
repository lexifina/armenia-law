# Հոդված 189.32. Ուսումնական հաստատությունների կամ կազմակերպությունների կողմից օտարերկրացու հետ կնքված կրթության (ուսումնառության) մասին պայմանագիրը լուծելու կամ կրթությունը (ուսումնառությունը) ընդհատվելու մասին սահմանված կարգով չհայտնելը
1. Ուսումնական հաստատությունների կամ կազմակերպությունների կողմից օտարերկրացու հետ կնքված կրթության (ուսումնառության) մասին պայմանագիրը լուծելու կամ կրթությունը (ուսումնառությունը) ընդհատվելու մասին սահմանված կարգով լուծելու կամ ընդհատելու օրվանից տասնօրյա ժամկետում միգրացիայի և քաղաքացիության բնագավառում պետական կառավարման լիազոր մարմնին չհայտնելը՝
