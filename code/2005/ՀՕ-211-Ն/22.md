# Հոդված 22. Անտառների պաշտպանությունը
1. Անտառի սեփականատերերը, անտառային տնտեսություն վարող անձինք և անտառօգտագործողները պարտավոր են անտառները պաշտպանել վնասակար օրգանիզմների զանգվածային բազմացումներից, ինչպես նաև բնական այլ վնասակար ազդեցություններից:
2. Անտառների պաշտպանությունը վնասակար օրգանիզմներից և հիվանդություններից ներառում է հետևյալ միջոցառումների իրականացումը.
ա) անտառապաթոլոգիական ուսումնասիրություններ.
բ) անտառի վնասատուների ու հիվանդությունների կանխարգելում.
