# Հոդված 199. Անձնագրերն ապօրինի վերցնելը և դրանք գրավ ընդունելը
Պաշտոնատար անձանց կողմից քաղաքացիների անձնագրերն ապօրինի վերցնելը, ինչպես նաև նրանց կողմից անձնագրերը գրավ ընդունելը`
