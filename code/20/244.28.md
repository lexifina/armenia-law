# Հոդված 244.28. Հանրության գերակա շահերի ապահովման նպատակով օտարվող սեփականության ձեռքբերողի կողմից օտարման նպատակի իրագործման ժամկետների խախտման վերաբերյալ գործեր քննող և վարչական տույժ կիրառող մարմինները
1. Սույն օրենսգրքի 152.4-րդ հոդվածով սահմանված վարչական գործերը քննում և վարչական տույժեր է նշանակում «Հանրության գերակա շահերի ապահովման նպատակով սեփականության օտարման մասին» օրենքով սահմանված կարգով ձեռքբերողի հետ պայմանագիր կնքած` համապատասխան ոլորտի պետական կառավարման մարմինը, իսկ եթե պետության անունից պայմանագիրը կնքելու լիազորությունը պատվիրակվել է Երևանի քաղաքապետին, ապա Երևանի քաղաքապետը:
