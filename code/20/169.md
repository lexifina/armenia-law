# Հոդված 169. Ապօրինի ձեռնարկատիրությունը
Առանց պետական գրանցման (բացառությամբ oրենքով նախատեսված դեպքերի) կամ առանց հատուկ թույլտվության (լիցենզիայի) լիցենզավորման ենթակա կամ օրենքով արգելված ձեռնարկատիրական գործունեություն իրականացնելը, եթե անձանց կամ կազմակերպություններին կամ պետությանը հասցված վնասը կազմել է սահմանված նվազագույն աշխատավարձի մինչև հինգհարյուրապատիկը`
առաջացնում է տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի տասնհինգապատիկից երեսնապատիկի չափով:
Սույն հոդվածի համաձայն` պետությանը պատճառված վնասի հաշվարկում ներառվում է նաև պետական գրանցման, ինչպես նաև հատուկ թույլտվության (լիցենզիայի) համար գանձման ենթակա պետական տուրքի գումարի չափը:
(169-րդ հոդվածը փոփ. 11.05.92, 02.09.93 ՀՕ-79, 03.12.96 ՀՕ-102, 23.06.97 ՀՕ-133, 10.10.00 ՀՕ-96, լրաց., փոփ. 26.12.08 ՀՕ-244-Ն, խմբ. 05.10.10 ՀՕ-138-Ն)
