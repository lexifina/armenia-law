# Հոդված 105. Էներգետիկայի բնագավառում և էներգասպառման ոլորտում պետական տեխնիկական վերահսկողություն իրականացնող լիազորված պետական մարմնի տեխնիկական վերահսկողական գործառույթների իրականացմանը խոչընդոտելը կամ թույլ չտալը, ինչպես նաև այդ մարմնի տված կարգադրագրերը չկատարելը
Էներգետիկայի բնագավառում և էներգասպառման ոլորտում պետական տեխնիկական վերահսկողություն իրականացնող լիազորված պետական մարմնի տեխնիկական վերահսկողական գործառույթների իրականացմանը խոչընդոտելը կամ թույլ չտալը, ինչպես նաև այդ մարմնի տված կարգադրագրերը չկատարելը`
