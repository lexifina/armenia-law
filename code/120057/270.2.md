# Հոդված 270.2. Իրազեկված համաձայնություն տալու հնարավորության բացակայության դեպքում 16 տարին լրացած երեխայի կամ օրենքով սահմանված կարգով անգործունակ ճանաչված անձի նկատմամբ հոգեբուժական միջամտություն իրականացնելու վերաբերյալ հոգեբուժական հանձնաժողովի դիմումների քննության կարգը
1. Դատարանը սույն գլխով սահմանված կարգով քննում է նաև «Հոգեբուժական օգնության մասին» Հայաստանի Հանրապետության օրենքի 17-րդ հոդվածի 3-րդ մասով սահմանված դիմումները։
(270.2-րդ հոդվածը լրաց. 18.06.20 ՀՕ-349-Ն)
