# Հոդված 423. Ազատ պահեստների տիրապետողների ռեեստրից հանելու հիմքերը
1. Ազատ պահեստի տիրապետողին ազատ պահեստների տիրապետողների ռեեստրից հանելու հիմքերը հետևյալն են՝
1) ազատ պահեստի տիրապետողի կողմից սույն Օրենսգրքի 424-րդ հոդվածի երկրորդից իններորդ պարբերություններով նախատեսված պարտականությունները չկատարելը.
2) ազատ պահեստի տիրապետողի դիմումը՝ իրեն ազատ պահեստների տիրապետողների ռեեստրից հանելու մասին.
3) ազատ պահեստների տիրապետողների ռեեստրում ընդգրկված իրավաբանական անձի լուծարումը.
