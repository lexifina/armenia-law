# Հոդված 8. Ընտրությունների նախապատրաստման և անցկացման ծախսերը
1. Ընտրությունների նախապատրաստման և անցկացման (ներառյալ` հանձնաժողովների անդամների ուսուցումը, ընտրողների ծանուցումը, ընտրողների ցուցակները կազմելը և վարելը) ծախսերը կատարվում են պետական բյուջեի միջոցների հաշվին:
2. Թեկնածուների նախընտրական քարոզչության ընթացքում ծախսերի կատարման և դրանց փոխհատուցման կարգը սահմանվում է սույն օրենսգրքով:
