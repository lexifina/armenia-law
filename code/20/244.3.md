# Հոդված 244³. Հայաստանի Հանրապետության սոցիալական ապահովագրության պետական հիմնադրամի մարմինները
Սույն օրենսգրքի 169¹, 170⁶ և 182¹ հոդվածներով, 198² հոդվածի երկրորդ և երրորդ մասերով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը` տեղեկություններին և կենսաթոշակներին վերաբերող իրավախախտումների մասով (բացի հարկային տեսչության մարմինների իրավասությանը վերապահված գործերից) քննելու և վարչական տույժեր նշանակելու իրավունք ունեն Հայաստանի Հանրապետության սոցիալական ապահովագրության պետական հիմնադրամի նախագահը, տեղակալները, ինչպես նաև սոցիալական ապահովագրության պետական հիմնադրամի տարածքային մարմինների պետերը (տնօրենները):
