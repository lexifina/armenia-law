# Հոդված 224. Վերցված ապրանքները վերադարձնելու ժամկետը
Անձը, որից սույն օրենսգրքի 212-րդ հոդվածով սահմանված կարգով կամ տուգանքի, մաքսային վճարների գանձումն ապահովելու նպատակով վերցվել են ապրանքներ` անկախ սեփականության պատկանելությունից, կարող է դրանք ստանալ տուգանքի վճարումից, մաքսային վճարների և պարտավորությունների կատարումից հետո` տասնհինգօրյա ժամկետում:
(224-րդ հոդվածը խմբ. 22.12.10 ՀՕ-25-Ն)
