# Հոդված 102. Անօրինական աշխատանքը
1. Անօրինական է համարվում առանց սույն օրենսգրքով սահմանված աշխատանքային պայմանագրի կատարվող աշխատանքը:
2. Կամավոր աշխատանքը և օգնություն ցուցաբերելու նպատակով կատարված աշխատանքը չեն կարող համարվել անօրինական: Այդպիսի աշխատանքների կատարման կարգն ու պայմանները սահմանվում են օրենքով:
3. Անօրինական աշխատանք կատարելու թույլտվություն տված և (կամ) աշխատանքի հարկադրող գործատուները կամ նրանց ներկայացուցիչները պատասխանատվություն են կրում Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով, ինչպես նաև հատուցում են նման աշխատանք կատարողներին այդ աշխատանքի կատարման ընթացքում ոչ աշխատողի մեղքով պատճառված վնասները:
(102-րդ հոդվածը խմբ. 24.06.10 ՀՕ-117-Ն)
