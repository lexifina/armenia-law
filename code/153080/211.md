# Հոդված 211. Քարոզչություն կատարելուն կամ քարոզչություն կատարելուց հրաժարվելուն հարկադրելը կամ քարոզչություն կատարելուն այլ կերպ խոչընդոտելը
1. Նախընտրական կամ հանրաքվեի քարոզչություն կատարելուն կամ քարոզչություն կատարելուց հրաժարվելուն հարկադրելը կամ նախընտրական կամ հանրաքվեի քարոզչություն կատարելուն այլ կերպ խոչընդոտելը՝
պատժվում է տուգանքով` տասնապատիկից երեսնապատիկի չափով, կամ ազատության սահմանափակմամբ՝ առավելագույնը երեք տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ` առավելագույնը երկու ամիս ժամկետով, կամ ազատազրկմամբ` առավելագույնը երեք տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը կատարվել է՝
1) շանտաժով,
2) անձի կամ նրա մերձավոր ազգականի կամ մերձավորի նկատմամբ բռնություն գործադրելու կամ գույք ոչնչացնելու կամ վնասելու սպառնալիքով,
3) իշխանական կամ ծառայողական լիազորությունները կամ դրանցով պայմանավորված ազդեցությունն օգտագործելով,
