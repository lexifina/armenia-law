# Հոդված 222.26. Դիմումի քննությունը
1. Վարչական դատարանը պարտավոր է դիմումն ստանալուց հետո` եռօրյա ժամկետում, ընդունել վարույթ, եթե այն ներկայացվել է սույն օրենսգրքի 222.25-րդ հոդվածով նախատեսված պահանջների պահպանմամբ:
2. Եթե չեն պահպանվել սույն օրենսգրքի 222.25-րդ հոդվածի պահանջները, ապա վարչական դատարանը եռօրյա ժամկետում պատճառաբանված որոշմամբ դիմումը վերադարձնում է` նշելով այն պահանջը, որը չի պահպանվել: Դիմումում առկա ձևական սխալները վերացնելու և որոշումն ստանալու օրվանից հետո` երկու օրվա ընթացքում, այն վարչական դատարան կրկին ներկայացնելու դեպքում դիմումը վարչական դատարան ընդունված է համարվում սկզբնական ներկայացման օրը:
3. Սույն գլխով նախատեսված գործերը վարչական դատարանը քննում է միանձնյա` գրավոր ընթացակարգով` դռնփակ դատական նիստում:
4. Սույն գլխով նախատեսված գործերով դիմումը վարչական դատարանը քննում և գործն ըստ էության լուծող դատական ակտը կայացնում է դիմումը վարույթ ընդունելուց հետո` տասնհինգօրյա ժամկետում:
