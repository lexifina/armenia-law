# Հոդված 169³. Հայաստանի Հանրապետության տնտեսական մրցակցության պաշտպանության պետական հանձնաժողովի կողմից պահանջվող, օրենսդրությամբ սահմանված անհրաժեշտ փաստաթղթեր և այլ տեղեկատվություն չներկայացնելը կամ ոչ հավաստի տեղեկություններ ներկայացնելը
