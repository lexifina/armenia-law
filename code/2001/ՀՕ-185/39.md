# Հոդված 39. ՀՈՂԵՐԻ ՕԳՏԱԳՈՐԾՄԱՆ և ՊԱՀՊԱՆՄԱՆ ՆԿԱՏՄԱՄԲ ՊԵՏԱԿԱՆ ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ ԽՆԴԻՐՆԵՐԸ
