# Հոդված 459. ԱՆՁԻՆ ՀՈԳԵԲՈՒԺԱԿԱՆ կազմակերպությունում ՏԵՂԱՎՈՐԵԼԸ և բուժելը
(վերնագիրը լրաց., փոփ. 18.06.20 ՀՕ-348-Ն)
1. Քրեական օրենքով չթույլատրված արարք կատարած և հասարակության համար վտանգ ներկայացնող անձի անմեղսունակության փաստը հաստատվելու պահից նա կարող է տեղավորվել և բուժվել հոգեբուժական կազմակերպությունում:
2. Հոգեբուժական կազմակերպությունում տեղավորելը և բուժելը թույլատրվում է քննիչի պատճառաբանված որոշմամբ, որը հաստատում է դատարանը:
