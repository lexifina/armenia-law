# Հոդված 191.¹. Միջամտությունը դատական գործերի լուծմանը
Կոնկրետ գործերի բազմակողմանի, լրիվ և օբյեկտիվ քննությանը խոչընդոտելու կամ անօրինական դատավճռի, վճռի կամ որոշման կայացման հասնելու նպատակով դատավորների կամ ժողովրդական ատենակալների վրա ներգրծելը, անկախ դրա եղանակից`
պատժվում է ուղղիչ աշխատանքներով մինչև մեկ տարի ժամանակով կամ տուգանքով երկու հարյուրից մինչև հինգ հարյուր դրամ:
Նույն գործողությունները, որ կատարվել են պաշտոնեական դիրքի օգտագործումով`
պատժվում են ազատազրկմամբ մինչև երկու տարի ժամանակով կամ ուղղիչ աշխատանքներով նույն ժամանակով:
