# Հոդված 45. ԱՆՏԱՌՆԵՐԻ ՊԱՀՊԱՆՈՒԹՅԱՆ ՈՒ ՊԱՇՏՊԱՆՈՒԹՅԱՆ ՆՊԱՏԱԿՆԵՐԸ և ԽՆԴԻՐՆԵՐԸ
