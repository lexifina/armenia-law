# Հոդված 413. Օրինական ներկայացուցչի մասնակցությունն անչափահասին վերագրվող հանցանքի վերաբերյալ վարույթին
1. Անչափահաuին վերագրվող հանցանքի վերաբերյալ վարույթով օրինական ներկայացուցչի մասնակցությունը պարտադիր է:
2. Անչափահաuին վերագրվող հանցանքի վերաբերյալ վարույթն իրականացնող մարմինն օրինական ներկայացուցչի մասնակցությունն ապահովում է անչափահասի ձերբակալման կամ նրան մեղադրանք ներկայացնելու պահից: Վարույթն իրականացնող մարմինն օրինական ներկայացուցչին պարզաբանում է սույն օրենսգրքով սահմանված նրա իրավունքներն ու պարտականությունները:
3.
