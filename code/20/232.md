# Հոդված 232. Պետատոմհսկողության մարմինները
Պետատոմհսկողության մարմինները քննում են սույն օրենսգրքի 97, 97¹, 97⁴, 97⁵, 97⁶ հոդվածներով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը:
Պետատոմհսկողության մարմինների անունից վարչական իրավախախտումների վերաբերյալ գործերը քննելու և վարչական տույժեր նշանակելու իրավունք ունեն`
1/ սույն օրենսգրքի 97, 97¹, 97⁴, 97⁵, 97⁶ հոդվածներով` պետատոմհսկողության մարմնի ղեկավարը.
2/ սույն օրենսգրքի 97, 97¹, 97⁵, 97⁶ հոդվածներով` նաև պետատոմհսկողության տեսչության պետը:
(232-րդ հոդվածը փոփ. 14.06.94 ՀՕ-105, 04.11.96 ՀՕ-85)
