# Հոդված 279. ԴԱՏԱՐԱՆԻ ՈՐՈՇՄԱՄԲ ԿԱՏԱՐՎՈՂ ՔՆՆՉԱԿԱՆ ԳՈՐԾՈՂՈՒԹՅՈՒՆՆԵՐԸ
