# Հոդված 325. Վարչական կալանքի ենթարկված անձանց աշխատանքային օգտագործումը
Սույն օրենսգրքի 53, 172 հոդվածով, 175 հոդվածի երրորդ մասով, 180¹, 182, 206¹ և 206⁴ հոդվածներով նախատեսված իրավախախտումների համար վարչական կալանքի ենթարկված անձինք օգտագործվում են ֆիզիկական աշխատանքներում:
Վարչական կալանքի ենթարկված անձանց աշխատանքային օգտագործման կազմակերպումը դրվում է պատգամավորների տեղական խորհուրդների գործադիր կոմիտեների վրա:
Վարչական կալանքի ենթարկված անձանց կալանքի տակ գտնվելու ժամանակի համար մշտական աշխատանքի վայրում աշխատավարձ չի վճարվում:
