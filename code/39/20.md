# Հոդված 20. ԲՆԱՊԱՀՊԱՆԱԿԱՆ ՀՈՂԵՐԸ
1. Բնապահպանական հողեր են համարվում բնական, գիտական, գեղագիտական, հանգստի նշանակություն ունեցող և հատուկ պահպանության նպատակով նախատեսված բնության հատուկ պահպանվող տարածքների հողերը, ինչպես նաև բուսաբանական այգիների, անտառպարկերի և դենդրոպարկերի հողերը:
2. Բնապահպանական հողերում արգելվում է բնական համալիրների ու օբյեկտների պահպանման և հետազոտման հետ չկապված ու օրենքով չնախատեսված որևէ գործունեություն:
Բնապահպանական հողերի օտարումը դրանց նպատակային և գործառնական նշանակությանը հակասող նպատակների համար արգելվում է:
3. Այն կազմակերպությունները և հիմնարկները, որոնց տրամադրվում են օգտագործման հատուկ պայմաններով հողամասեր, պարտավոր են նշաններ տեղադրել դրանց սահմաններին:
(20-րդ հոդվածը խմբ. 18.06.26 ՀՕ-301-Ն)
