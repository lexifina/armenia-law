## ՊԱՏԳԱՄԱՎՈՐԻ ԹԵԿՆԱԾՈՒՆԵՐԻ ԱՌԱՋԱԴՐՈՒՄԸ ԵՎ ԳՐԱՆՑՈՒՄԸ
# Հոդված 81. Պատգամավորի թեկնածու առաջադրելու իրավունքը
1. Ազգային ժողովի պատգամավորի թեկնածուներ առաջադրելու իրավունք ունեն կուսակցությունները և կուսակցությունների դաշինքները:
Պատգամավորի թեկնածուն կարող է առաջադրվել միայն մեկ կուսակցության ընտրական ցուցակով:
2. Կուսակցությունների դաշինքները կարող են կազմավորվել առնվազն երկու կուսակցության կողմից: Կուսակցությունների դաշինքի դեպքում դաշինքի անվանման ներքո փակագծերում նշվում են դաշինքի անդամ բոլոր կուսակցությունների անվանումները։ Կուսակցությունը կարող է ընդգրկվել միայն մեկ դաշինքի կազմում:
3. Կուսակցությունների դաշինքում ընդգրկված կուսակցությունը չի կարող ինքնուրույն մասնակցել ընտրություններին:
4. Կուսակցությունների դաշինքում ընդգրկվելու որոշումն ընդունվում է կուսակցության մշտական գործող ղեկավար մարմնի որոշմամբ:
(81-րդ հոդվածը լրաց. 07.05.21 ՀՕ-202-Ն, 14.07.22 ՀՕ-311-Ն, փոփ. 05.12.24 ՀՕ-505-Ն)
(07.05.21 ՀՕ-202-Ն օրենքն ունի եզրափակիչ մաս և անցումային դրույթներ)
(14.07.22 ՀՕ-311-Ն օրենքն ունի անցումային դրույթ)
(05.12.24 ՀՕ-505-Ն օրենքն ունի անցումային դրույթ)
