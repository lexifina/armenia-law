# Հոդված 204²⁴. Բողոքի բովանդակությունը
Նոր հանգամանքներով դատական ակտը վերանայելու բողոքը պետք է պարունակի`
1) այն դատարանի անվանումը, որին բողոքը հասցեագրվում է.
2) վերանայման ենթակա դատական ակտի կայացման տարին, ամիսը, ամսաթիվը.
3) դատական ակտի վերանայման համար հիմք դարձած նոր հանգամանքի շարադրանքը.
4) բողոքով ներկայացվող պահանջը` ըստ համապատասխան նոր հանգամանքի.
5) բողոք ներկայացրած անձի անունը, ազգանունը (անվանումը).
