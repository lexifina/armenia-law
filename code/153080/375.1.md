# Հոդված 375.1. Լուծարված հորատանցքերը վերաբացելը կամ առանց ջրօգտագործման թույլտվության ստորերկրյա ջրային ռեսուրսներից ջրօգտագործում իրականացնելը կամ առանց ջրօգտագործման թույլտվության ջրօգտագործման նպատակով հորատանցք հորատելը կամ առանց ջրօգտագործման թույլտվության կոնսերվացված հորատանցքերը վերաբացելը
(հոդվածը 20.03.24 ՀՕ-131-Ն օրենքի լրացման մասով ուժի մեջ է մտնում 2024 թվականի հուլիսի 1-ից)
