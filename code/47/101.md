# Հոդված 101. Պատիժը կատարելու համար ուղղիչ հիմնարկի տեսակը փոխելը
Պատիժը կատարելու համար ուղղիչ հիմնարկի տեսակը փոխում է սույն օրենսգրքի 100-րդ հոդվածով նախատեսված տեղաբաշխման հանձնաժողովը՝ հաշվի առնելով որոշակի ժամկետով կամ ցմահ ազատազրկման դատապարտված անձի դրսևորած վարքագիծը, մեկուսացվածության աստիճանի նպատակահարմարությունը և սույն օրենսգրքի 68-րդ հոդվածի պահանջները:
(101-րդ հոդվածը փոփ. 08.07.05 ՀՕ-161-Ն)
