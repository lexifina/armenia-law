# Հոդված 154.10. Ազգային ժողովի ընտրությունների ժամանակ օրենքով սահմանված՝ նախընտրական քարոզչության ծախսերը նախընտրական հիմնադրամից կամ հանրաքվեի քարոզչության ծախսերը հանրաքվեի քարոզչության ֆինանսավորման հիմնադրամից չկատարելը կամ հայտարարագրման ենթակա տվյալները չհայտարարագրելը կամ հայտարարագիր չներկայացնելը
(հոդվածը 07.05.21 ՀՕ-204-Ն օրենքի լրացմամբ ուժի մեջ կմտնի 01.01.22 թվականին)
