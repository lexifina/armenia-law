# Հոդված 50. Պետական և համայնքային անտառների կամ անտառային հողերի վարձակալության ժամկետը և վարձավճարը
1. Անտառների կամ անտառային հողերի վարձակալության պայմանագիրը կնքվում է մինչև 60 տարի ժամկետով: Անտառային հողերի գյուղատնտեսական նպատակների համար նախատեսված հողատեսքերի վարձակալության պայմանագիրը կնքվում է Հայաստանի Հանրապետության հողային օրենսգրքով սահմանված ժամկետներով։
