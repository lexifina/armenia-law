# Հոդված 81. Կառույցներ և այլ օբյեկտներ շահագործման հանձնելն առանց մթնոլորտային օդի պահպանության պահանջները կատարելու
Մթնոլորտային օդի պահպանության պահանջները չբավարարող կառույցներ և այլ օբյեկտներ կառուցելը և շահագործելը`
