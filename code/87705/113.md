# Հոդված 113. Դատական վիճաբանությունները
1. Ապացույցների հետազոտման ավարտից հետո դատավարության մասնակիցներն իրավունք ունեն հանդես գալու ամփոփիչ ճառերով (դատական վիճաբանություններ)։
2. Սկզբում հանդես է գալիս հայցվորը, ապա՝ պատասխանողը, այնուհետև՝ երրորդ անձը:
3. Վարչական դատարանը կարող է ի սկզբանե սահմանել դատական վիճաբանությունների առավելագույն` դատավարության յուրաքանչյուր մասնակցի համար հավասար տևողություն։
