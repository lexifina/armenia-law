# Հոդված 58. Դատապարտյալի նկատմամբ կիրառվող խրախուսանքի միջոցները
Դատապարտյալի նկատմամբ պատիժը կատարող հիմնարկի պետը սահմանված կարգով կարող է կիրառել խրախուսանքի հետևյալ միջոցները.
1) զբոսանքի ժամանակի մեկ ժամով ավելացում՝ մինչև մեկ ամիս ժամկետով.
2) հեռախոսակապից մեկանգամյա կամ մինչև մեկ ամիս ժամկետով օգտվելու թույլտվություն.
