# Հոդված 71. Անտառներում և պետական անտառային ֆոնդի ոչ անտառապատ հողերում ինքնակամ խոտհունձ կատարելն ու անասուններ արածեցնելը և (կամ) դրանց կանոնները խախտելը
Անտառներում և պետական անտառային ֆոնդի ոչ անտառապատ հողերում ինքնակամ խոտհունձ կատարելն ու անասուններ արածեցնելը և (կամ) դրանց կանոնները խախտելը`
