# Հոդված 261. Սոցիալական ապահովագրության միջոցները
Բանվորների ու ծառայողների պետական սոցիալական ապահովագրությունն իրականացվում է պետության հաշվին:
Սոցիալական ապահովագրության համար կատարվող մուծումները վճարվում են ձեռնարկությունների, հիմնարկների, կազմակերպությունների կողմից` առանց բանվորների ու ծառայողների աշխատավարձից որևէ պահում կատարելու: Ձեռնարկությունների, հիմնարկների, կազմակերպություների կողմից ապահովագրական մուծում չկատարելը բանվորներին ու ծառայողներին չի զրկում պետական սոցիալական ապահովագրության գծով ապահովության իրավունքից:
