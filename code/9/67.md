# Հոդված 67. ԼԻԱԶՈՐԱԳՐԻ ԺԱՄԿԵՏԸ
Լիազորագրի գործողության ժամկետը չի կարող երեք տարուց ավելի լինել: եթե լիազորագրում ժամկետ չի նշված, ապա այն պահպանում է ուժը կնքման օրվանից մեկ տարվա ընթացքում:
Այն լիազորագիրը, որում չի նշված նրա կնքման տարին ու ամսաթիվը, անվավեր է: արտասահմանում գործողություններ կատարելու համար նախատեսված` պետական նոտարի կողմից հաստատված լիազորագիրը, որը ցուցումներ չի պարունակում նրա գործողության ժամկետի մասին, ուժը պահպանում է մինչև լիազորագիր տվող անձի կողմից նրա վերացումը:
(26.11.75. խմբագրությամբ)
