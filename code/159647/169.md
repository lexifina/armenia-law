# Հոդված 169. Վերամշակման արդյունքների ելքի չափաքանակները
1. «Վերամշակման արդյունքների ելքի չափաքանակ» ասելով ենթադրվում են Միության մաքսային տարածքում օտարերկրյա ապրանքների որոշակի քանակի վերամշակման գործողությունների կատարման արդյունքում գոյացած՝ վերամշակման արդյունքների քանակը և (կամ) տոկոսային պարունակությունը:
2.
