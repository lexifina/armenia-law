# Հոդված 111. Դատական ծախսերի հատուցումը երրորդ անձանց կողմից
1. Վեճի առարկայի նկատմամբ ինքնուրույն պահանջներ ներկայացնող երրորդ անձանց վրա տարածվում են սույն գլխով սահմանված` հայցվորներին վերաբերող դրույթները:
2. Վեճի առարկայի նկատմամբ ինքնուրույն պահանջներ չներկայացնող երրորդ անձը դատական ծախսերի փոխհատուցման պարտականություն կրում է միայն այն դեպքում, երբ իր գործողությունների հետևանքով առաջացել են դատական ծախսեր, և եթե դատական ակտը կայացվել է ի վնաս այն կողմի, որի կողմից հանդես է գալիս վեճի առարկայի նկատմամբ ինքնուրույն պահանջներ չներկայացնող երրորդ անձը։
