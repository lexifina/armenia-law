# Հոդված 53. Գույքի մանր հափշտակումը
1. Գույքի մանր չափերով հափշտակությունը՝ գողության, յուրացման, վատնման, պաշտոնեական դիրքի չարաշահման կամ խարդախության միջոցով`
առաջացնում է տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի հիսնապատիկից հարյուրապատիկի չափով:
2. Սույն հոդվածով նախատեսված մանր չափերով հափշտակություն է`
- գողության միջոցով իրավախախտումը կատարելու պահին Հայաստանի Հանրապետությունում սահմանված նվազագույն աշխատավարձի հնգապատիկը չգերազանցող գումարը (արժեքը).
- յուրացման, վատնման, պաշտոնեական դիրքի չարաշահման կամ խարդախության եղանակով իրավախախտումը կատարելու պահին Հայաստանի Հանրապետությունում սահմանված նվազագույն աշխատավարձի երեսնապատիկը չգերազանցող գումարը (արժեքը):
(53-րդ հոդվածը խմբ. 07.03.01 ՀՕ-156)
