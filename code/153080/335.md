# Հոդված 335. Հրազենի, դրա հիմնական բաղկացուցիչ մասերի, ռազմամթերքի և այլ նյութերի, սարքերի, առարկաների ապօրինի շրջանառությունը

պատժվում է ազատազրկմամբ՝ երեքից վեց տարի ժամկետով:
