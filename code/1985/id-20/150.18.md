# Հոդված 150.18. Գովազդային վիճակախաղի կազմակերպման և իրականացման գործընթացը «Իրավաբանական անձանց պետական գրանցման, իրավաբանական անձանց առանձնացված ստորաբաժանումների, հիմնարկների և անհատ ձեռնարկատերերի պետական հաշվառման մասին» օրենքով սահմանված կարգով պետական գրանցում կամ պետական հաշվառում չստացած անձանց պատվիրելը
(հոդվածը 03.07.26 ՀՕ-353-Ն օրենքի լրացման մասով ուժի մեջ է մտնում «Խաղային գործունեության կարգավորման մասին» օրենքը գործողության մեջ դրվելու օրվանից)
