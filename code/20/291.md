# Հոդված 291. Վարչական իրավախախտման վերաբերյալ գործի որոշման դեմ գանգատի և բողոքի քննության ժամկետը
Վարչական իրավախախտման վերաբերյալ գործի որոշման դեմ գանգատը և բողոքը քննվում են դրա համար իրավազոր մարմինների (պաշտոնատար անձանց) կողմից, դրանց ստացման օրվանից երեսնօրյա ժամկետում, եթե օրենքով այլ բան սահմանված չէ:
