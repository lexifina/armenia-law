# Հոդված 11. Դատապարտյալի իրավական վիճակը

3. Դատապարտյալը քաղաքացիական պարտականությունների կատարումից կարող է ազատվել միայն օրենքով նախատեսված դեպքերում։
4. Դատապարտյալի իրավունքները, ազատությունները և պարտականություններն իրականացնելու կարգը սահմանվում է սույն օրենսգրքով, ինչպես նաև ուղղիչ հիմնարկների ներքին կանոնակարգով։ Դատապարտյալը իր իրավունքները, ազատությունները և պարտականություններն իրականացնելիս չպետք է խախտի պատիժը կրելու կարգն ու պայմանները, ինչպես նաև ոտնահարի այլ անձանց իրավունքները կամ օրինական շահերը։
