# Հոդված 57. Կալանքը
1. Կալանքը ուղղիչ հիմնարկում անազատության մեջ պահելու ձևով հասարակությունից խիստ մեկուսացման պայմաններում դատապարտյալին պահելն է: Կալանքը դատարանը նշանակում է տասնհինգ օրից մինչև երեք ամիս ժամկետով և միայն այն դեպքում, երբ կալանավորումը որպես խափանման միջոց չի ընտրվել:
2. Կալանքը չի նշանակվում դատավճիռը կայացնելու պահին տասնվեց տարին չլրացած անձանց կամ հղի կանանց կամ խնամքին մինչև ութ տարեկան երեխա ունեցող անձանց նկատմամբ:
3. Զինծառայողները կալանքը կրում են զինվորական կալանատանը:
