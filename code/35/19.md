# Հոդված 19. Նախընտրական քարոզչության իրավունքի չարաշահման անթույլատրելիությունը
Նախընտրական քարոզչության ընթացքում արգելվում են սահմանադրական կարգը բռնի տապալելու, բռնության կամ պատերազմի քարոզումը, ազգային, ռասայական, կրոնական ատելության բորբոքումը, ինչպես նաև ռասայական, ազգային կամ կրոնական ատելություն առաջացնող նյութերի հրապարակումն ու տարածումը:
