# Հոդված 55.3. Կենտրոնական ընտրական հանձնաժողովի կողմից ստեղծվող աշխատանքային խմբերը
1. Ընտրությունների ժամանակահատվածում (մինչև ընտրությունների արդյունքների բողոքարկման վերաբերյալ վերջնական դատական ակտն ուժի մեջ մտնելը) ընտրությունների վերաբերյալ լրացուցիչ տեղեկություններ հավաքելու, առկա տեղեկությունների հավաստիությունը պարզելու, դրանց վերաբերյալ պարզաբանումներ կամ տեղեկություններ տրամադրելու, տեղեկությունները համակարգելու և Կենտրոնական ընտրական հանձնաժողով ներկայացնելու, ինչպես նաև թվարկված գործառույթներից բխող առանձին այլ գործառույթներ կատարելու և խնդիրներ լուծելու նպատակով Կենտրոնական ընտրական հանձնաժողովում կարող են ստեղծվել աշխատանքային խմբեր Կենտրոնական ընտրական հանձնաժողովի որոշմամբ։
2. Ստեղծվող աշխատանքային խմբերի կազմը, գործառույթներն ու խնդիրները հաստատում է Կենտրոնական ընտրական հանձնաժողովը։
