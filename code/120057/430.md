# Հոդված 430. Հայաստանի Հանրապետության դատարանների բացառիկ ընդդատությունը օտարերկրյա անձանց մասնակցությամբ գործերով
1. Բացառապես Հայաստանի Հանրապետության դատարաններին են ընդդատյա`
1) Հայաստանի Հանրապետության տարածքում գտնվող անշարժ գույքի նկատմամբ իրավունքների վերաբերյալ գործերը.
2) Հայաստանի Հանրապետության քաղաքացիների որդեգրման վերաբերյալ գործերը.
3) Փոխադրման պայմանագրից ծագած վեճերի վերաբերյալ գործերը, եթե փոխադրողները գտնվում են Հայաստանի Հանրապետության տարածքում,
4) Հայաստանի Հանրապետության քաղաքացիների և օտարերկրյա քաղաքացիների կամ քաղաքացիություն չունեցող անձանց ամուսնալուծության վերաբերյալ գործերը, եթե երկու ամուսիններն էլ բնակվում են Հայաստանի Հանրապետությունում:
