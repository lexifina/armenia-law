# Հոդված 159. Վաճառելու նպատակով տնային եղանակով թունդ ոգելից խմիչքներ պատրաստելը, դրանց վաճառելը, ինչպես նաև կեղծած գինի ու կեղծած կոնյակ պատրաստելը
Ինքնաթոր օղի, ճաճա, արակա, թթի օղի, բրագա կամ տնային եղանակով այլ թունդ ոգելից խմիչքներ պատրաստելը կամ պահելը ոչ վաճառելու նպատակով, դրանց արտադրության համար ապարատներ պատրաստելը կամ պահելը ոչ վաճառելու նպատակով, որ կատարվել է վարչական տույժ նշանակելուց հետո կրկին անգամ մեկ տարվա ընթացքում`
պատժվում է ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով կամ տուգանքով` երկու հարյուրից մինչև հինգ հարյուր դրամ:
Ինքնաթոր օղի, ճաճա, արակա, թթի օղի, բրագա կամ տնային եղանակով այլ թունդ ոգելից խմիչքներ պատրաստելը կամ պահելը ոչ վաճառելու նպատակով, դրանց արտադրության համար ապարատներ պատրաստելը կամ պահելը ոչ վաճառելու նպատակով, որ կատարվել է սույն հոդվածով նախատեսված հանցագործությունների համար նախկինում դատապարտված անձի կողմից`
պատժվում է ազատազրկմամբ մինչև երկու տարի ժամանակով կամ ուղղիչ աշխատանքներով մեկից մինչև երկու տարի ժամանակով:
Ինքնաթոր օղի, ճաճա, արակա, թթի օղի, բրագա կամ տնային եղանակով այլ թունդ ոգելից խմիչքներ պատրաստելը կամ պահելը վաճառելու նպատակով, կամ էլ դրանց արտադրության համար ապարատներ պատրաստելը կամ պահելը վաճառելու նպատակով, ինչպես նաև այդ ոգելից խմիչքների կամ ապարատների վաճառքը`
պատժվում են ազատազրկմամբ մեկից մինչև երեք տարի ժամանակով` գույքի բռնագրավմամբ կամ առանց դրա, կամ էլ ուղղիչ աշխատանքներով մինչև երկու տարի ժամանակով` գույքի բռնագրավմամբ կամ առանց դրա, կամ էլ տուգանքով` հինգ հարյուրից մինչև հազար դրամ:
Սույն հոդվածի երրորդ մասով նախատեսված գործողությունները, որոնք կատարվել են կրկին անգամ` պատժվում են ազատազրկմամբ երեքից մինչև հինգ տարի ժամանակով` գույքի բռնագրավմամբ:
(05.12.85, 30.09.87 խմբագրությամբ)
