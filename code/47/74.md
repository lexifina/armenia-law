# Հոդված 74. Դատապարտյալի անձնական հիգիենան
1. Դատապարտյալը պետք է ապահովված լինի իր հիգիենայի պահանջները բավարարելու համար մարդկային արժանապատվությունը չնվաստացնող պայմաններով:
2. Դատապարտյալի անձնական հիգիենայի պահպանման պայմանները և կանոնները սահմանվում են ուղղիչ հիմնարկների ներքին կանոնակարգով և իրավական այլ ակտերով:
3. Դատապարտյալի անձնական հիգիենայի պահպանման համար անհրաժեշտ հիգիենայի պարագաների չափաբաժինները սահմանում է Հայաստանի Հանրապետության կառավարությունը:
