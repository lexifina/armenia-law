# Հոդված 122. Արագացված դատաքննություն կիրառելու մասին դատական ակտի վերացումը
1. Եթե գործն ըստ էության լուծող դատական ակտ կայացնելիս ի հայտ են գալիս հանգամանքներ, որոնք պարզելու համար անհրաժեշտ է գործի քննությունն անցկացնել բանավոր ընթացակարգով, ապա դատարանը որոշում է կայացնում գործի քննությունը վերսկսելու մասին` այդ որոշումը եռօրյա ժամկետում ուղարկելով դատավարության մասնակիցներին։
