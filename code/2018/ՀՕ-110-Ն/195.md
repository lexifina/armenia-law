# Հոդված 195. Վճռի կատարման ապահովումը
1. Առաջին ատյանի դատարանը գործին մասնակցող անձի միջնորդությամբ վճռի կայացումից հետո մինչև վճռի օրինական ուժի մեջ մտնելը կիրառում է վճռի կատարման ապահովման միջոցներ:
2. Վճռի կատարման ապահովման միջոց կիրառելու վերաբերյալ միջնորդությունը քննվում է անհապաղ, առանց դատական նիստ հրավիրելու:
3. Վճռի կատարման ապահովման միջոցների նկատմամբ կիրառվում են սույն օրենսգրքի 13-րդ գլխի կանոնները:
