# Հոդված 3. Քրեական դատավարության օրենսգրքի գործողությունը տարածության վրա
1. Հայաստանի Հանրապետության տարածքում, անկախ հանցանքի կատարման վայրից, քրեական վարույթն իրականացվում է սույն օրենսգրքի դրույթներին համապատասխան, եթե Հայաստանի Հանրապետության միջազգային պայմանագրերով այլ բան նախատեսված չէ:
2. Հայաստանի Հանրապետության սահմաններից դուրս՝ Հայաստանի Հանրապետության դրոշի տակ օրինական կարգով գտնվող կամ Հայաստանի Հանրապետության տարբերանշանը կրող, Հայաստանի Հանրապետության օդանավակայանում կամ նավահանգստում գրանցված օդային, ծովային կամ գետային նավի վրա կատարված ենթադրյալ հանցանքների վերաբերյալ վարույթն իրականացվում է սույն օրենսգրքի նորմերով:
3. Հայաստանի Հանրապետության միջազգային պայմանագրերով նախատեսված դեպքերում սույն օրենսգրքի դրույթները կիրառվում են նաև օտարերկրյա պետությունների տարածքում:
