# Հոդված 45. Վերաքննիչ դատարանին ընդդատյա գործերը
(Վերնագիրը փոփ. 05.02.09 ՀՕ-45-Ն)
Քրեական վերաքննիչ դատարանին ընդդատյա են առաջին ատյանի դատարանների՝ օրինական ուժի մեջ չմտած, իսկ քրեադատավարական օրենսդրությամբ նախատեսված բացառիկ դեպքերում՝ օրինական ուժի մեջ մտած դատական ակտերին վերաբերող գործերը:
(45-րդ հոդվածը փոփ. 21.02.07 ՀՕ-93-Ն, խմբ. 28.11.07 ՀՕ-270-Ն, փոփ. 05.02.09 ՀՕ-45-Ն)
