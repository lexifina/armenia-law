# Հոդված 441. Իրավաբանական անձի իրավունքները և պարտականությունները
1. Վարույթի ընթացքում իրավաբանական անձն օժտված է մեղադրյալի՝ սույն օրենսգրքի 43-րդ հոդվածով նախատեսված իրավունքներով և կրում է նույն հոդվածով նախատեսված պարտականություններն այնքանով, որքանով դրանք վերագրելի կարող են լինել իրավաբանական անձին։
