# Հոդված 171.4. Արգելված համակենտրոնացումը գործողության մեջ դնելը
Տնտեսավարող սուբյեկտի կողմից Մրցակցության պաշտպանության հանձնաժողովի որոշմամբ արգելված համակենտրոնացումը գործողության մեջ դնելը տնտեսավարող սուբյեկտի պաշտոնատար անձի համար`
առաջացնում է նախազգուշացում կամ տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի երեքհազարապատիկից մինչև հինգհազարապատիկի չափով:
2. Համակենտրոնացման մասնակից ֆիզիկական անձի կողմից Մրցակցության պաշտպանության հանձնաժողովի որոշմամբ արգելված համակենտրոնացումը գործողության մեջ դնելը ֆիզիկական անձի համար`
