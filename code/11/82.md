# Հոդված 82. պետական տուրքի չափը
դատարաններին տրվող հայցադիմումներից, հատուկ վարույթի գործերով դիմումներից (գանգատներից), դատարանների վճիռների դեմ տրվող վճռաբեկ գանգատներից, ինչպես նաև դատարանների կողմից կրկնակի անգամ փաստաթղթերի պատճեններ տալու համար, պետական տուրքը գանձվում է հետևյալ չափերով.
1) հայցադիմումներից, այդ թվում պետական, կոոպերատիվ և այլ հասարակական ձեռնարկությունների, կազմակերպությունների և հիմնարկների հետ կոլտնտեսությունների և միջկոլտնտեսային կազմակերպությունների վեճերի, ինչպես նաև միմյանց միջև վեճերի վերաբերյալ հայցադիմումներից, երբ հայցագինը կազմում է.
ա) մինչև հարյուր դրամ` հինգ դրամ.
բ) հարյուր դրամից բարձր մինչև հինգ հարյուր դրամ` հայցագնի վեց տոկոսը.
գ) հինգ հարյուր դրամից բարձր մինչև հազար դրամ` հայցագնի ութ տոկոսը.
2) քաղաքացիների իրավունքները ոտնահարող պետական կառավարման մարմինների և պաշտոնատար անձանց ապօրինի գործողությունների դեմ գանգատներից` տասը դրամ.
3) ամուսնալուծության վերաբերյալ հայցադիմումներից` երեսուն դրամ.
4) կրկնական ամուսնալուծության վերաբերյալ հայցադիմումներից` հիսուն դրամ.
5) ամուսնալուծության դեպքում գույքի բաժանման վերաբերյալ հայցադիմումներից տուրքը որոշվում է ըստ հայցագնի` սույն հոդվածի 1-ին կետի <ա designtimesp=30233>, <բ designtimesp=30234>, <գ designtimesp=30235>, <դ designtimesp=30236> ենթակետերի համապատասխան.
6) այն անձանց հետ ամուսնալուծության հայցադիմումներից, որոնք սահմանված կարգով ճանաչվել են անհայտ բացակայող կամ հոգեկան հիվանդության կամ տկարամտության հետևանքով անգործունակ, կամ այն անձանց հետ, ովքեր դատապարտվել են առնվազն երեք տարվա ազատազրկման` հինգ դրամ.
7) բնակելի շենքերի վարձակալության պայմանագրի փոփոխման կամ լուծման, ժառանգության ընդունման ժամկետի երկարացման, գույքը արգելանքից ազատելու հայցադիմումներից և ոչ գույքային բնույթի (կամ գնահատման ոչ ենթակա) այլ հայցադիմումներից` տասը դրամ.
8) հատուկ վարույթի գործերի դիմումներից (գանգատներից)` տասը դրամ.
9) պետական, կոոպերատիվ և այլ հասարակական ձեռնարկությունների հետ կոլտնտեսությունների և միջկոլտնտեսային կազմակերպությունների նախապայմանագրային վեճերի, ինչպես նաև միմյանց միջև նախապայմանագրային վեճերի վերաբերյալ հայցադիմումներից` քսանհինգ դրամ.
10) դատարանների վճիռների դեմ վճռաբեկ գանգատներից` հայցադիմում (հատուկ վարույթի գործերով դիմում) տալու դեպքում վճարման ենթակա դրույքի հիսուն տոկոսը, իսկ գույքային վեճերի դեպքում` այն դրույքով, որը հաշվարկվում է ելնելով վիճարկվող գումարից:
դատարանի որոշումների դեմ մասնավոր գանգատների համար պետական տուրք չի վճարվում.
11) դատարանի վճռի, դատավճռի, որոշումների և դատարանի այլ որոշումների պատճենը կրկին անգամ տալու համար` երեք դրամ և, բացի այդ, յուրաքանչյուր պատրաստված էջի համար` վաթսուն լումա:
(10.03.90 խմբագրությամբ)
