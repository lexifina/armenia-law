# Հոդված 118. Գրավոր դատաքննություն կիրառելու մասին որոշման վերացումը
1. Եթե գրավոր ընթացակարգով քննելու համար գործը նախապատրաստելիս ի հայտ են գալիս հանգամանքներ, որոնք պարզելու համար անհրաժեշտ է գործի քննությունն անցկացնել բանավոր ընթացակարգով, ապա վարչական դատարանը որոշում է կայացնում գործը բանավոր ընթացակարգով քննելու վերաբերյալ` այդ որոշումը եռօրյա ժամկետում ուղարկելով դատավարության մասնակիցներին։
