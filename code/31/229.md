# Հոդված 229. Վճռաբեկ բողոք բերելու ժամկետները
Վճռաբեկ բողոքը կարող է բերվել uտորադաu դատարանի` գործն ըuտ էության լուծող դատական ակտն oրինական ուժի մեջ մտնելու պահից եռամuյա ժամկետում: Վերաքննիչ դատարանի միջանկյալ դատական ակտի, ինչպես նաև միջանկյալ ակտի դեմ բերված վերաքննիչ բողոքի հիման վրա վերաքննիչ դատարանի որոշման դեմ բողոք կարող է ներկայացվել որոշումն ստանալու պահից եռօրյա ժամկետում:
