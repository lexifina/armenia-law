# Հոդված 2. Հայաստանի Հանրապետության դատարանները

1) ընդհանուր իրավասության դատարանները.

1) վարչական դատարանը.
2) սնանկության դատարանը:

1) վերաքննիչ քրեական դատարանը.
2) վերաքննիչ քաղաքացիական դատարանը.
