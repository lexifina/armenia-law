# Հոդված 79. Միջազգային թռիչքների կանոնները խախտելը
Առանց սահմանված թուլատվության ՀՀ թռչելը և ՀՀ-ից դուրս թռչելը, թույլատվության մեջ մատնանշված երթուղիները, վայրէջքի տեղերը, օդային դարպասները, թռիչքների բարձրությունը չպահպանելը կամ միջազգային թռիչքների կանոնների այլ խախտումը`
