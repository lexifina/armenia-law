# Հոդված 242. դատարանի վճիռը դիմումի վերաբերյալ
դատարանը, պարզելով, որ ապառքը բռնագանձելու վերաբերյալ պահանջը օրինական է, դատարանին ներկայացված վերգրման վերաբերյալ ակտի համաձայն վճիռ է կայացնում ապառքատիրոջից գույքը վերցնելու մասին, իսկ գույք չլինելու դեպքում` բռնագանձումը ապառքատիրոջը ուրիշ անձերից հասանելիք դրամական գումարների վրա տարածելու մասին:
եթե գույքի վերագրման վերաբերյալ ակտի մեջ մտցված է այնպիսի գույք, որի վրա ըստ օրենքի չի կարող բռնագանձում տարածվել, դատարանը վերացնում է այդ գույքի վրա դրված արգելանքը:
եթե դատարանը պարզի, որ ապառքը բռնագանձելու վերաբերյալ պահանջը ապօրինի է, մերժում է հայտարարված պահանջը:
(26.08.81. խմբագրությամբ)
