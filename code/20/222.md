# Հոդված 222. Հարբեցողության դեմ պայքարի հանձնաժողովները
Պատգամավորների շրջանային, քաղաքային և քաղաքների շրջանային խորհուրդների գործադիր կոմիտեներին առընթեր հարբեցողության դեմ պայքարի հանձնաժողովները քննում են սույն օրենսգրքի 159 հոդվածով նախատեսված վարչական իրավախախտումների վերաբերյալ գործերը:
(222-րդ հոդվածը փոփ. 10.10.00 ՀՕ-96)
