# Հոդված 2. Վարչական դատավարության մասին օրենսդրությունը
1. Վարչական դատավարության կարգը սահմանվում է սույն օրենսգրքով և Հայաստանի Հանրապետության դատական օրենսգրքով, իսկ սույն օրենսգրքով նախատեսված դեպքերում` նաև Հայաստանի Հանրապետության քաղաքացիական դատավարության օրենսգրքով։
2. Վարչական դատավարությունն իրականացվում է գործի քննության ժամանակ գործող օրենքով։
