# Հոդված 41. Տեսչական մարմնի իրավասությունները հողերի օգտագործման և պահպանման նկատմամբ վերահսկողություն իրականացնելիս
(վերնագիրը խմբ. 09.07.20 ՀՕ-365-Ն)
1. Տեսչական մարմինը վերահսկողություն է իրականացնում`
1) հողային ֆոնդի նպատակային օգտագործման նկատմամբ.
2) հողային օրենսդրության պահանջների պահպանման նկատմամբ.
3) տարածքային կառավարման և տեղական ինքնակառավարման մարմինների` հողային հարաբերությունների բնագավառում իրականացվող գործունեության նկատմամբ.
4) նոր հողերի յուրացման նկատմամբ:
2. Տեսչական մարմնի ղեկավարն օրենքով սահմանված դեպքերում ու կարգով կարող է տալ պարտադիր կատարման ցուցումներ, նշանակել վարչական տույժեր, ինչպես նաև հաղորդումներ ներկայացնել իրավասու մարմիններ` հողային օրենսդրության պահանջները խախտողներին օրենքով նախատեսված պատասխանատվության ենթարկելու վերաբերյալ:
(41-րդ հոդվածը խմբ., փոփ., լրաց. 09.07.20 ՀՕ-365-Ն)
