# Հոդված 26. Տուգանք
Վարչական իրավախախտումների համար քաղաքացիների նկատմամբ նշանակվող տուգանքը, որպես կանոն, չի կարող գերազանցել սահմանված նվազագույն աշխատավարձի վեցապատիկը, իսկ պաշտոնատար անձանց նկատմամբ` տասնապատիկը, եթե վարչական իրավախախտումների առանձին տեսակների համար պատասխանատվությունն ուժեղացնելու կապակցությամբ այլ բան չի նախատեսվում: Վարչական իրավախախտումների համար քաղաքացիների և պաշտոնատար անձանց նկատմամբ նշանակվող տուգանքը չի կարող պակաս լինել սահմանված նվազագույն աշխատավարձի երեք տոկոսից:
(11.05.92, 18.08.93 խմբագրությամբ)
