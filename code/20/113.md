# Հոդված 113. Շներ և կատուներ պահելու կանոնները խախտելը
Քաղաքներում և այլ բնակավայրերում շներ ու կատուներ պահելու կանոնները խախտելը`
առաջացնում է նախազգուշացում կամ տուգանքի նշանակում քաղաքացիների նկատմամբ` սահմանված նվազագույն աշխատավարձի մինչև հինգ տոկոսի չափով և նախազգուշացում կամ տուգանքի նշանակում պաշտոնատար անձանց նկատմամբ` սահմանված նվազագույն աշխատավարձի մինչև տասը տոկոսի չափով:
Նույն խախտումները, որոնց հետևանքով վնաս է պատճառվել քաղաքացիների առողջությանը կամ գույքին`
առաջացնում են տուգանքի նշանակում քաղաքացիների նկատմամբ` սահմանված նվազագույն աշխատավարձի մինչև քսան տոկոսի և պաշտոնատար անձանց նկատմամբ` քսան տոկոսից մինչև երեսունհինգ տոկոսի չափով:
(113-րդ հոդվածը խմբ. 02.09.93 ՀՕ-79)
