# Հոդված 1123. Ստեղծագործությունը հրապարակելու իրավունքը
1. Հեղինակին է պատկանում անձանց անորոշ շրջանակին իր ստեղծագործությունը մատուցելու իրավունքը (հրապարակելու իրավունքը):
2. Ստեղծագործությունը համարվում է հրապարակված, եթե հեղինակի կողմից կամ նրա համաձայնությամբ ստեղծագործությունն առաջին անգամ մատուցվում է անձանց անորոշ շրջանակի` այն հրատարակելու, հրապարակայնորեն կատարելու, ցուցադրելու, լույս ընծայելու կամ այլ կերպ հրապարակելու միջոցով:
3. Հեղինակն իրավունք ունի հրաժարվել ստեղծագործությունը հրապարակելու վերաբերյալ նախկինում ընդունած որոշումից (հետկանչի իրավունք)` նման որոշմամբ ստեղծագործությունն օգտագործելու իրավունք ունեցող անձանց պատճառած վնասները` ներառյալ բաց թողնված օգուտը, հատուցելու պայմանով: Եթե ստեղծագործությունն արդեն իսկ հրապարակվել է, հեղինակը պարտավոր է հրապարակայնորեն ծանուցել դրա հետկանչի մասին: Ընդ որում, նա իրավունք ունի իր հաշվին շրջանառությունից հանել ստեղծագործության նախկինում պատրաստված օրինակները:
Սույն կետի դրույթները կիրառվում են նաև ծառայողական ստեղծագործությունների նկատմամբ, եթե այլ բան նախատեսված չէ հեղինակի հետ կնքված պայմանագրով:
