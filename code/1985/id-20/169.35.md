# Հոդված 169.35. Սոցիալական աջակցության ոլորտի սոցիալական ծառայությունների կամ անկախ կյանքի կենտրոնի գործունեության նվազագույն չափորոշիչները չպահպանելը
(վերնագիրը լրաց. 03.07.26 ՀՕ-358-Ն)
1. «Սոցիալական աջակցության մասին» օրենքով սահմանված դեպքերում սոցիալական աջակցության ոլորտի սոցիալական ծառայություններ տրամադրողի (բացառությամբ տեղական ինքնակառավարման մարմինների) կողմից, ինչպես նաև անկախ կյանքի կենտրոնի սոցիալական աջակցության ոլորտում պետական լիազոր մարմնի սահմանած նվազագույն չափորոշիչները չպահպանելը՝
առաջացնում է նախազգուշացում կամ տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի քսանապատիկից մինչև հիսնապատիկի չափով:
2. Սույն հոդվածի 1-ին մասում նշված արարքը վարչական տույժը նշանակելուց հետո` մեկ տարվա ընթացքում, կրկին կատարելը`
առաջացնում է տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի հարյուրապատիկից մինչև երկուհարյուրապատիկի չափով:
3. Սույն հոդվածի 1-ին մասով նախատեսված արարքը վարչական տույժ նշանակելուց հետո` մեկ տարվա ընթացքում, երրորդ և յուրաքանչյուր հաջորդ անգամ կատարելը`
առաջացնում է տուգանքի նշանակում` սահմանված նվազագույն աշխատավարձի երկուհարյուրհիսնապատիկից հինգհարյուրապատիկի չափով:
(169.35-րդ հոդվածը լրաց. 24.10.24 ՀՕ-427-Ն, 03.07.26 ՀՕ-358-Ն)
