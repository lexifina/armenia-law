# Հոդված 314.2. Հայտարարագրերը Կոռուպցիայի կանխարգելման հանձնաժողով դիտավորությամբ չներկայացնելը
(վերնագիրը փոփ. 21.01.20 ՀՕ-72-Ն)
1.«Հանրային ծառայության մասին» և «Կուսակցությունների մասին» օրենքներով սահմանված՝ հայտարարագիր ներկայացնելու պարտականություն ունեցող անձի կողմից հայտարարագրերը Վարչական իրավախախտումների վերաբերյալ Հայաստանի Հանրապետության օրենսգրքի 169.28-րդ հոդվածի 1-ին կամ 4-րդ մասով սահմանված վարչական տույժի կիրառումից հետո՝ 30 օրվա ընթացքում, դիտավորությամբ չներկայացնելը`
