# Հոդված 219. ԱՐՏԱՇԻՐՄՈՒՄԸ
1. Դիակի արտաշիրմման անհրաժեշտության դեպքում քննիչն այդ մասին կայացնում է որոշում:
2. Արտաշիրմումը կատարվում է քննիչի և դատաբժշկության բնագավառի մասնագետի, իսկ անհրաժեշտության դեպքում` այլ մասնագետի մասնակցությամբ: Ընթերակաների մասնակցությունը պարտադիր է:
Արտաշիրմմանը՝ իրենց ցանկությամբ, իրավունք ունեն մասնակցելու նաև տուժողի մերձավոր ազգականները:
3. Արտաշիրմումից հետո դիակը կարող է բերվել համապատասխան բժշկական հաստատություն` այլ հետազոտություններ կատարելու համար:
4. Քննիչը կազմում է արտաշիրմման արդյունքները ներկայացնող արձանագրություն: Արձանագրությունն ստորագրվում է այդ քննչական գործողության բոլոր մասնակիցների կողմից, որոնք իրավունք ունեն պահանջել դրա մեջ մտցնելու իրենց դիտողությունները:
5. Արտաշիրմումը չի կարող կատարվել առանց արտաշիրմվողի մերձավոր ազգականների համաձայնության, բացառությամբ այն դեպքերի, երբ քրեական գործով բավարար հիմքեր կան ենթադրելու, որ մերձավոր ազգականներից թեկուզ մեկը մասնակցել կամ որևէ կերպ առնչվել է արտաշիրմվողի մահվան հետ կապված դեպքին, կամ եթե հնարավոր չէ այլ կերպ պարզել դեպքի հանգամանքներն ու լուծել գործի ընթացքը։
(219-րդ հոդվածը լրաց. 25.05.06 ՀՕ-91-Ն)
