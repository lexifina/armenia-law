# Հոդված 223. ԴԻԱԿԸ ՃԱՆԱՉՄԱՆ ՆԵՐԿԱՅԱՑՆԵԼԸ
1. Դիակի, դրա մասերի, ճանաչումը կատարվում է ներկայացված մեկ օրինակով:
2. Եթե ճանաչվում է մարդու դիակ, որին ճանաչողը կենդանի է տեսել, թույլատրվում է հանգուցյալին գրիմ անել:
3. Դիակը ճանաչման ներկայացնելու ընթացքը և արդյունքներն ամրագրվում են տեսաձայնագրառման կիրառումով:
(223-րդ հոդվածը փոփ. 25.05.06 ՀՕ-91-Ն, խմբ. 21.03.18 ՀՕ-181-Ն)
