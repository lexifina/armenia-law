# Հոդված 237. ԴԱՏԱԿԱՆ ՆԻՍՏԸ ՆԱԽԱԳԱՀՈՂԸ
Ժողովրդական դատարանի դատական նիստում նախագահում է ժողովրդական դատավորը, իսկ Հայաստանի Հանրապետության գերագույն դատարանի և զինվորական տրիբունալի նիստում` դատարանի նախագահը, նախագահի տեղակալը կամ դատարանի անդամը:
Նախագահողը ղեկավարում է դատական նիստը, ձեռք առնելով սույն օրենսգրքով նախատեսված բոլոր միջոցները` գործի հանգամանքները բազմակողմանիորեն, լրիվ ու օբյեկտիվ կերպով հետազոտելու և ճշմարտությունը հայտաբերելու համար, դատական քննությունից վանելով այն ամենը, ինչը առնչություն չունի գործի հետ, և ապահովելով դատավարության պատշաճ դաստիարակչական մակարդակը:
