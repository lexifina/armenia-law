# Հոդված 1140. Հարակից իրավունքների սուբյեկտները
1. Հարակից իրավունքների սուբյեկտներ են` կատարողները, ձայնագրման և տեսագրումներ ստեղծողները, եթերային կամ կաբելային հաղորդումներ կազմակերպողները:
2. Կատարման նկատմամբ իրավունքը պատկանում է կատարողներին, ինչպես նաև նրանց ժառանգներին: Նման կատարումն օգտագործելու իրավունքը կարող է անցնել այլ իրավահաջորդների:
3. Ձայնագրման և տեսագրման նկատմամբ իրավունքը պատկանում է այն ստեղծած անձանց կամ նրանց իրավահաջորդներին:
4. Հեռարձակելու իրավունքը պատկանում է հաղորդումն ստեղծած եթերային կամ կաբելային հեռարձակող կազմակերպությանը կամ նրա իրավահաջորդներին:
(1140-րդ հոդվածը փոփ. 07.02.00 ՀՕ-29)
