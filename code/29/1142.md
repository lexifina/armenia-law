# Հոդված 1142. Հարակից իրավունքների գործողության ժամկետը
1. Կատարողի իրավունքները գործում են առաջին կատարման (բեմադրության) կամ առաջին ձայնագրման և տեսագրման պահից հաշված` 50 տարվա ընթացքում:
Անվան նկատմամբ կատարողի իրավունքը և կատարումը խեղաթյուրումներից պաշտպանելու իրավունքը պահպանվում են անժամկետ:
2. Ձայնագրություն և տեսագրություն ստեղծողի իրավունքը գործում է դրա առաջին ձայնագրությունից և տեսագրությունից հետո հաշված` 50 տարվա ընթացքում:
3. Եթերային կամ կաբելային հաղորդման կազմակերպության հեռարձակելու իրավունքը գործում է դրա առաջին հեռարձակման պահից հաշված` 50 տարվա ընթացքում:
4. Սույն հոդվածով սահմանված ժամկետների հաշվարկն սկսվում է սույն հոդվածի 1-3-րդ կետերում նշված իրավաբանական փաստերին հաջորդող տարվա հունվարի 1-ից:
(1142-րդ հոդվածը փոփ., լրաց. 07.02.00 ՀՕ-29)
