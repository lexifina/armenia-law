# Հոդված 36. Հիմնավորված ռիսկը
1. Քրեական պատասխանատվության ենթակա չէ այն անձը, որը քրեական օրենքով պաշտպանվող շահերին վնաս է պատճառել անձի, հասարակության կամ պետության համար օգտակար, իրավաչափ նպատակի հասնելու համար գործադրված հիմնավորված ռիսկի ժամանակ:
2. Ռիսկը համարվում է հիմնավորված, եթե հետապնդվող նպատակին չէր կարելի հասնել առանց ռիսկի դիմելու, և ռիսկի դիմած անձն անհրաժեշտ միջոցներ է ձեռնարկել քրեական օրենքով պաշտպանվող շահերին վնաս պատճառելը կանխելու համար:
3. Ռիսկը հիմնավորված չի համարվում, եթե դա ակնհայտորեն զուգորդված է եղել այլ անձի զոհվելու վտանգով կամ արտակարգ իրավիճակի սպառնալիքով:
