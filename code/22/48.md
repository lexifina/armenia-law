# Հոդված 48. պաշտպանության կարիքների համար հողեր
պաշտպանության կարիքների համար հողեր են համարվում զինված ուժերի, սահմանապահ, ներքին ու երկաթուղային զորքերի զորամասերի, պաշտպանության հիմնարկների, ռազմական-ուսումնական հաստատությունների, ձեռնարկությունների և կազմակերպությունների տեղաբաշխման և մշտական գործունեության համար հատկացված հողերը: Պաշտպանության կարիքների համար հողերի հատկացման և օգտագործման կարգը սահմանում է Հայաստանի Հանրապետության Գերագույն խորհուրդը:
