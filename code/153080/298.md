# Հոդված 298. Կավատությունը
1. Կավատությունը՝ շահադիտական նպատակով կամ այլ ստոր դրդումներով այլ անձի պոռնկությամբ զբաղվելուն ներգրավելը կամ հակելը, եթե բացակայում են սույն օրենսգրքի 188-րդ կամ 189-րդ հոդվածով նախատեսված հանցանքների հատկանիշները՝
պատժվում է տուգանքով՝ քսանապատիկից հիսնապատիկի չափով, կամ հանրային աշխատանքներով՝ հարյուր հիսունից երկու հարյուր յոթանասուն ժամ տևողությամբ, կամ ազատության սահմանափակմամբ՝ մեկից երեք տարի ժամկետով, կամ կարճաժամկետ ազատազրկմամբ՝ մեկից երկու ամիս ժամկետով, կամ ազատազրկմամբ՝ երկուսից հինգ տարի ժամկետով:
2. Սույն հոդվածի 1-ին մասով նախատեսված արարքը, որը կատարվել է՝
1) հղի կնոջ նկատմամբ,
2) հանցավորից նյութական կամ այլ կախվածության մեջ գտնվող անձի նկատմամբ,
3) մի խումբ անձանց կողմից նախնական համաձայնությամբ կամ
4) իշխանական կամ ծառայողական լիազորությունները կամ դրանցով պայմանավորված ազդեցությունն օգտագործելով՝
պատժվում է ազատազրկմամբ՝ երեքից վեց տարի ժամկետով:
