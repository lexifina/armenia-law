# Հոդված 380. Արգելանքի վերցված (արգելապահված) ապրանքների և դրանց վերաբերյալ փաստաթղթերի պահպանման ժամկետը
1. Արգելանքի վերցված (արգելապահված) ապրանքները և դրանց վերաբերյալ փաստաթղթերը, բացառությամբ սույն հոդվածի 2-րդ կետում նշված ապրանքների, մաքսային մարմինների կողմից պահվում են 30 օրացուցային օր, իսկ արագ փչացող ապրանքները՝ 24 ժամ:
2. Սույն Օրենսգրքի 12-րդ հոդվածի 4-րդ և 5-րդ կետերին համապատասխան մաքսային մարմինների կողմից արգելանքի վերցված (արգելապահված) ապրանքները և դրանց վերաբերյալ փաստաթղթերը մաքսային մարմինների կողմից պահվում են 3 օրացուցային օր:
3. Արգելանքի վերցված (արգելապահված) ապրանքների և դրանց վերաբերյալ փաստաթղթերի պահպանման ժամկետը հաշվարկվում է դրանք արգելանքի վերցնելու (արգելապահելու) օրվանից:
4. Սույն հոդվածի կիրառման նպատակներով անդամ պետությունների օրենսդրությամբ կարող է սահմանվել արագ փչացող ապրանքների ցանկը:
