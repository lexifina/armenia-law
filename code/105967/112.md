# Հոդված 112. Համայնքի ղեկավարի և ավագանու անդամի թեկնածուի գրանցումը մերժելու, անվավեր ճանաչելու մասին որոշումների բողոքարկման կարգը
1. Համայնքի ղեկավարի և ավագանու անդամի թեկնածուի գրանցումը մերժելու կամ անվավեր ճանաչելու մասին ընտրատարածքային ընտրական հանձնաժողովի որոշումը կարող է բողոքարկվել վարչական դատարան:
2. Համայնքի ղեկավարի և ավագանու անդամի թեկնածուի գրանցումը մերժելու կամ անվավեր ճանաչելու մասին ընտրատարածքային ընտրական հանձնաժողովի որոշումն անվավեր ճանաչելու մասին դատական ակտով թեկնածուն համարվում է գրանցված կամ վերագրանցված:
(112-րդ հոդվածը փոփ. 07.05.21 ՀՕ-202-Ն)
