# Հոդված 105. Վկաների, փորձագետների և թարգմանիչների` դատական նիստին չներկայանալու հետևանքները
1. Վկաների, փորձագետների և թարգմանիչների` դատական նիստին չներկայանալու դեպքում վարչական դատարանը լսում է դատավարության մասնակիցների կարծիքները` նրանց բացակայությամբ գործը քննելու հնարավորության մասին, և կայացնում է որոշում` գործի դատաքննությունը շարունակելու կամ գործի դատաքննությունը հետաձգելու մասին։
